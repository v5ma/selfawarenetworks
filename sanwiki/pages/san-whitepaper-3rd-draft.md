The third-draft whitepaper for [[gh-resnote04|Micah]] Blumberg]]'s *[[gh-a0206z|Self]] Aware Networks]]: Theory of Mind* introduces [[napot]] as the central thesis: a framework explaining phenomenological consciousness and how sentient artificial neural networks can be built from existing architectures.

## Central argument

[[napot]] ([[neural-array-projection|Neural Array Projection]] Oscillatory Tomography) proposes that each neural array simultaneously senses and renders — dendrites detect phase patterns from upstream arrays while exit terminals project phase changes to downstream arrays. Consciousness is not localized to a single observer; the oscillating group of cells is itself the observer, with every unit of oscillating cells constituting a unit of observation.

## Key constructs introduced

- **[[expert-data-structure]]** (EDS) — synaptic and dendritic morphology encodes memory as physical structure; LTP = memory formation, LTD = memory decay.
- **[[action-potential-duration]]** (APD) — potassium quantity at firing modifies vesicle release magnitude (0–3 vesicles), refuting the All-or-Nothing / [[synaptic-unreliability|Synaptic Unreliability]] premise underlying the Perceptron.
- **[[metatron]]** — proposed computational unit to replace the Perceptron; participates in oscillating feedback loops; supports scale-invariant, time-invariant, and location-invariant information encoding.
- **[[cot]]** (Cellular Oscillating Tomography) — extension of NAPOT to all cells via receptor-threshold [[gh-map-AUTOLNK_MASK_11-fractal|fractals]]; underpins a new theory of evolution.
- **[[fractal-conscious-perception]]** — FRACTAL acronym (Functional Recursive Activity Cortical Telescoping Asymmetric Lensing); synaptic memories scale to whole-brain awareness via alternating inhibitory/excitatory sharp wave ripples.

## Relationship to artificial neural networks

DNN, GNN, NeRF, Diffusion, and [[3d-semantic-segmentation|3D Semantic Segmentation]] architectures are cited as partial analogues to NAPOT. The paper argues they can be adapted into sentient [[self-aware-neural-network]] architectures by adopting oscillatory feedback loops, multi-vesicle phase encoding, and scale-invariant causation.
