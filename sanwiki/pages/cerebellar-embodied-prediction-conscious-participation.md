# Cerebellar Embodied Prediction and Conscious Participation

## The question

The cerebellum helps predict what an action should feel like, compare that prediction with what
actually returns from the body, and update movement. SAN asks a further, testable question: does
that prediction-and-correction process also help construct the changing body state that the larger
neural system experiences and uses?

This is a participation hypothesis. It does not claim that the cerebellum alone creates
consciousness, that neuron count proves consciousness, or that motor impairment is reduced
consciousness.

## The loop

```text
current body state and intended action
-> predicted sensory consequence
-> action
-> proprioceptive, vestibular, tactile, interoceptive, and visual return
-> prediction error and timing correction
-> revised body estimate and next action
```

Established research supports cerebellar roles in sensorimotor prediction, timing, adaptation,
active perception, and regionally differentiated motor and cognitive functions. SAN's extension is
that these operations help shape an embodied state that becomes available through wider recurrent
cortical, thalamic, basal-ganglia, brainstem, autonomic, and peripheral loops.

## Claim ladder

1. **Established:** the cerebellum contributes to prediction, error correction, timing, motor
   adaptation, active force perception, and aspects of self-motion processing.
2. **SAN synthesis:** those operations help construct and revise an action-usable body state.
3. **Stronger hypothesis:** selective cerebellar perturbation changes the content, timing,
   precision, or ownership of embodied experience after motor and report effects are controlled.
4. **Strongest hypothesis:** cerebellar prediction participates in the recurrent field-cell
   process constituting an embodied conscious episode.

Each level requires evidence beyond the one below it.

## How to test it

Compare active and passive force, stiffness, self-motion, and body-ownership judgments during
cerebellar lesion, stimulation, or reversible perturbation studies. Measure movement, autonomic
state, confidence, report latency, and task difficulty. Use matched sham and control-site
conditions. A useful result must distinguish changed experience from motor error, attention,
timing, and report preparation.

A null result is meaningful: if a matched perturbation changes movement but not embodied content,
the stronger conscious-participation claim loses support.
