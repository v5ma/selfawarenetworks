[[gh-resnote04|Micah]]'s 2012 EEG project used brainwave signals to drive real-time changes to light and sound, which in turn altered the user's EEG — a closed-loop biofeedback system intended as a [[gh-a0206z|self]]-reflective meditative tool.

## Core claim

The feedback loop is: person → EEG sensor → computer → light/sound output → person. This makes the technological system an external mirror of the user's neural state. The loop is a low-bandwidth prototype of what SAN theory later formalizes as [[Self-Aware-Networks]]: a system that observes and modifies its own oscillatory state.

## Multimodal BCI context

AR/VR headsets (Microsoft, Meta, Apple, Google, Vive) integrate cameras, eye tracking, and EEG to reconstruct avatars and predict intention and emotion. The combination of gaze, facial expression, and neural oscillation data creates a richer sensor fusion than single-modality EEG.

Relevant BCI projects: BrainGate (motor prosthetics via Utah Array), DARPA neurotechnology programs, applied robotic-arm control.

## Relation to SAN concepts

- [[Self-Aware-Networks]] — the biofeedback loop is the original prototype of a [[gh-a0206z|self]]-aware system: observes internal state, generates output, observes result.
- [[NAPOT]] — the light/sound stimuli targeted oscillatory frequency bands, anticipating the NAPOT resonance framework.
- [[neural-coincidence-patterns]] — biofeedback works by presenting patterns that coincide with the user's existing neural patterns.
