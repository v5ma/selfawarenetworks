# Microtubule Memory

**Microtubule memory** is a hypothesis that persistent or history-dependent states of neuronal microtubules contribute to memory. The phrase must not collapse several different propositions into one.

## Three different claims

| Claim | Current status | What would establish it |
|---|---|---|
| Microtubules support plasticity-related transport and structural remodeling | Established cellular role with experiment-specific support | Manipulation of microtubule dynamics changes a defined plasticity mechanism under appropriate controls |
| Microtubule state carries information that a neuron later reads to alter synaptic or intrinsic response | Candidate intracellular-memory mechanism | State-specific write, persistence, selective readout, perturbation, and rescue |
| A tubulin code stores complete memories or conscious contents | Unestablished strong claim | Content-specific decoding plus biological readout and causal necessity beyond synaptic, dendritic, transcriptional, and network alternatives |

Dynamic microtubule entry into a subset of dendritic spines can influence spine morphology and BDNF-related PSD-95 accumulation ([Jaworski et al., 2009](https://doi.org/10.1016/j.neuron.2008.11.013); [Hu et al., 2011](https://doi.org/10.1523/JNEUROSCI.2445-11.2011)). This supplies a plausible route by which cytoskeletal state can affect future synaptic efficacy. It does not demonstrate a durable tubulin code, identify the represented variable, or show that the organism reads such a code as memory.

## SAN interpretation

SAN should use **microtubule-dependent memory modulation** as the bounded term. A microtubule state may influence cargo delivery, local protein availability, spine remodeling, axonal maintenance, or other slow variables that change a neuron's later receive-integrate-project behavior. The memory-bearing organization may therefore be distributed across synapses, dendrites, cytoskeleton, gene expression, glia, local circuits, and systems-level reactivation rather than stored in one privileged substrate.

At the micro scale, a useful experiment must identify:

1. the physical state written into the microtubule system;
2. how long it persists;
3. which molecule or cellular process reads it;
4. what downstream synaptic or intrinsic variable changes;
5. whether the effect is specific to learned content rather than general cell health or transport; and
6. whether selective disruption and rescue change the predicted behavior.

Without that chain, "microtubule memory" remains a research label rather than a demonstrated memory code. It must not be used to install a hidden observer inside the cell or to infer [[orch-or|Orch OR]].
