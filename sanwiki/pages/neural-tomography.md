Neural tomography is [[gh-resnote04|Micah]] Blumberg]]'s term for the brain's process of extracting invariant patterns by combining many overlapping representations of the same sensory input. Like medical tomography reconstructs 3D structure from multiple 2D projections, the brain reconstructs stable, location-independent patterns from many varied perspectives of the same stimulus.

The mechanism: cortical neurons receive numerous variations of incoming sensory data — from different movement states, angles, and modalities. At each layer, the network detects and retains what is *common* across those variations. Shared structure crystallises into a learned pattern. Because this process runs across many layers simultaneously, the resulting representation is robust to viewpoint, timing, and modality shift.

Neural tomography is the link between [[phase-wave-propagation]] and [[scale-invariant-patterns]]: phase waves deliver signal variations across cortical regions; the tomographic combination step at each layer extracts what persists invariantly across the flood of inputs. Jeff Hawkins's cortical-column model (*A Thousand Brains*) distributes this process — thousands of columns in V1, S1, and A1 each hold their own version of an object's pattern, built from repeated exposure to that object from many perspectives.

The output is a pattern that *any* sufficiently connected set of neurons can represent once the right phase links are established. This explains [[patterns-flow-across-brain-regions]]: the unit of transmission is the [[phase-change]], not the neuron. A pattern learned in the visual cortex can be re-instantiated by neurons in the motor or prefrontal cortex when the same phase structure arrives there.

The idea bridges mechanically with [[color-as-phase-field-contrast]]: color qualia arise from comparing contrasts in a phase field, not from a fixed spectral code. The same tomographic principle — extract invariants across variations — is what allows the same 'red' to be recognized under radically different lighting.
