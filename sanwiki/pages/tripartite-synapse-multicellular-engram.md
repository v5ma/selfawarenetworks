# From Tripartite Synapse to Multicellular Engram

How can one fast synaptic event leave a slower local state that later helps a changing neural ensemble reconstruct, stabilize, or select a memory?

The **tripartite synapse** supplies a cellular starting point. A presynaptic terminal and postsynaptic cell communicate while fine [[astrocytes|astrocyte]] processes detect and alter nearby chemical, ionic, metabolic, and structural conditions. The **multicellular engram** is the larger hypothesis: learning leaves coordinated readiness across neurons and glia, and later recall reconstructs a usable relation through those changing carriers rather than replaying one frozen cellular picture.

The two terms are not synonyms. A tripartite synapse is a local structural and functional arrangement. A multicellular engram is a proposed memory architecture spanning many cells, sites, and timescales.

## Joined causal chain

```text
synaptic release and local potassium change
-> perisynaptic astrocyte processes detect local conditions
-> astrocyte voltage, calcium, transporter, metabolic, or transcriptional state changes
-> clearance, synaptic coverage, gain, and plasticity conditions change
-> learning leaves coupled neuronal and astrocytic readiness
-> a later cue recruits a present neuronal ensemble within that altered state
-> neuronal and astrocyte ensembles affect recall access, stability, or precision
-> changing multicellular carriers reconstruct a usable relation
-> SAN asks whether glial state also changes tonic context and PWD routing
```

Each arrow is a separate scientific question. Showing that astrocytes affect recall does not by itself prove that they encode cue identity. Showing that they retain a multiday state does not show that one astrocyte contains a complete memory. The architecture allows content, indexing, access, gain, stability, precision, and general state to be distributed across different components.

## What is established

Experiments have demonstrated the following operations in defined preparations:

- Local astrocyte processes can detect nearby synaptic activity and alter release or clearance conditions.
- Astroglial potassium clearance can contribute to short-term synaptic plasticity.
- Astrocyte calcium state can affect perisynaptic coverage, transmitter spillover, plasticity, and selected memory outcomes.
- Activating hippocampal astrocytes can produce neuronal potentiation and enhance later recall under the tested conditions.
- Learning-associated astrocyte ensembles can interact with neuronal engrams and causally regulate recall.
- A longer-lived astrocyte ensemble can affect memory stability and precision after repeated experience.
- Task-recruited astrocyte ensembles can alter cue-motivated behavior, and astrocyte population state can track and change anxiety-related behavior.

These findings support a multicellular memory process. They do not yet decide whether an astrocyte ensemble stores content, indexes a neuronal engram, regulates access, stabilizes a trace, changes precision, or primarily controls a broader state. Those roles require dissociating experiments.

## Dated SAN genealogy

### 2017: neural network plus glionet

In the May 5, 2017 fourth Neural Lace Podcast, Micah Blumberg argued that a useful brain snapshot would need to capture astrocytes as well as neurons. The discussion explicitly described a **neural net** and a **glionet** interfacing with one another. This is the public ancestor of SAN's multicellular-computation claim.

### June-August 2022: glial state enters COT and NAPOT

In June 2022, SAN proposed that phase-coincidence relations could signal neurons and glia to grow or remove connections while contributing to a tomographic reconstruction. In August 2022, SAN explicitly included astrocytes, oligodendrocytes, microglia, T cells, and other cells in the COT-to-[[napot-theory|NAPOT]] interface. It also connected astrocyte voltage and transporter state to changes in the conditions surrounding neural signaling.

One phrase in the August source says that astrocyte depolarization releases "inhibitory glutamate." The cited experiment instead showed that depolarization inhibited glutamate transporters and slowed glutamate uptake, increasing extracellular glutamate. Recovering that intended operator preserves the SAN idea - astrocyte state changes the next neuronal condition - without retaining the transcription error.

### 2024-2026: ensemble experiments sharpen the hypothesis

Recent studies now separate learning-associated astrocyte ensembles, multiday stabilizing traces, cue-motivated ensembles, and affective state representations. They make SAN's earlier multicellular scope more testable, but they do not retroactively prove every SAN mechanism or establish PWD terminology.

## SAN extension

SAN proposes that memory recall is a reconstruction performed by a changing multicellular network. On this view, a glial state can change the **tonic context**, local route eligibility, gain, and persistence in which faster neuronal [[phase-wave-differential|phase-wave differentials]] are received. The astrocytic contribution need not be a neuron-like spike and need not be a hidden viewer. The observer is the distributed network activity itself.

This yields a specific hierarchy of claims:

1. **Established:** astrocytes can alter local transmission and plasticity, and selected astrocyte ensembles can alter memory or state-related behavior.
2. **Documented SAN synthesis:** neural and glial networks jointly contribute to learned state and recurrent reconstruction.
3. **SAN extension:** glial history changes receiver-relative tonic context and the routing or persistence of PWD events.
4. **Open strongest claim:** specific multicellular timing patterns contribute directly to reconstructed perceptual or mnemonic content.

## Decisive test

Tag neurons and astrocytes engaged during learning, then record both populations during natural cue recall. Perturb the tagged neuronal ensemble, the tagged astrocyte ensemble, and both together. Measure cue identity, recall access, stability, precision, arousal, movement, and general network activity separately.

A strong content test would reactivate learning-tagged astrocytes while suppressing the surrounding neuronal engram and ask whether the result is cue-specific rather than generic fear, arousal, freezing, or motivation. A strong SAN phase test would then ask whether receiver-relative timing or state variables improve held-out prediction and selective causal control beyond firing rate, calcium, cell identity, and general-state models. Mechanism-matched rescue and measurement of each tool's spatial and temporal footprint are required.
