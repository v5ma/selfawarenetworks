Long-term potentiation (LTP) memories are reframed not as static synaptic weight changes but as **electro-chemical tempo-spatial rhythms** — protein-calibrated axon potential discharges with a characteristic timing and spatial spread. This positions LTP within the SAN [[oscillating-network-of-oscillators]] framework rather than the static connectivity view.

## Core claim

LTP encodes information as a repeating discharge pattern across a dendritic-axonal circuit, calibrated by protein expression (AMPA/NMDA receptor densities, CaMKII activity). The rhythm IS the memory: the same tempo-spatial signature re-fires when recalled. This is why [[phase-wave-differential]] is a better unit of memory than "synaptic weight."

## The neurogenesis paradox

Adult neurogenesis generates new neurons that lack the history of those they replace. If memory is a tempo-spatial rhythm distributed across a circuit, two questions arise:

1. Can a new neuron slot into an existing rhythm without disrupting it?
2. Could protein configuration be replicated to a new neuron (a form of "pattern cloning") so the rhythm persists?

The document raises but does not resolve whether DNA-mediated transfer of LTP-encoding protein states is possible. Current neuroscience holds that new neurons integrate into existing circuits gradually (spine growth, synaptic competition) rather than by copying pattern states.

## Relation to SAN framework

This reframing converts LTP from a weight-based (connectionist) concept to a rhythm-based (oscillatory) one, directly supporting [[napot]]'s claim that neural arrays project and propagate phase patterns rather than propagating activation magnitudes.
