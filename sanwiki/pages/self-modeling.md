# Self-Modeling

**Self-modeling** is the maintenance and causal use of estimates about a system's own body,
sensors, effectors, capabilities, internal constraints, or control history. A researcher being
able to decode one of those variables from hidden activity is not enough: the system must use the
estimate in prediction, action, adaptation, or report.

## Operational test

A strong test changes a body or capability variable:

- rotate or delay a sensor;
- weaken or remap an effector;
- alter body geometry;
- remove a feedback channel; or
- change the relation between action and consequence.

The candidate system must estimate the changed condition and use that estimate. Two complementary
interventions are needed: manipulate the represented body or capability while the physical
condition is held fixed, and manipulate the physical condition while direct cues are controlled
where possible. A preregistered mediation or causal-use analysis should test whether the estimate
carries the predicted policy effect.

Direct policy adaptation can succeed without an explicit self-model. That is a useful alternative,
not a failed agent. The narrower conclusion is that the self-model claim was not supported.

## What SAN proposed

SAN sources connect recursive self-modeling with shared phase patterns and temporal persistence,
and later drafts describe that combination as sufficient for first-person coherence. They also
connect self-modeling to long-term memory and context-sensitive artificial agency. These statements
establish the SAN proposal's genealogy.

They do **not** establish that three conditions are sufficient for phenomenal consciousness.
Shared phase can arise without a self-model; persistent state can exist without experience;
recursive representations can be implemented symbolically; and competent behavior can arise from
policy adaptation without an identifiable self-related state.

## Levels that must remain separate

| Level | What can be shown |
|---|---|
| Decodability | An external analyst can recover a body or capability variable from activity |
| Endogenous access | Other system components receive the variable |
| Causal use | Intervention on the variable changes prediction or action as specified |
| Adaptive value | The variable improves remapping, robustness, or control over matched alternatives |
| SAN conformance | A versioned architecture satisfies declared SAN self-model commitments |
| Consciousness assessment | Evidence is evaluated across competing theories with explicit uncertainty |

No earlier row automatically proves a later row.

## Distributed observer-action

Self-modeling does not create a model watched by a hidden self. The maintained estimate is one part
of a distributed loop that registers changes, predicts consequences, selects actions, receives
reafference, and updates. SAN's tonic canvas supplies proposed ongoing receiver context; phasic ink
supplies proposed state-changing differences. Whether those roles contribute to experience remains
an open SAN hypothesis.

## Socially learned other-models

`a0036z.md` adds a developmental question that the earlier self-model page did not preserve. An
agent may learn a model of another individual's voice or policy, reactivate part of that model when
the individual is absent, and use the reactivation in its own prediction or action. That sequence
can scaffold self-modeling only if it changes a variable about the learner's own capability,
action, or expected consequence.

The required alternatives are stored imitation, direct policy adaptation, generic memory replay,
and current external cueing. Source monitoring is also essential: internally generated speech or
imagery must be distinguished from current external input. See
[[socially-internalized-inner-speech-self-model|From Other-Model to Self-Model]].
