# Detection-Rendering Interlace

## The idea in plain language

The brain does not need a hidden viewer to watch an internal picture. The same distributed system
that constructs an updated sensory state is changed by that state and registers the change in its
next cycle of activity.

SAN calls this a **detection-rendering interlace**:

```text
render an update -> the network changes -> detect that change -> render the next update
```

Visual, auditory, tactile, remembered, and predicted patterns can contribute different parts of
the changing state. The observer is the coordinated operation of the network, not a separate thing
inside it.

## What is established and what is proposed

Neuroscience supports recurrent processing, multisensory integration, and state-dependent
perception. SAN adds the stronger proposal that interlaced construction and detection form the
observer operation. Literal alternating frames and sufficiency for consciousness remain open.

## Simultaneous observing and encoding oscillators

[[gh-a0066z|a0066z]], Git-fixed on June 10, 2022, supplies an earlier mechanical ancestor. Local
phasic or inhibitory events perturb an ongoing population state; a sufficiently large change
reorganizes the group state, which then influences downstream and recurrent activity.

```text
local departures -> population-state change -> downstream detection -> recurrent update
```

The changed population state can therefore be both a consequence detected by the network and an
encoding transmitted into its next step. This does not mean every neuron resets phase at once or
that phase reset proves consciousness. Tests must measure phase-reset concentration, recruitment,
effective connectivity, and downstream information while controlling firing rate, evoked
amplitude, movement, and arousal.
