# Brain As Hard Drive Vrma 2017

**Brain As Hard Drive Vrma 2017** is a 2017 VR/AR-conference talk slot in this wiki's legacy SAN archive in which the [brain-as-hard-drive](brain-as-hard-drive.md) metaphor -- that long-term memory is laid down in the brain the way files are laid down on a magnetic disk -- is staged as a foil against the [Self-Aware Networks theory](self-aware-networks-theory.md). The "VRMA 2017" suffix marks it as one of [Micah Blumberg](micah-blumberg.md)'s 2017 conference appearances alongside [nervegear-show-2017](nervegear-show-2017.md), [neural-lace-ar-vr-no-glasses-2017](neural-lace-ar-vr-no-glasses-2017.md), [mind-code-brain-code-alphago-2017](mind-code-brain-code-alphago-2017.md), and the [Neural Lace Podcast](neural-lace-podcast-four-episodes-index-2017.md) series; it is a *position*, not an endorsement.

The hard-drive analogy treats the brain as passive storage and the [connectome](connectome.md) as a fixed write-once medium where [engrams](engrams.md) and [Hebbian engrams](hebbian-engrams.md) persist as static address-and-data pairs. The 2017 talk uses this picture as the strawman against which [self-activating-content-addressable-memory](self-activating-content-addressable-memory.md) is contrasted -- memory in SAN is not a sectored disk but an oscillatory pattern that re-instantiates itself, closer to [wave recontextualization](memory-wave-recontextualization.md) and [oscillation reinstatement](oscillation-memory-reinstatement.md) than to a filesystem. Where a hard drive *holds* bits between reads, a [self-aware network](self-aware-network.md) *re-runs* them via [travelling-wave](traveling-waves-neural-oscillations.md) dynamics, [prediction loops](memory-prediction-as-intelligence.md), and [drifting virtual engrams](neural-drift-virtual-engrams.md) that are never identically restored.

In the 2017 framing, three follow-up moves are anticipated: replace static storage with a [memory-as-prediction](life-as-memory-prediction.md) view, replace fixed addresses with [attractor](attractor-memory.md)-style basins, and replace deterministic readback with [probabilistic readout](memory-as-probability-distribution.md). The talk is also the canonical hand-off point into the [queryable-network](brain-as-queryable-network.md) reframing and the [fractal-modules](brain-as-fractal-of-modules.md) picture that succeed it in later writing. Until primary-source artifacts (slides, video transcript, abstract) are backfilled into the packet, this page should be read as a marker that the 2017 VRMA appearance happened, that it explicitly engaged the hard-drive metaphor, and that its rejection seeded the SAN-side concepts catalogued under [Self-Aware Networks theory](self-aware-networks-theory.md) and [adjacent 2017 talks](neural-lace-ar-vr-no-glasses-2017.md).
