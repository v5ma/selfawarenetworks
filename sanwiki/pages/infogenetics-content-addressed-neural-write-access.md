# Infogenetics: Content-Addressed Neural Write Access

Infogenetics is Micah Blumberg's name for a proposed neural write system that learns which
spatiotemporal stimulation pattern will recruit a declared neural, perceptual, mnemonic, or
behavioral state, then verifies and corrects the intervention in a closed loop.

It is not the claim that an abstract information pattern automatically finds a matching neuron.
The address must be learned from measured stimulation-response relationships.

## Source genealogy

[[gh-a0390z|a0390z]] contains an internally dated October 18, 2013 discussion that first proposes
`electrogenetics` as electrical rather than optical intervention and then coins `infogenetics` for
criteria-matched, information-pattern control of neural activity. The note entered the downloaded
Git repository on June 8, 2022. The internal date and Git date are different evidence layers.

Modern `electrogenetics` usually refers to electrical control of engineered gene expression. That
is not identical to the broad neural-control proposal in the historical note.

## Architecture

Keep three layers separate:

1. **Carrier:** light, electrical current, ultrasound, magnetic induction, or another physical
   intervention.
2. **Address:** anatomy, cell type, genetic sensitization, current state, or a learned response
   model.
3. **Payload and control:** the spatiotemporal pattern, target state, feedback signal, and safety
   constraints.

```text
measured neural state
-> learned stimulation-response model
-> bounded patterned intervention
-> measured neural and behavioral consequence
-> model update
```

Changing carriers does not create semantic specificity. The content-addressed claim requires
held-out evidence that one learned pattern recruits the declared state better than simpler
location-, rate-, state-, random-, and replay-based controls.

## Scientific neighborhood and boundary

Activity-tagged engram reactivation, two-photon ensemble imprinting, holographic ensemble recall,
closed-loop all-optical control, and adaptive patterned electrical stimulation establish several
components of this architecture. They do not establish arbitrary qualia writing, person-to-person
code identity, or machine consciousness.
