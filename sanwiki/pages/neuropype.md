# Neuropype

**Neuropype** is the time-synchronisation pipeline software built by Tim Mullen (CEO of Intheon, and creator of the [Glass Brain](./glass-brain.md) [EEG](./eeg.md) visualization) that aligns heterogeneous biosignal streams -- [EEG](./eeg.md), EMG, ECG -- into a single multimodal time-series so that cross-modal patterns can be detected. In [Micah Blumberg](./micah-blumberg.md)'s [Self-Aware Networks](./self-aware-networks.md) notes Neuropype is repeatedly invoked as a *conceptual analogue* for how the brain itself combines unstructured sensor streams from across its own modalities, and it is one of the recurring software references he cites when explaining the [oscillatory-synchrony multimodal integration](./oscillatory-synchrony-multimodal-integration.md) mechanism inside [NAPOT](./napot-overview.md) and the [multimodal rendering loop](./consciousness-multimodal-rendering-loop.md).
