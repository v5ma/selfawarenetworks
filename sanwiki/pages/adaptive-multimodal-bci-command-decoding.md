# Adaptive Multimodal BCI Command Decoding

## The problem

A brain-computer interface does not receive a clean object called "intention." It receives partial
measurements. Electrical, ocular, muscular, hemodynamic, behavioral, and device signals expose
different parts of a user-system interaction at different speeds and with different artifacts.

A second problem appears after calibration: the person learns. A classifier trained on an
effortful novice strategy may become less reliable as the user discovers a more efficient way to
produce the same intended command.

## The operation in plain language

```text
declared user intention
-> chosen mental, ocular, or muscular strategy
-> modality-specific measurement
-> bounded feature extraction and classification
-> declared device command
-> device trajectory and timing
-> success, error, and user correction
-> user learning plus decoder recalibration
```

The system does not need one sensor to do everything. It needs to know what each channel measures,
how long that measurement takes, what command vocabulary was trained, and whether the intended
outcome occurred.

## What "eight-command decoding" meant

Khan and Hong's 2017 system used two four-class branches:

| Branch | Trained classes | Window | Role |
|---|---|---:|---|
| fNIRS | mental arithmetic, mental counting, mental rotation, word formation | 0-2 s | four commands |
| EEG-system | two blinks, three blinks, vertical eye movement, horizontal eye movement | 1 s | four other commands |

The branches were independently processed. Their outputs controlled different quadcopter
movements. The study therefore expanded the command vocabulary through complementary channels; it
did not train one feature-fused eight-class EEG-fNIRS model
([Khan and Hong, 2017](https://doi.org/10.3389/fnbot.2017.00006)).

The article's abstract reports 75.6 percent mean fNIRS accuracy. Its table, results, and conclusion
report 76.5 percent, and the ten Table 2 values average to 76.5 percent. The EEG-system branch
reports 86 percent. The discrepancy is retained as a source inconsistency.

## A command can have bounded meaning

The user intentionally performed one of a declared set of tasks or eye actions. The classifier
selected a trained class. Software mapped that class to a declared movement, and the quadcopter
changed state.

That is genuine **bounded command decoding**. Its semantic scope is fixed by the training protocol,
command table, user instruction, and measured device consequence.

This positive result should be stated before asking what the system did not decode. Open-ended
thought, detailed conceptual content, qualia, selfhood, and consciousness are different targets
that require different labels and tests.

## Acquisition, fusion, and adaptation are different

Several operations are often compressed into the word `hybrid`:

1. **acquisition:** record more than one signal family;
2. **registration:** align clocks, sensor locations, anatomy, task events, and device events;
3. **feature fusion:** join features before classification;
4. **decision fusion:** join probabilities, votes, or class decisions;
5. **command arbitration:** let independent channels constrain, confirm, or counteract commands;
6. **adaptation:** update the decoder as the person, hardware, or context changes.

Khan and Hong used parallel acquisition, independent processing, and command-level
complementarity. They paired opposing movements across modalities so that one command could
counteract an erroneous movement from the other.

Explicit feature fusion is a different architecture. For example, Jafari Deligani and colleagues
joined EEG and fNIRS features with mutual-information-based feature selection and compared the
fused model with the individual modalities
([2021](https://doi.org/10.1364/BOE.413666)).

## The user is part of the learning system

Co-adaptive BCI research treats user and classifier as two changing parts of one feedback loop.
Machine-learning-based co-adaptive calibration has been tested as an alternative to a fixed
offline calibration followed by later feedback
([Vidaurre et al., 2011](https://doi.org/10.1162/NECO_a_00089)).

Practice can also change the neural activity supporting control. In one ECoG BCI task, increasing
proficiency was accompanied by reduced task-related activation in parts of prefrontal, premotor,
and posterior parietal cortex
([Wander et al., 2013](https://doi.org/10.1073/pnas.1221127110)).

That finding supports a general nonstationarity problem. It does not say that every practiced
task, signal, person, or brain region changes in the same direction.

## Physiological labels matter

An EEG headset can detect strong signals generated by eye movements and blinks. Those features can
include corneo-retinal potentials and periocular muscle activity. Calling the hardware `EEG` does
not make every feature cortical EEG.

This is not a dismissal of the control result. It is a better description of why the eye-action
commands were robust and a guide for deciding when EEG, EOG, or EMG is the appropriate name and
sensor.

Likewise:

- fNIRS estimates hemoglobin-related optical changes over tissue volumes;
- scalp EEG measures voltage differences produced by organized population currents;
- EMG measures muscle-related electrical activity;
- device telemetry measures the machine's later state;
- behavior and report indicate whether the intended outcome occurred.

## Where the comparison stops

- Simultaneous EEG-fNIRS acquisition is not automatically feature or decision fusion.
- A finite trained command vocabulary is not open-vocabulary thought reading.
- A mental-task class is not a reconstruction of the participant's complete thought content.
- fNIRS is not a direct oxygen measurement from one neuron.
- Sampling rate is not the same as usable physiological bandwidth.
- Reduced activation with practice in one task is not a universal decline in neural firing or
  metabolism.
- Attention, arousal, fatigue, medication, strategy, and clinical condition may affect the
  measurement, but effects must be measured rather than generalized.
- The 2017 study used ten right-handed male participants and does not establish universal or
  clinical performance.
- Adaptive flight control, adaptive signal decoding, user learning, and co-adaptation are
  different update operations.

## The SAN extension

SAN preserves the 2021 discussion as a bridge from multimodal instrumentation to a long-term
person-interface relationship:

> A personalized system that preserves modality-specific forward models, uses behavior and device
> consequence as feedback, and recalibrates with the learner will remain useful longer than a
> fixed decoder trained on one session and one effort strategy.

The extension has four testable parts:

1. **timescale-aware integration:** align each signal by its measured latency and integration
   window;
2. **outcome supervision:** include device trajectory, task completion, correction, and user
   report;
3. **longitudinal co-adaptation:** compare frozen and adaptive decoders over repeated sessions;
4. **capability labeling:** report exactly which level of neural semantics was demonstrated.

## Capability ladder

```text
signal detection
-> finite task-state classification
-> declared command decoding
-> behavioral goal inference
-> structured content reconstruction
-> induced percept verification
-> self-model or conscious-state assessment
```

Evidence at one level remains genuine evidence. It does not automatically establish every level
above it.
