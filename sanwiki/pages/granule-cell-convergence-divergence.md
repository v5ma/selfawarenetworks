The same neural signal pathway appears simultaneously as divergent (macroscopically) and
convergent (from each neuron's local perspective) — a duality that [[gh-resnote04|Micah]] highlights via
the entorhinal cortex → granule cell projection as a key example of scale-dependent
interpretation in [[napot|SAN's multi-scale signal theory]].

## Core observation

Entorhinal cortex (~50 000 neurons) fans out to ~1 000 000 granule cells in the dentate
gyrus — a massive divergence by any global count. Yet from the perspective of any single
granule cell, it is *receiving* converging inputs from many entorhinal neurons. The
same anatomical projection is simultaneously:
- **Macroscopically divergent** — one entorhinal signal reaches exponentially more cells
- **Locally convergent** — each granule cell integrates many upstream inputs

## SAN implication

[[gh-resnote04|Micah]]'s note emphasizes that *all* neurons in the brain exhibit this dual convergence-
divergence simultaneously. No neuron is purely a sender or purely a receiver — every
cell fans its output out to downstream targets while integrating incoming streams. This
scale-dependent reversal of directionality is one reason [[functional-fractal-isomorphism]]
holds: the same pattern (many-to-one or one-to-many) reappears at every level.

## Relation to stable base oscillations

The same note describes a "hospitality signal" — a stable low-frequency oscillatory
base that waits for incoming data to update portions of it. The convergence-divergence
architecture is what makes this possible: the stable base (tonic low-frequency) can be
selectively updated by incoming high-frequency bursts because divergence fans those
bursts across a large surface while convergence integrates them into specific local
attractors. See [[tonic-oscillation-framework]] and [[consciousness-wave-magnification]].
