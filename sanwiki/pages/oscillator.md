# Oscillator

![Oscillator as SAN phase-bearing computational unit](/v5ma.github.io/wiki/assets/generated/san/oscillator/oscillator-phase-bearing-unit-20260628-v4.png)

This SAN mechanism image frames the oscillator as a phase-bearing computational unit: a local oscillator carries phase as both data and update rhythm, neighbor phase differences become phase-wave differential signals, synchronized groups behave as macro-oscillators, and the same rule repeats from cell to cortical column to network field.
