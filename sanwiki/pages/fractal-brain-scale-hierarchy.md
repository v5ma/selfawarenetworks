The fractal brain scale hierarchy describes how the same pattern of oscillatory
processing repeats across at least four nested spatial scales in the brain, from
individual synapses to the whole-brain thalamo-cortical loop.

## The four scales

[[gh-resnote04|Micah]] identifies (in audio notes `b0122y`):

1. **Microscale** — [[dendrite]] and dendritic microtubule level; individual synapse events.
   See [[dendritic-coincidence-detection]] for how each [[dendrite]] acts as a local
   pattern detector.
2. **Horizontal neural circuit scale** — local circuits within a cortical column;
   neurons exchanging phase signals laterally.
3. **Mesoscale / cortical column** — each column acts as its own oscillator,
   integrating horizontal circuits into a column-level representation.
4. **Macroscale** — all cortical columns networked through and oscillated by the
   [[thalamus]], which functions as the macro-scale frame of representation.

A hypothetical fifth scale — quantum microtubule dynamics — is noted as possible but
expected to have effects too small to tip action potentials in most circumstances.
[[gh-resnote04|Micah]] remains skeptical of [[orch-or]] as a *necessary* mechanism while acknowledging
it doesn't invalidate the rest of [[self-aware-networks]] theory.

## The fractal oscillatory memory system

At each scale the pattern is the same: inputs drive oscillations, oscillations encode
memory traces, and action-prediction loops close the cycle. [[gh-resnote04|Micah]]'s shorthand:
**fractal oscillatory action-prediction memory system** — the same architecture
repeated from [[dendrite]] to thalamus.

This nesting is what allows the brain to function as a distributed [[phase-wave-differential]]
network rather than a simple feedforward processor. See [[napot]] for how the
thalamo-cortical loop projects these oscillations into unified percepts.

## Implications

If the brain's networking protocol is fractal-oscillatory, then artificial sensory
prosthetics (eyes, nose, touch) could be designed to exploit the same multi-scale
encoding — feeding richer sensory bandwidth into the existing hierarchy without
requiring a new protocol.
