# Voluntary Shared Cognitive Environments and Retained Personhood

## The problem

A group can share information or a virtual world without becoming one person. A future neural
interface could make that distinction harder to inspect. The important design question is
therefore not only how much information can pass between people and machines. It is how to preserve
who sensed, remembered, chose, acted, learned, and can leave.

## The operation in plain language

Each participant begins with a continuing perception-action loop:

```text
person-specific sensing and memory
-> preparation and action
-> bodily and environmental consequence
-> returned evidence
-> later learning and choice
```

A shared artificial environment can connect several such loops. It can maintain common objects,
carry messages, and register joint actions. Each participant still needs a separately trackable
viewpoint, action channel, memory history, error signal, and means of disconnection.

An avatar helps by making location, available action, and returned consequence explicit. It is an
action and perspective reference, not a little viewer inside the mind.

```text
individual continuity
-> voluntary connection
-> registered channels
-> situated avatar or body reference
-> shared perception and coordinated action
-> separately attributable consequences
-> reversible disconnection
```

After that operation is understood, **voluntary shared cognitive environment** names the
interface. **Retained personhood** names the SAN hypothesis that temporary collective coupling can
preserve each participant as a distinct continuing person.

## The 2021 source

A November 2021 Micah Blumberg recording describes a shared artificial world in which connected
people retain their own situated perspectives and use player characters to act. It joins
voluntary participation, network coupling, oscillatory organization, sensorimotor rendering, and
the possibility of an external cognitive environment before the 2022 public SAN synthesis.

The recording was first fixed publicly in Git on June 8, 2022. A separate 2022 note,
[[gh-a0080z|a0080z]], develops cellular pixels, tonic and phasic activity, synaptic distribution,
and layer-to-layer rendering. The notes are connected, but the later cellular wording is not
backdated into the 2021 recording.

A separate November 5, 2021 recording adds a neighboring external-cortex operation. It begins with
a portable WebXR layer, allocates detail according to the current viewpoint, recalls the 2018
EEG-in-XR project, and then asks whether several distinct users and one adaptive shared system can
maintain a temporary task-level "we" model. This second recording remains private and is represented
through bounded paraphrase. Public June and August 2022 Git objects corroborate the EEG-in-VR and
external-cortex program without being treated as copies of the recording.

## Established footholds

BrainNet connected three people in a collaborative Tetris-like task using EEG for two senders and
TMS for a receiver. It demonstrates bounded multi-person neural mediation while retaining
separate participant roles
([Jiang et al., 2019](https://doi.org/10.1038/s41598-019-41895-7)).

Virtual-reality experiments show that first-person perspective and multisensory congruence can
alter body ownership and self-location
([Petkova et al., 2011](https://doi.org/10.3389/fpsyg.2011.00035);
[Maselli and Slater, 2014](https://doi.org/10.3389/fnhum.2014.00693)).
These results make an avatar a plausible reference for perspective and agency.

Distributed functional-connectivity profiles can identify individuals across sessions and tasks
([Finn et al., 2015](https://doi.org/10.1038/nn.4135)). Interpersonal musical performance can also
produce measurable within- and between-brain phase coordination
([Sanger et al., 2012](https://doi.org/10.3389/fnhum.2012.00312)).
Co-adaptive BCI research adds the practical point that users and decoders can learn together
([Vidaurre et al., 2011](https://doi.org/10.1162/NECO_a_00089)).

Other bounded footholds clarify the temporary shared-state question. Speaker-listener coupling can
covary with communication success
([Stephens et al., 2010](https://doi.org/10.1073/pnas.1008662107)), and dual-EEG work can measure
interpersonal phase relations during behavioral coordination
([Dumas et al., 2010](https://doi.org/10.1371/journal.pone.0012166)). Group performance can also
contain a measurable collective-intelligence factor
([Woolley et al., 2010](https://doi.org/10.1126/science.1193147)). These results make coordinated
group state a legitimate measurement target while leaving the participants as distinct people.

## Where the comparison stops

- A collaborative BCI does not establish a merged mind or shared qualia.
- Between-brain synchrony does not make two people one person.
- A neural fingerprint is one measurable individual feature, not a complete identity criterion.
- An avatar is not the observer and does not prove that its software is conscious.
- WebXR can render a shared environment but does not itself read or write neural states.
- An external cortex coupled to a human is not the same architecture as an autonomous artificial
  mind.
- The 2021 recording does not contain every later PWD, NAPOT, Gamma Consideration Sandwich,
  Field-Cell Self, or machine-consciousness definition.

## The SAN extension

SAN proposes that retained personhood during coupling should be tested through a bundle of
properties rather than one rhythm or connection:

1. continuity of memory and learned history;
2. stable but revisable sensorimotor contingencies;
3. separately attributable action and consequence;
4. causal autonomy and independent error correction;
5. persistence of values and preferences;
6. explicit consent and inspectable information flow; and
7. revocation followed by successful independent operation.

The shared system should first be modeled as several interacting loops. A stronger merged-person
claim is warranted only if registered evidence cannot be explained by the participants, their
channels, common input, or the shared task model.

SAN separately preserves a **transient shared "we" hypothesis**: several continuing persons may
maintain one common task representation containing shared objects, goals, roles, uncertainty, and
returned consequences. This is a claim about an operational group controller, not yet a claim
about one shared conscious subject. It should be compared against independent-agent, common-input,
ordinary-communication, and static-workspace models before stronger language is used.

## Discriminating prediction

A well-designed coupled system should improve shared task performance while preserving
within-person continuity, separately attributable agency, independent error correction, and
reversible departure.

If coupling irreversibly destroys those properties, the retained-personhood criterion fails.
