# Expert Data Structures

A biological neuron is not adequately described as one number followed by one threshold. The
location and history of its synapses, dendritic branches, receptor states, membrane conductances,
inhibition, recent activity, and chemical context change which input combinations it recognizes
and what it does next.

**Expert Data Structure (EDS)** is Micah Blumberg's name for that learned biological
receive-transform-project configuration. *Expert* means selectively responsive because of prior
structural and state change. It does not mean that one dendrite is a person or understands an
object.

## A bounded state description

```text
E_i(t) = {morphology, synapses, receptors, context, inhibition, history, optional vesicle terms}
y_i(t) = F_i(inputs_i(t), E_i(t), network_context(t))
```

An EDS is a measurable state bundle and transformation, not a new anatomical organ.

## Source genealogy

`a0131z.md`, internally dated February 21, 2014 and first Git-fixed in June 2022, uses the earlier
phrase **advanced expert data structures** for self-activating, content-addressable dendritic
memory. `a0196z.md`, first current-path Git-fixed June 11, 2022 and expanded in July, joins
dendritic and synaptic morphology, vesicle or exosome release, nested oscillatory organization,
and proposed invariance across scale, time, space, or phase. The white paper later compresses the
idea to: synapses and dendrites constitute an Expert Data Structure.

```text
learned local configuration
  -> selective reception and nonlinear transformation
  -> state-dependent cellular output
  -> recruitment of a larger learned group
  -> possible reconstruction of object properties for thought, perception, or action
```

## Claim ladder

**Established background:** dendrites and synapses perform state-dependent nonlinear computation;
neuronal extracellular-vesicle release can be activity regulated; selected Arc capsids can
transfer RNA; oscillatory coupling changes with brain state.

**SAN synthesis:** treat the learned dendritic-synaptic-receptor configuration and its current
state as one addressable biological transformation rather than a point unit.

**Stronger SAN hypothesis:** nested EDS configurations preserve declared task-relevant relations
across bounded changes in carrier, scale, timing, viewpoint, or phase, allowing partial cues to
recruit and re-express a learned distributed pattern.

**Additional molecular hypothesis:** selected vesicle or RNA-transfer pathways contribute
causally to the long-timescale state of some EDS configurations. This is separable from the
dendritic-synaptic core.

## Scientific corrections

- A rhythmic-plasticity model does not show that sleep literally clears human short-term memory.
- Neuronal vesicles and Arc-RNA transfer do not establish exosome-coded memory or routine DNA
  messages. That remains a testable extension.
- Dendritic computation does not establish universal invariance, consciousness, qualia, NAPOT, or
  one unchanged rule across every scale.
- Burst-dependent learning is a computational comparison, not proof of biological backpropagation
  or EDS.

## Decisive tests

1. Compare a point-neuron baseline with models that add measured branch geometry, synaptic
   location, receptor state, inhibition, and recent activity.
2. Define each proposed invariance and test held-out generalization under that transformation.
3. Perturb individual EDS terms while approximately preserving the others.
4. Separate local recognition, group recruitment, content reconstruction, conscious access, and
   action.
5. Test the molecular extension only after synaptic and transcriptional controls.
