# Attractor Memory

![Attractor Memory phase basin retrieval diagram](/v5ma.github.io/wiki/assets/generated/san/attractor-memory/attractor-memory-phase-basin-retrieval-20260628-v4.png)

This image states the page's core mechanism as one retrieval cycle: a partial cue reactivates part of a stored ensemble, CA3-style recurrent feedback pulls activity into the nearest stable basin, and the completed engram returns as a coherent memory state.

**[Attractor](attractor.md) Memory** is a model of how the brain stores and retrieves learned patterns by encoding them as stable [attractor states](attractor.md) in the dynamics of [neural circuits](neural-circuits.md), such that partial or noisy inputs converge toward the stored pattern through the network's own [oscillatory](neural-oscillation.md) settling process. In the [Self-Aware Networks](self-aware-networks.md) framework, [attractor](attractor.md) memory is conceptually adjacent to the broader account of how [NAPOT](napot-overview.md) generates stable [perceptual representations](conscious-awareness.md) from the continuous interplay between [predictive feedback](predictive-coding.md) and sensory input.

[Attractor](attractor.md) networks differ from purely feedforward memory systems in that they exhibit [pattern completion](oscillatory-binding.md): a stored [engram](engrams.md) acts as a basin of attraction, and any input sufficiently similar to the stored pattern causes the network to settle into the full memory state. This property is closely tied to [Hebbian synaptic modification](hebbian-learning.md) — the strengthening of connections between co-active neurons — and to [long-term potentiation](long-term-potentiation.md) (LTP) that makes those co-active pathways more likely to reactivate together in the future. The [hippocampus](hippocampus.md), with its recurrent CA3 connections, is the canonical biological substrate for autoassociative [attractor](attractor.md)-style [memory retrieval](memory-consolidation.md), where partial cues reinstantiate complete [episodic memories](episodic-memory.md) via [theta-driven](theta-oscillations.md) recurrent reactivation.

In the [NAPOT](napot-overview.md) account, the stability of [attractor](attractor.md) states is not simply synaptic weight structure but also a function of the [tonic oscillatory](tonic-oscillation.md) background set by [neuromodulators](neurotransmitters.md). The dominant [oscillatory frequency band](brain-rhythms.md) at a given moment determines which [neural arrays](neural-array.md) can enter a coherent settling regime, and [phase wave differentials](phase-wave-differential.md) across arrays modulate which stored patterns are accessible. [Synaptic plasticity](synaptic-plasticity.md) mechanisms — including [vesicle release modulation](synaptic-vesicle-release.md) via [action potential duration](action-potential-duration.md) — continuously update the [attractor](attractor.md) landscape, allowing [neuroplastic](neuroplasticity.md) shifts in memory storage without erasing existing stable states. The interplay between [inhibitory interneurons](inhibitory-interneurons.md) and excitatory [pyramidal cells](pyramidal-cells.md) in [cortical columns](cortical-columns.md) provides the local recurrent architecture through which attractors are physically realized.
