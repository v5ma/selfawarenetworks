# Early a0503-a0530 Obscure Argument Map

This page maps a fixed sixteen-source queue from the downloaded SAN repository. It begins by
recovering the strongest legitimate operation in each source, then states where literal period
wording must be qualified. Internal dates, Git fixation, source-family repetition, speaker
attribution, and present scientific evidence remain separate.

## The problem before the terminology

An embodied brain does not make decisions from information alone. Its current energy, body state,
learned structure, active memories, sensory evidence, attention, inhibition, and expected
consequences all change what it can do next. Nor does one identical spike erase everything that
happened before it. A neural event's consequence depends on the state of the sender, the timing and
waveform of the event, release at its terminals, and the state of its receivers.

The recovered chain is:

```text
metabolic, bodily, and ongoing neural state
-> learned dendritic, synaptic, and network disposition
-> new evidence and partial cues
-> state-dependent transmission and receiver transformation
-> updated self/world model and candidate actions
-> attention and inhibition alter route accessibility
-> action, returned consequence, and later memory change
```

Later SAN terms can connect to this chain only at their later verified dates.

## Constructive branches

### Energy constrains action without becoming willpower

`a0503z.md`, `a0526z.md`, and `a0527z.md` were trying to connect physical capacity to motivation and
choice. The source-faithful operation is broader than a dopamine or ATP reservoir:

```text
metabolic and bodily state
+ sleep, health, medication, stress, and task context
+ learned value and expected consequence
-> changing effort cost and candidate accessibility
-> possible action
```

This preserves the embodied constraint while keeping historical nutritional, supplement,
stimulant, and treatment claims out of current guidance.

### A current model changes when evidence arrives

Micah's part of `a0509z.md` asks how new evidence changes a prior perception. `a0510z.md` and
`a0521z.md` extend the question through association, abstraction, prediction, feedback, and
top-down/bottom-up interaction:

```text
prior model Y + new evidence X + current context
-> updated state Z
-> Z becomes part of the next prior
```

That is a genuine ancestor of [[state-relative-differential-neural-write-in]] and
[[memory-prediction-rendering-sequence]]. It is not backdated as PWD, and `X/Y=Z` is not retained as
a literal neural equation.

### Learned structure does not vanish into one identical pulse

`a0506z.md` and `a0523z.md` overstate storage and packet capacity, but their central question
survives: if dendrites, synapses, membranes, and recent history matter, how do their effects remain
consequential after a cell fires?

```text
learned morphology and synaptic state
-> dendritic and membrane transformation
-> timing, burst, waveform, terminal calcium, and release
-> receiver-specific postsynaptic change
-> multi-step network consequence
```

This is richer than an identical `Hi` without requiring a spike to contain the whole neuron's
topology. See [[synaptic-unreliability-mvr-2021]], [[flow-of-information-in-the-brain]], and
[[expert-data-structures]].

### Attention can select a self-model without hiding another observer

`a0511z.md` contains a durable branch beneath its speculative imagery: several learned self,
social, and counterfactual models can be partly active; attention and inhibition change which one
guides report and action. The active network performs the selection. It does not require another
secret person watching the alternatives.

This branch connects [[attention-hallucination-self-model-dissolution]],
[[socially-internalized-inner-speech-self-model]], [[feedback-strange-loops-self-model]], and
[[memory-state-drift-virtual-mind]].

### Memory stabilization is multiscale

`a0512z.md`, `a0529z.md`, and `a0530z.md` can be repaired without losing Micah's central concern:
information must become a physical change that can outlast the initiating event. The current
evidence supports a distributed process:

```text
activity and coincidence
-> synaptic tags and local biochemical change
-> receptor, cytoskeletal, and spine remodeling
-> protein-synthesis-dependent stabilization under some protocols
-> ensemble and systems-level reorganization
-> later cue-dependent reinstatement
```

A plasticity-related protein participates in stabilization but is not itself a complete memory,
does not become a new genetic sequence, and is not copied from a learned synapse into sperm.

### Physical information and artificial neurology

`a0524z.md` preserves the anti-dualist operation: information becomes causally relevant only through
a physical system. `a0525z.md` turns that premise into an engineering program: study biological
receive-transform-project organization, build bounded read/write interfaces, distinguish an
external cortex coupled to a person from an autonomous artificial brain, and test each claimed
capacity rather than presuming selfhood.

## Matching scientific evidence

- [Hove et al. 2015](https://doi.org/10.1016/j.nicl.2015.05.005) measured postural sway and
  cerebellar-volume association in a small adult ADHD sample. It supports a bounded motor marker,
  not camera diagnosis.
- [Polanco et al. 2018](https://doi.org/10.1016/j.celrep.2018.01.085) and
  [Sardar Sinha et al. 2018](https://doi.org/10.1007/s00401-018-1868-1) support extracellular-
  vesicle transport of tau- or amyloid-related cargo under specified experimental conditions.
- [Dias and Ressler 2014](https://doi.org/10.1038/nn.3594) reported odor-specific intergenerational
  effects and sperm-gene methylation differences. It did not demonstrate synaptic-memory transfer.
- [Frey and Morris 1997](https://doi.org/10.1038/385533a0),
  [Matsuzaki et al. 2004](https://doi.org/10.1038/nature02617), and
  [Bosch et al. 2014](https://doi.org/10.1016/j.neuron.2014.03.021) support synaptic tagging,
  activity-dependent spine change, and staged molecular remodeling during LTP.
- [Kurniawan, Guitart-Masip, and Dolan 2011](https://doi.org/10.3389/fnins.2011.00081) organizes
  dopamine evidence around effort cost and action value rather than a finite willpower reservoir.

These are neighboring component findings, not automatic validation of the complete SAN synthesis.
