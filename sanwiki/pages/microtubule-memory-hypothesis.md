# Microtubule Memory Hypothesis

The **Microtubule Memory Hypothesis** proposes that history-dependent states of neuronal microtubules contribute to the persistence or retrieval of learned information. This is a candidate extension of established cytoskeletal participation in neuronal structure and plasticity. It is not established that microtubules form an autonomous memory store, encode semantic content, or contain a conscious observer.

## Established substrate and proposed extension

Microtubules are established components of axonal and dendritic architecture, intracellular transport, neuronal polarity, and dynamic remodeling. Growing microtubule ends can transiently enter a subset of actin-rich dendritic spines and influence experimentally measured postsynaptic organization ([Jaworski et al., 2009](https://doi.org/10.1016/j.neuron.2008.11.013); [Hu et al., 2011](https://doi.org/10.1523/JNEUROSCI.2445-11.2011)).

The memory hypothesis adds a stronger proposition: some microtubule state is written by experience, remains stable enough to matter, and is later read by cellular machinery to reconstruct or bias a learned response. Evidence for transport or structural support alone does not prove that chain.

## Required causal chain

A defensible microtubule-memory result should establish:

`learning event -> specific microtubule state -> persistence -> cellular readout -> selective neural consequence -> behavioral effect`

Each arrow needs an intervention. General cytotoxicity, impaired transport, altered arousal, or broad synaptic disruption cannot distinguish a memory code from infrastructure required by many cellular functions. A strong test should preserve ordinary neuronal viability while selectively changing the proposed state, then restore the predicted cellular and behavioral consequence through rescue.

## SAN position

SAN does not need microtubules to be a second nervous system inside the neuron. The bounded SAN interpretation is that microtubule-dependent state may modulate the slow preparation of a receiver: what reaches a dendritic or axonal compartment, which synapses are structurally supported, and how later signals are transformed. This can participate in distributed memory without making one molecular lattice the location of a whole memory or the observer of a rendered percept.

The hypothesis is separate from [[orch-or|Orch OR]]. A classical cytoskeletal contribution to plasticity could be real even if quantum-consciousness claims fail. Conversely, a quantum-optical effect in purified tubulin does not establish a memory code.
