## Prediction becomes perceptual distinction

The strongest part of `a0433z.md` is not its period argument about Russell or its blanket denial of
choice. It is the compact claim that perception depends on learned expectations and relations that
make otherwise different sensory states usable as different things:

```text
learned history + present sensory evidence
-> state-dependent expectations
-> relational distinction among body, object, and sensory quality
-> prediction, report, or action
```

Rao and Ballard's predictive-coding model provides an earlier computational comparison: higher
levels predict lower-level neural activity, while residual errors travel forward. SAN later adds
the receiver-relative phase, waveform, embodied-action, and distributed-rendering questions. The
2012 note is evidence of Micah's development, not evidence that every percept is a literal inner
narrative or that predictive coding proves consciousness.

## From deterministic reaction to Choice

The source sequence shows a genuine refinement:

```text
2012: no uncaused inner chooser; action reflects learned relations
2013: remembered causal relations are projected into possible futures
2013: evidence accumulates toward a task-dependent commitment
2014: learned cellular criteria determine which transition becomes effective
2022: circuit routing, inhibition, PWD, action, consequence, and criteria update are joined
```

This is compatible with a physically lawful system. The later Choice operator does not restore a
homunculus; it asks which dendritic, circuit, population, and embodied conditions explain a
measurable transition. Gold and Shadlen's accumulation framework and later single-trial work
provide established comparison models. SAN has an additional burden only where phase-compatible
PWD features are claimed to improve prediction or control beyond rate, power, anatomy, and standard
state-space variables.

The physiological bridge from `a0452z.md` is:

```text
learned criteria + current state + coincident evidence
-> receiver and circuit threshold transitions
-> premotor and motor-pool recruitment
-> motor-neuron action potentials
-> acetylcholine release at neuromuscular junctions
-> muscle-fiber action potentials and calcium release
-> ATP-powered actin-myosin contraction
-> movement or vocal action
```

Neural electrical activity organizes the control signal. It does not provide the chemical energy
used by contracting muscle.

## Synapse-centered transformation before PWD and APME

`a0449z.md` is an important 2014 bridge because it rejects a context-free scalar spike model and
places coincidence-sensitive transformation at the dendrite and synapse:

```text
dendritic morphology + receptor and membrane state + temporally structured input
-> nonlinear local integration and threshold event
-> spike timing, burst structure, duration, and waveform
-> terminal calcium and release state
-> receiver-specific postsynaptic effect
```

Current physiology supports each bounded stage. Dendrites can detect coincident inputs and generate
bursts; presynaptic voltage and action-potential waveform can modulate calcium entry and transmitter
release. The SAN extension is that a typed, receiver-relative combination of these variables carries
information needed by PWD/APME and Neural Rendering. That extension needs held-out prediction and
selective perturbation, not only similarity of vocabulary.

## Receptors, ATP, and experience

The multi-speaker `a0448z.md` discussion contains a productive distinction that became clearer in
later SAN work: a chemical's name is not the experience. Effects depend on which receptors are
engaged, where they are expressed, the cell's intracellular and membrane state, network context,
and subsequent action and feedback.

ATP requires an explicit two-role boundary:

1. intracellular ATP is a metabolic energy carrier used by cellular work; and
2. extracellular ATP can act at purinergic receptors as a transmitter or cotransmitter.

These roles are biologically connected but not interchangeable. A ligand that activates a receptor
does not thereby become an endogenous neurotransmitter, and receptor plasticity is not the same as a
receptor reshaping itself to fit an introduced drug.

## Memory, body model, and instrumentation

`a0434z.md` correctly identifies Hopfield attractors as a computational memory model and asks how
an active neural state relates to a longer-lived memory substrate. The strongest modern form keeps
three layers separate:

```text
durable synaptic, cellular, and circuit constraints
-> cue-dependent ensemble reactivation
-> transient population trajectory used for recall, prediction, or action
```

Macroscopic EEG or MEG can constrain models of large-scale current organization, but it does not
uniquely reveal the microscale state. Deep-source inference, including thalamic inference, is
possible only under declared head models, source assumptions, signal quality, and validation.

`a0450z.md` supplies a body-model comparison route. In the cited primate experiment, congruent
virtual touches altered responses in somatosensory and motor cortex, supporting a dynamically
updated multisensory body schema. It does not show that vision and touch are identical codes or that
one region contains the whole body model.
