# 2021-2023 Audio Transcripts

This folder contains 237 transcript files selected from the 2026 transcript review under the owner's explicit publication instruction. It includes records classified as low risk or medium risk and excludes every high-risk review status.

The recordings are primary-source material. Dates, speaker attribution, and quotations require independent verification against the original audio before use as evidence.

`MANIFEST.csv` records the filename, recorded date, selection status, and SHA-256 hash for each file.
