# Phase Reset

**Phase Reset** is the [Self-Aware Networks (plural)](self-aware-networks.md) term for the abrupt re-alignment of an ongoing neural [Tonic Phasic Neural Oscillation](tonic-phasic-neural-oscillation.md) when an incoming signal forces its phase to a new value. Within SAN, it is the mechanism by which prediction errors, [Sharp Wave Ripples](sharp-wave-ripples.md), and long-range thalamic and hub-cortical pulses re-coordinate a [Brain As Spectral Graph](brain-as-spectral-graph.md) population that would otherwise drift. It is the dynamic-side companion to [Neural Ensemble Phase Reset Communication](neural-ensemble-phase-reset-communication.md) and the [Dominant Phase Wave Differential](dominant-phase-wave-differential.md) / [Dominant Phase Wave Differential Rhythm](dominant-phase-wave-differential-rhythm.md) machinery used elsewhere in the wiki.

## Post-SAN

Mainstream [Neuroscience](neuroscience.md) already treats phase reset and oscillatory re-alignment as measurable events. The empirical literature on hippocampal [Sharp Wave Ripples](sharp-wave-ripples.md), [Gamma Oscillations](gamma-oscillations.md) / theta-gamma cross-frequency coupling, [Cortical Traveling Waves](cortical-traveling-waves.md), and the Fries / Lakatos communication-through-coherence program is the converging evidence base. Buzsaki and Draguhn's 2004 review argues that network oscillations bias input selection, temporally link neurons into assemblies, and support synaptic plasticity ([PubMed](https://pubmed.ncbi.nlm.nih.gov/15218136/)). Fries's 2005 communication-through-coherence hypothesis gives the cortical communication frame ([DOI](https://doi.org/10.1016/j.tics.2005.08.011)), and Schroeder and Lakatos's 2008 review describes low-frequency oscillations as rhythmic excitability states that attention can entrain to task-relevant input streams ([PubMed](https://pubmed.ncbi.nlm.nih.gov/19012975/)).

The [Self-Aware Networks (plural)](self-aware-networks.md) reading converges on those results but does two things the published literature tends not to. First, it treats phase reset as the coupling event that makes the [Oscillating Network Of Oscillators](oscillating-network-of-oscillators.md) picture mechanistically real: where mainstream papers describe phase reset as a correlate of [Attention](attention.md) or memory encoding, SAN treats it as the operation by which a [Neural Ensemble Phase Reset Communication](neural-ensemble-phase-reset-communication.md) event re-aligns a [Dominant Phase Wave Differential](dominant-phase-wave-differential.md) across populations and updates the [Brain As Memory Prediction Machine](brain-as-memory-prediction-machine.md) state. Second, the `a0309z--md` extension - phase reset entrains metabolism through [Hippocampus](hippocampus.md) to hypothalamus connections - is the testable wedge: SAN predicts that phase-reset signatures should be visible not only in EEG/[Fnirs Brain Imaging](fnirs-brain-imaging.md) time-locked to ripples but also in slow physiological variables such as glucose and autonomic rhythms.
