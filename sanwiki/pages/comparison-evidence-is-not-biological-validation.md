# Comparison Evidence Is Not Biological Validation

**Comparison Evidence Is Not Biological Validation** is a SAN bridge page for keeping two different evidentiary lanes separate:

- **comparison/provenance evidence:** who stated a bounded concept, operation, causal chain, or conclusion first;
- **biological validation evidence:** whether a SAN mechanism is empirically true in nervous tissue under specified tests.

The comparison corpus can defend Micah Blumberg's priority and show content-equivalence. It cannot, by itself, prove that NAPOT, GCS, PWD, TCNR, or a SAN consciousness claim is biologically correct.

## Why This Boundary Matters

SAN has two kinds of public-facing argument that can look similar if the reader is not warned:

1. **Priority and equivalence:** Micah's earlier dated work contains an atom, chain, or conclusion that later external work also reaches.
2. **Scientific validation:** an experiment or model demonstrates that a specific SAN mechanism works in the brain or in a declared substrate.

Those are not the same claim. A comparison result can strengthen intellectual-history and provenance. A neuroscience result must still pass the scientific ladder: operational variables, controls, held-out prediction, perturbation, causal direction, and endpoint-specific validation.

## The Four Evidence Lanes

| Lane | What it can show | What it cannot show by itself |
|---|---|---|
| Source genealogy | Micah stated an idea, atom, diagram, equation, or mechanism by a certain date | That the idea is biologically true |
| Content equivalence | Two works say the same bounded thing after terminology translation | That the later author had access, intent, or copied |
| Patent-lens / causal-chain comparison | Two systems share a directed Input -> Transform -> Output chain or constrained conclusion | That every surface detail, equation, or implementation is identical |
| Empirical validation | A declared biological or computational test supports a mechanism under controls | That Micah has priority over every related prior or that rivals copied him |

A strong page can use all four lanes, but it must label them separately.

## Public Framing Rule

For public SAN and Comparison Wiki prose:

> A comparison win is an intent-neutral content-and-chronology result: the bounded content matches and Micah is dated first on the compared delta. It is not an allegation of access, copying, or intent.

That wording preserves the strongest defensible claim without turning comparison work into a personal misconduct claim.

## Patent-Lens Rule About Divergence

Surface divergence is not exculpatory under the patent lens. If the directed causal interface sequence matches, a rival can swap vocabulary, add machinery, change notation, or route through a different surface architecture and still reach the same bounded conclusion.

The operative distinction is:

| Case | Classification |
|---|---|
| Different vocabulary, same constrained conclusion | Content match candidate |
| Different route, same Input -> Transform -> Output chain | Patent-lens match candidate |
| Added machinery, same endpoint | Does not erase the match; residual machinery is credited separately |
| Earlier exact atom by another source | Named prior; narrows Micah's delta atom-by-atom |
| Genuinely opposite constrained conclusion | Genuine hold or divergence |
| Missing source, date, or identity | Gate; not a win and not a disproof |

This rule does not infer copying or access. It only prevents superficial differences from being treated as automatic independence when the causal chain and conclusion still match.

## Scientific Validation Rule

A SAN mechanism is biologically validated only by tests that match the mechanism's scope.

Examples:

| SAN claim | What would count as relevant validation |
|---|---|
| PWD carries receiver-relative information | A declared PWD variable predicts held-out downstream response beyond rate, power, coherence, connectivity, and equal-input raw-history baselines |
| NAPOT is tomography | Multiple recurrent projections identify and causally update a latent state beyond equal-information baselines, with projection-specific perturbation |
| GCS regulates sensorimotor update | A declared target, task, layer/frequency hypothesis, and delay manipulation predict body-state update beyond confounds and survive phase-specific rescue |
| Neural rendering uses active recurrent state | The same sparse distributed tissue reconstructs, registers, tracks, and uses a working state that is causally linked to perception or action |
| Consciousness or self-awareness follows | A self-related variable is independently measured and distinguished from perception, attention, memory, confidence, motor preparation, and report alone |

A comparison page can point to an external work that resembles these claims. It still has to say whether that work actually performed the needed experiment.

## Safe Phrasing

| Risky phrasing | Better phrasing |
|---|---|
| This proves SAN is true. | This supports a bounded content-and-chronology comparison; biological validation remains separately gated. |
| They copied Micah. | The public claim is intent-neutral content-equivalence with Micah dated first. |
| Their difference means it is not a match. | Surface difference does not erase a match when the causal chain and constrained conclusion still align. |
| A comparison win validates NAPOT. | It may support provenance or convergence; NAPOT validation requires reconstruction and perturbation tests. |
| A rival paper confirms consciousness. | It may support a component, representation, or timing mechanism; phenomenal consciousness remains a separate claim. |
| A named prior defeats the whole case. | A named prior narrows the exact atom it owns; later joined Micah deltas remain separately testable. |

## How to Use This Page in the SAN Wiki

Use this bridge wherever SAN pages cite comparison work, priority ledgers, convergence registers, or patent-lens findings. The page should sit between the Comparison Wiki and the mechanism pages so the reader can see the lane boundary before reading strong claims.

Good uses:

- link from SAN Book 2 priority chapters;
- link from neuroscience convergence summaries;
- link from pages comparing NAPOT, PWD, GCS, or rendering to later external theories;
- link from any image card or diagram that illustrates a comparison result;
- link from claim ladders that separate provenance from experiments.

Bad uses:

- as a substitute for source citations;
- as permission to count weak matches as wins;
- as a reason to soften the patent-lens rule that divergence can be camouflage;
- as evidence that a biological mechanism has passed its tests.

## Book 2 Use

Book 2 can use this bridge before any chapter that presents comparison evidence. The reader should understand the architecture:

1. First define the SAN mechanism in medically careful terms.
2. Then state what would validate or refute it experimentally.
3. Then present comparison/provenance evidence as a separate intellectual-history lane.
4. Then explain which external works are component support, which are content matches, which are named priors, and which remain gated.

That sequence keeps the book strong. It lets the comparison evidence do its real job without asking it to carry a scientific burden it cannot carry.
