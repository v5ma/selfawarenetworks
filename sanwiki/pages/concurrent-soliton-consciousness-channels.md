The **concurrent soliton consciousness channels** hypothesis proposes that the brain runs four distinct physical wave substrates simultaneously — electric-field solitons, magnetic-field solitons, longitudinal acoustic solitons, and chemical waves — each carrying the same information in parallel and maintaining phase alignment across all channels at all times.

## Core Claim

Rather than a single dominant medium, four wave types co-propagate and stay aligned:

1. **Electric-field solitons** — fast; candidate substrate for visual processing.
2. **Magnetic-field solitons** — co-propagate with electric field as unified EM phase.
3. **Acoustic/mechanical solitons** — longitudinal waves through fluid; candidate "audio consciousness."
4. **Chemical waves** — molecular propagation (metabotropic cascades); slower but persistent.

All four channels represent the same [[phasic-tonic-relationship|phase patterns]] simultaneously. They are not separate minds but parallel physical encodings of one unified signal — "all four different soliton fields are going to be happening simultaneously and they're all going to be perfectly aligned" ([[gh-b0073y|b0073y]], ~27:31).

## Connection to SAN Framework

This model extends [[napot]] by providing four concurrent physical implementations of the same oscillatory phase structure. The 4-state phase encoding (inhibited / tonic / low-phase / high-phase) described in [[phasic-tonic-relationship]] and [[four-dimensional-phase-tracking]] can be simultaneously embodied in all four substrates, making the representation more robust and cross-modal.

The metabotropic / ionotropic distinction (Andrew Watson, NeuraLace Podcast S1E3) maps onto this directly: ionotropic receptors handle fast ion-channel signals (electric), while metabotropic receptors mediate chemical cascades — two of the four channels expressed at the receptor level.

## Color Perception as Phase Comparison

The same source frames color perception as the brain computing **contrast comparisons within a phase field**: "color is a different frequency, but the frequency to your brain is just a difference, relative to everything else." Color emerges from comparing phase contrasts, not from fixed frequency labels — consistent with the multi-channel model where each substrate contributes a phase comparison and the aggregate is perceived as hue.
