# Thalamocortical Network

> **Boundary note (2026-07-18):** The thalamocortical network is an established family of reciprocal thalamus-cortex circuits, not one uniform hub that literally renders consciousness. SAN can use it as a bridge for relay, gating, recurrence, attention, state control, and timing hypotheses, but claims must stay nucleus-, pathway-, modality-, layer-, state-, and measurement-specific. See [[san-scale-ladder-and-claim-boundaries]], [[thalamic-cortical-loop]], and [[phase-language-firewall]].

**Thalamocortical Network** names the reciprocal circuit family connecting thalamic nuclei with cortical areas. In established neuroanatomy, different thalamic nuclei have different roles: sensory relay, motor coordination, attentional modulation, arousal and state regulation, limbic participation, and higher-order corticocortical routing through thalamic loops. The useful SAN version starts from that diversity instead of treating the thalamus as one generic switchboard.

## Established Base

The medically safe base claim is that many cortical areas participate in closed thalamocortical and corticothalamic loops. These loops can regulate gain, timing, attention, sleep-wake state, sensory routing, and recurrent cortical dynamics. They are not interchangeable: a visual relay nucleus, a motor-related nucleus, an intralaminar nucleus, and a higher-order association nucleus cannot be swapped without changing the claim.

## SAN Interpretation

Within [[self-aware-networks]], the thalamocortical network is a bridge between partial sensory state and recurrent cortical updating. SAN/NAPOT can ask whether relative timing, oscillatory phase, tonic/phasic state, and corticothalamic feedback help determine which signals become part of an integrated working model. That is a hypothesis about bounded circuits, not automatic proof of a unified conscious display.

## Reader Boundary

When this wiki links thalamic relay, display-screen, convergence-zone, bridge, artificial-perception, and AGI-module pages, read them as different layers:

1. Established anatomy: named thalamic nuclei, cortical targets, and reciprocal projections.
2. Established physiology: measured relay, gating, burst/tonic firing, rhythms, attention, and state effects.
3. SAN interpretation: NAPOT/GCS timing, rendering, convergence, and phase-differential hypotheses.
4. Engineering analogy: BCI, artificial perception, and AGI routing proposals inspired by the biological motif.

A strong Book 2 treatment should keep those layers visible on the page instead of letting "thalamus" become a placeholder for every integration function.
