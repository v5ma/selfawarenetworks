# Engram

An **engram** is the lasting biological change produced by learning that helps a later cue recruit
memory-related neural activity. Modern experiments support learning-tagged cell ensembles, causal
reactivation, and distributed engram complexes. They do not establish that a memory is a literal
picture inside one neuron, that one fixed waveform contains the complete memory, or that
reactivation is automatically conscious.

Self-Aware Networks adds a testable proposal to that established base. Learned synaptic, dendritic,
cellular, and circuit state changes alter what later inputs can recruit. A cue can then activate a
partial ensemble, recurrent pathways can complete and transform the activity, and connected
populations can re-express a memory-guided state. SAN asks whether receiver-relative timing, phase,
waveform, inhibition, and other [[phase-wave-differentials|phase-wave differential]] variables
carry an invariant that improves this reconstruction. The further claim that a persistent or
dominant phase-wave-differential rhythm corresponds to conscious access is a separate, stronger
hypothesis.

## Five layers that must remain separate

### 1. Learning-induced substrate

Learning can change synaptic efficacy, spine structure, gene expression, intrinsic excitability,
and the probability that particular cells will participate in later activity. These changes are
physical constraints on retrieval. They are not a miniature stored scene and are not identical to
the experience of remembering.

### 2. Engram-cell ensemble

An engram-cell ensemble is a population whose learning-related changes and later reactivation
contribute causally to recall. In mice, optogenetic activation of hippocampal cells tagged during
learning can elicit context-specific fear-memory behavior. This establishes a causal contribution
from a tagged ensemble; it does not show that those cells alone contain every property of the
remembered event. [Liu et al., 2012](https://www.nature.com/articles/nature11028)

### 3. Cue-driven reconstruction

Retrieval is an active state transition. A partial cue interacts with present sensory input,
internal state, inhibition, and recurrent connectivity. The recruited network can perform
[[pattern-completion|pattern completion]] and generate a current memory-guided state rather than
read an unchanged file from one address.

### 4. Distributed re-expression

A single memory can recruit connected ensembles in several regions. In a mouse contextual-fear
preparation, simultaneous reactivation of multiple engram ensembles produced stronger recall than
reactivation of one ensemble. Different regions need not hold identical copies; their
contributions can be pathway- and function-specific.
[Roy et al., 2022](https://www.nature.com/articles/s41467-022-29384-4)

### 5. Conscious access

Memory-related activity can influence behavior without becoming a reportable experience.
Therefore, active substrate, successful retrieval, and conscious remembering cannot be treated as
synonyms. SAN's **Dominant Phase Wave Differential Rhythm** (DPWDR) is a proposed access criterion,
not an established property of engrams. It must be tested with conditions that separate memory
availability, behavioral use, report, and awareness.

## Scale ladder

| Scale | Medically bounded operation | What must not be inferred |
|---|---|---|
| Micro: synapse, dendrite, cell | Learning changes later response probability through synaptic, dendritic, molecular, and excitability mechanisms. | One spine, branch, or neuron contains or views a complete memory. |
| Meso: local ensemble and recurrent circuit | A partial cue recruits selected cells; excitation and inhibition shape completion, competition, and transition into a population state. | One canonical circuit or one oscillation is universal across memories and regions. |
| Macro: connected brain systems | Pathway-specific populations re-express complementary aspects that can guide perception, prediction, emotion, and action. | Every region stores an identical copy, or a single central region watches the result. |
| Phenomenal access | A retrieved state may become available for report and flexible action under additional conditions. | Reactivation, ripple occurrence, synchrony, or signal strength alone proves consciousness. |

The network itself performs the retrieval and its consequences. There is no internal screen and no
localized observer outside the participating biological process. See
[[memory-state-drift-virtual-mind|Memory, Engrams, Representational Drift, and the Virtual Mind]]
for the broader stability-plasticity problem.

## Source-faithful SAN genealogy

The SAN formulation developed in stages. The stages should not inherit terminology that appeared
only later.

- **June 8, 2022 - classical and attractor intake.** [[gh-a0434z|a0434z]] records Semon's latent
  physical-trace and reactivation vocabulary, then asks how an active memory state relates to
  Hopfield-style attractor dynamics. This is historical and conceptual intake, not a claim that a
  brain wave is the sole storage substrate.
- **June 10, 2022 - learned cellular readiness and group re-expression.**
  [[gh-a0079z|a0079z]] asks whether learned connectivity determines what a cell is tuned to
  "receive, identify, predict" and compares oscillating-group re-expression with a piano playing a
  learned sequence. The note itself warns that part of its anatomy is imprecise. The recovered
  operation is learned receiver state -> cue sensitivity -> selected cellular output -> group
  recruitment, not little eyes or a memory picture inside one cell.
- **June 12, 2022 - holographic-engram hypothesis.** [[gh-a0439z|a0439z]] introduces
  "Holographic Engrams" as distributed phase-pattern changes against tonic activity. Here,
  *holographic* is retained as SAN's partial-cue/distributed-reconstruction hypothesis. It is not
  optical holography or established whole-brain storage.
- **June 13, 2022 - sparse phase-differential proposal.** [[gh-a0638z|a0638z]] proposes that sparse,
  distributed departures from an ongoing oscillatory context can form an engram-like trace. This
  is the bridge from learned ensemble state to a receiver-relative phase hypothesis.
- **November 28, 2022 - mature PWD/DPWDR formulation.**
  [a0325zNAPOT6.md](https://github.com/v5ma/selfawarenetworks/blob/4e0cf1ee0975c01dc57182368497d3f0cd864030/a0325zNAPOT6.md)
  states the mature proposition: an engram may be treated as a PWD relative to tonic activity, and
  a conscious engram as a persistent or dominant DPWDR. The Git date fixes this formulation
  publicly; it does not make the biological proposition established.

This source ladder preserves the historical claim while correcting the generated page's earlier
identity statement. The engram is not currently known to *be* a PWD. SAN proposes that a
phase-relational description may explain variance in retrieval and access that ordinary
substrate, rate, ensemble, recurrent, and state-space models leave unexplained.

## Operational SAN model

The bounded mechanism is:

`learning-induced cellular change -> altered receiver readiness -> partial-cue recruitment ->
recurrent completion and competition -> pathway-specific distributed re-expression ->
memory-guided perception or action`

SAN adds a nested candidate:

`receiver-relative tonic context -> multidimensional local departure -> phase-compatible or
phase-separating population consequence -> changed recruitment and routing`

The second chain is useful only if its declared variables improve prediction or causal control
beyond the first chain. Coherence is not automatically success and dispersion is not automatically
failure. Both coordinated recruitment and structured separation may matter for preserving one
memory while suppressing competitors.

## Discriminating experiments

1. Track identified learning-related ensembles across encoding, delay, and cued retrieval while
   measuring spikes, local field potentials, behavior, movement, and arousal.
2. Compare held-out prediction from firing rate, ensemble identity, recurrent connectivity,
   attractor geometry, and receiver-relative phase/waveform models.
3. Perturb relative timing or coupling while approximately preserving spike count and mean firing
   rate; test completion accuracy, discrimination, confidence, and action.
4. Test partial cues that retrieve overlapping memories so recruitment and competitor suppression
   can be measured separately.
5. Separate successful behavioral use from reportable access before evaluating DPWDR.
6. Test whether the candidate phase relation survives cellular and rate drift better than simpler
   population codes.

The phase-relational engram hypothesis is weakened if its variables add no reproducible held-out
predictive value and no selective causal leverage beyond known plasticity, ensemble recruitment,
recurrent connectivity, firing rate, common input, movement, arousal, and task structure. The
DPWDR claim is weakened if the proposed dominance measure cannot distinguish conscious from
unconscious memory use under matched performance and state controls.
