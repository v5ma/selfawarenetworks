## Post-SAN

Mainstream literature occupies adjacent ground without using the same name. [[dendritic-computation|Dendritic computation]] work (Mel, Polsky, Larkum, Magee) treats the [[dendrite]] as a sub-cellular computational unit performing nonlinear pattern detection — see [[dendritic-computation-pattern-detection]] for SAN's engagement with that literature. SAN's specific addition is twofold: it widens the unit from "the [[dendrite]] as nonlinear summer" to "synapses + dendrites as a morphological pattern-classifier with receptor-level perception", and it generalizes the abstraction to non-neural cells via [[cells-as-pattern-recognition-devices]]. The `a0196z--md` extension — including extracellular RNA/DNA messengers in the EDS — moves further than mainstream dendritic-computation work, which typically restricts itself to membrane voltage and synaptic input. That widening is testable: it predicts that interfering with exosome / vesicle release in a specific dendritic compartment should change classification behavior in ways not predicted by voltage-only models.
