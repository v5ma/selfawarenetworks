# LTP

![LTP](../assets/generated/san/ltp/ltp-structural-memory-oscillatory-control-20260702-v1.png)

This plate shows the page's central mechanism: pre-before-post coincidence drives calcium accumulation, calcium thresholds separate LTD/no-change/LTP outcomes, LTP writes structural synaptic memory through spine and receptor changes, and SAN adds the phase-wave rule that oscillation timing gates whether the same input strengthens or weakens a memory trace.

**LTP** (Long-Term Potentiation) is the [self-aware-networks](self-aware-networks.md) entry for the synaptic-plasticity mechanism by which the connection between a pre- and postsynaptic neuron is durably strengthened, and within SAN it is treated not as a free-standing molecular event but as the structural-memory side of a [phase-wave-differential](phase-wave-differentials.md) account in which the [chemical-synapse](chemical-synapse.md), [dendritic-coincidence-detection](dendritic-coincidence-detection.md), [dendritic-morphology-memory](dendritic-morphology-memory.md), [ltp-bouton-synaptic-memory-traces](ltp-bouton-synaptic-memory-traces.md), [ltp-structural-memory-encoding](ltp-structural-memory-encoding.md), [ltp-tempo-spatial-rhythmic-memory](ltp-tempo-spatial-rhythmic-memory.md), [synaptic-computation-ltp](synaptic-computation-ltp.md), [synaptic-molecular-complexity-ltp](synaptic-molecular-complexity-ltp.md), and [kibra-pkm-zeta-memory-anchor](kibra-pkm-zeta-memory-anchor.md) machinery are *coordinated by* oscillation.
