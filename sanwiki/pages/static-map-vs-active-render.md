# Static Map vs Active Render

This page separates five things that SAN often has to discuss together:

1. the structural wiring map;
2. the stored biological substrate;
3. the active neural ensemble;
4. the reconstructed working content; and
5. conscious access to part of that content.

The distinction matters because SAN does not become medically stronger by treating these as one
thing. It becomes stronger when each claim names the biological denominator it actually uses.

## The core distinction

The connectome is a constraint map. It tells us something about which signals can travel where and
which populations can influence one another. It is not, by itself, the current percept, the current
memory, the current self-model, or the current conscious field.

An active render is a time-varying state. It depends on the connectome, synaptic weights, cellular
state, body state, sensory input, recurrent loops, oscillatory timing, and action context. SAN's
neural-rendering language belongs here: not in the wiring diagram alone, but in the living update
process that uses the wiring.

## Five variables that should not be swapped

| Layer | What it means | Example evidence | What it is not |
|---|---|---|---|
| Structural map | The relatively stable connection architecture: tracts, local circuits, synapse-level wiring where measured | Diffusion tractography, anatomical tracing, serial EM, circuit reconstruction | A complete record of current thought or perceptual content |
| Stored substrate | Durable biological changes that constrain later activity | Synaptic strength, receptor composition, spine state, molecular plasticity, glial/cellular state | The conscious memory itself |
| Active ensemble | The cells and populations recruited during perception, recall, action, or offline processing | Ensemble reactivation, population dynamics, oscillatory coupling, perturbation response | A fixed address where the object is stored |
| Working render | The current distributed model useful for recognition, prediction, report, or action | Decodable content, predictive use, behavior-linked state, recurrent stabilization | A state detached from the sparse distributed tissue that constructs and uses it |
| Conscious access | The subset of active content available for report, control, global update, or subjective access under a declared criterion | Report, choice, perturbation-linked access, TCNR/SAN criteria if tested | The whole connectome, the whole active brain, or every unconscious representation |

## Relation to existing SAN pages

[[connectome|Connectome]] is the structural anchor. Its strongest SAN use is not
"the connectome is the mind." Its stronger use is: the connectome is the wiring constraint that
makes stable recurrent rendering possible.

[[memory-state-drift-virtual-mind]] is the memory anchor. It already separates substrate state,
active ensemble, measured representation, content, drift, and conscious access. This page generalizes
that decomposition beyond memory.

[[perceptual-screen-neural-rendering]] is the render anchor. It identifies the perceptual screen with
the organized distributed process: the same field-cell system constructs, registers, and uses its changing state.

[[napot-overview|NAPOT]] is the proposed update-cycle anchor. NAPOT is strongest when it is framed as repeated
partial-state gathering, integration, projection, and update across declared scales.

[[tcnr]] is the formalization anchor. TCNR turns the rendering idea into a quantitative model with
latent-state estimation, coherence, counterfactual capacity, null classes, and held-out prediction.

## Why this matters for NAPOT

NAPOT can be misread in two opposite ways:

- too static: as if a fixed connection map already contains the rendered world;
- too mystical: as if a rendered world floats free from biological substrate.

The safer SAN position is between those errors:

> Structure constrains possible dynamics. Plastic substrate stores learned constraints. Active
> ensembles instantiate the current state. Recurrent rendering organizes that state into usable
> content. Conscious access is a further condition, not an automatic property of every active pattern.

## Medical and scientific boundary

Established neuroscience supports structural connectivity, recurrent processing, distributed
ensembles, plasticity, representational drift, predictive processing, and body-linked perception.
Those components do not automatically prove SAN, NAPOT, TCNR, or consciousness claims.

The SAN-specific claims begin when the page asserts:

- a particular receive-integrate-project update cycle;
- a phase-wave differential or dominance criterion;
- a tomography-like reconstruction operator;
- a cross-scale continuity rule such as NDCA;
- a conscious-access criterion such as DPWDR or a TCNR threshold.

Each stronger claim needs its own test.

## Reader rule

When reading or writing SAN pages, ask:

1. Is this sentence about structure, substrate, ensemble activity, working content, or conscious
   access?
2. Is the page describing established neuroscience, SAN interpretation, or a stronger unverified
   hypothesis?
3. Does the diagram or metaphor accidentally move a claim from one layer to another?

If the answer is unclear, the page needs a boundary sentence.

## Book 2 use

Book 2 should use this distinction before asking readers to follow NAPOT, GCS, NDCA, or TCNR. It
can state the architecture simply:

> A connectome is the map of possible roads. Plasticity changes the roads and their tolls. Active
> ensembles are the traffic. Neural rendering is the current coordinated route through the city.
> Conscious access is the part of that route the organism can use for report, planning, and global
> control.

That metaphor should be followed immediately by the biological version: wiring, synapses, ensembles,
recurrent loops, working model, access.
