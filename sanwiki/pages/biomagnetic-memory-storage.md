The hypothesis that biological magnetite (Fe₃O₄) in neurons and [[astrocytes]] contributes to memory encoding and retrieval at molecular and columnar scales. Post-Hameroff models treat this as classical biophysics rather than quantum-gravitational: columnar electromagnetic fields interact with magnetite crystals to form stable memory traces.

## Core mechanism

Neurons and [[astrocytes]] contain magnetite crystals. [[Neuronal-minicolumns]] generate columnar EEG magnetic fields that influence crystal alignment, encoding short-term memory at the molecular level. Long-term memory correlates with stable magnetite configurations that persist beyond active neural firing.

## Relation to SAN theory

In [[self-aware-networks]], information is encoded as [[phase-wave-differentials]] propagating across cortical columns. Biomagnetic fields offer a candidate substrate for persisting phase patterns between firing events — explaining how columnar patterns are "held" during working memory without continuous spiking.

The multi-scale framing (molecular → columnar → neocortical dynamics) aligns with SAN's core claim that brain information architecture is fractal across scales. See also [[statistical-mechanics-neocortical-interactions]].

## Distinction from Orch OR

Hameroff's [[orchestrated-objective-reduction]] proposed quantum gravity in microtubules as the consciousness substrate. The magnetite-memory literature is more conservative: classical biophysical mechanism, no quantum collapse required. The link to consciousness is indirect — via memory persistence, not quantum measurement.
