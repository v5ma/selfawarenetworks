# Multi-Scale Causality

**Multi-scale causality** asks when a cellular, circuit, body, task, or organism-level description does genuine causal work rather than merely summarizing the same physical process at a different resolution.

> **Scientific status:** A higher-level pattern does not acquire causal power merely because it has a useful name, and a lower-level intervention does not automatically explain the whole organism. Every causal claim requires a declared state map, a realizable intervention, a measured outcome, and controls for alternative routes. SAN proposes cross-scale organization; it does not introduce a nonphysical force acting downward on neurons.

## Levels are descriptions of implemented states

A goal, self-model, task context, or body state is not an object floating above cells. It is implemented by organized physical state across cells, circuits, body, and environment. A useful macro variable must be related to lower-level variables by a declared map:

\[
M=\Phi(X),
\]

where `X` is a specified microstate or distribution of microstates and `M` is the coarse-grained variable. Different microstates may realize the same `M`. The map must state what information is retained, what is discarded, and what outcome it predicts.

## Prediction is not yet causation

If a macro variable predicts behavior better than one recorded cellular variable, it may be a useful model. A stronger causal claim requires an intervention. For declared variables `X` and `Y`, a standard estimand is:

\[
\operatorname{ACE}_{X\rightarrow Y}
=\mathbb E[Y\mid\operatorname{do}(X=x_1)]
-\mathbb E[Y\mid\operatorname{do}(X=x_0)].
\]

An intervention at a higher descriptive level must map to realizable lower-level changes. The macro description earns stronger causal status when corresponding implementations produce sufficiently invariant outcome distributions across relevant micro-realizations. Rescue is especially useful when it restores the operation predicted to have been disrupted rather than bypassing it.

## Bottom-up, top-down, and lateral are map-relative

- **Bottom-up** can describe an identified influence from a lower or earlier level in a declared hierarchy.
- **Top-down** can describe an identified returning influence from a higher or later level.
- **Lateral** can describe interaction among units assigned to a similar modeled level.

These are not different physical forces. Axons, synapses, dendrites, inhibition, neuromodulation, body mechanics, and environmental consequences implement the influence. The same structure may be upstream for one variable and downstream for another.

## The basketball analogy, bounded

An inflated and deflated basketball behave differently despite being made from similar kinds of material. The relevant difference is organized pressure, shape, elasticity, boundary condition, and interaction with the ground. This illustrates why a macroscopic state can be an efficient explanatory variable.

It does not prove irreducible downward causation. A causal test must manipulate the relevant organization while controlling competing material changes and measure the predicted outcome. The macro description and physical implementation are complementary levels of the same system.

## SAN interpretation

SAN proposes a multiscale observer-action chain:

1. receptor, dendritic, synaptic, and cellular state changes local transitions;
2. local transitions alter population trajectories and effective routes;
3. distributed activity contributes to an embodied self-world model;
4. that model constrains prediction and action through implemented pathways;
5. action changes body and environment;
6. returning sensory consequences alter later cellular and network state.

The tonic canvas is the maintained network and body context against which consequential changes are registered. Phasic ink is the differentiated activity that changes receiver state and later action. Neither is an abstract agent controlling cells. The active field-cell-body loop is the proposed observer-action process.

## Evidence and limits

Formal work on causal emergence shows that, under a particular effective-information measure, some coarse-grained models can be more causally informative than a selected micro description ([Hoel, Albantakis, and Tononi, 2013](https://doi.org/10.1073/pnas.1314922110)). This demonstrates a mathematically defined possibility, not general experimental proof of downward causation in brains.

Neuroscience supports many implemented cross-level routes: pathway interventions can alter dendritic events, population activity, behavior, and learning. Those results remain pathway-, preparation-, task-, and outcome-specific. Similar organization across scales does not prove one universal fractal computation.

## Falsification contract

A SAN multiscale-causality claim narrows or fails when:

- the macro variable adds no held-out prediction beyond capacity-matched lower-level variables;
- its intervention cannot be implemented independently of confounds;
- different implementations assigned to the same macro state produce incompatible outcomes;
- a cellular perturbation changes a local measure but not the predicted circuit or behavioral endpoint;
- an apparent top-down effect is explained by common input, arousal, movement, or measurement reference;
- the same result is explained by an ordinary recurrent or control model without the proposed SAN variable; or
- scale language substitutes for a missing anatomical and causal route.
