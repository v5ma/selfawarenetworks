# Early a0352-a0372 Obscure Argument Map

This map records sixteen fixed-queue SAN sources. It preserves early collective-observer,
carrier-invariance, action-potential-output, Choice, dissipative-system, field-sensing, and BCI
arguments while keeping copied research, other speakers, internal dates, and later Git fixation
separate.

## Main result

1. `a0354z.md`, internally dated January 9, 2014, describes the brain as a movie watching itself:
   new sensory frames alter already active frames for prediction and action. Read without a literal
   frame rate, it is an early anti-homuncular recurrent-rendering statement.
2. `a0358z.md`, internally dated July 10, 2011, calls the self a collective of cells and
   consciousness a headline or summary of extensive unconscious processing. It strengthens the
   distributed-observer and conscious-access genealogy.
3. `a0359z.md`, internally dated December 30, 2012, explicitly says features are trans-neuronal
   patterns and that different neurons can realize a recognizable pattern, like a melody played on
   different keys. This is a strong carrier-substitution and relational-code ancestor.
4. `a0366z.md`, internally dated November 2, 2013, preserves a direct debate between Micah's
   whole-cell state-to-output proposal and Dean's spike-train, glial, ephaptic, and
   NeuroElectroDynamics comparison. It is an important source for APME and PWD development.
5. `a0372z.md`, internally dated February 22, 2014 and explicitly modified in June 2022, joins
   resonant routing, action-potential duration, coherence/decoherence, visual distinction, and
   receiver neurons as the system that reads prior activity.
6. `a0371z.md` preserves the 2019 Neural Lace/fNIRS program joining HEG/fNIRS, speech
   reconstruction, EEG-to-WebVR, PointNet, 3D Cross-Hair CNNs, Or Litany's work, and semantic
   co-registration of world, body, behavior, and brain measurements.

## The collective system watches by changing

The January 2014 `a0354z.md` phrase "a movie that is watching itself" and the July 2011
`a0358z.md` phrase "a collective of cells" describe the same anti-homuncular problem at different
times. The modern mechanism is:

```text
ongoing distributed state
+ new sensory, memory, and body-state differences
-> recurrent transformation
-> changed prediction, report, or action
-> returned consequence
```

The system observes because its own organization is changed and uses those changes. The historical
"ten thousand frames per second" is not adopted as a biological refresh rate. Consciousness as a
"headline" becomes a testable access claim only when the summary can be linked to report, flexible
use, action, and perturbation while extensive processing remains outside that access state.

## Carrier substitution and relational pattern identity

In `a0359z.md`, Micah states that features are represented across neurons and compares a stable
pattern with a melody playable on different piano keys. This anticipates a carrier-content
separation:

```text
different recruited cells
+ sufficiently preserved temporal-spatial relation
-> similar downstream recognition or action
```

This does not make patterns free of anatomy. Connectivity, receptor state, learned decoders,
modality, and task constrain which substitutions preserve function. The discriminating experiment
compares cell identity, firing rate, representational geometry, timing relations, and behavior
across controlled carrier turnover or remapping.

The source is multi-speaker. Ivan Pierre, Juan Carlos Kuri Pinto, Yan King Yin, and Micah each
contribute distinct category-theory, AI, recurrence, and neural-pattern arguments.

## Whole-cell state, output waveform, and the receiver

`a0366z.md` preserves a useful disagreement. Micah proposes that dendritic, synaptic, protein, and
other cellular changes must alter what a neuron sends. Dean replies that biological information is
not compressed into one context-free spike, emphasizes spike trains and extrasynaptic mechanisms,
and points to Dorian Aur's NeuroElectroDynamics as a related waveform/directivity proposal.

The strongest joined research question is neither scalar all-or-none coding nor an entire program
inside one pulse:

```text
cell morphology + synaptic state + membrane and ionic state + recent input
-> local dendritic events and spike initiation
-> timing, burst pattern, duration, waveform, axonal and terminal consequences
-> receiver-specific postsynaptic transformation
```

`a0372z.md` extends the same question through resonance and action-potential duration. It also
answers the viewer problem in distributed terms: subsequent neurons and populations are the
receivers changed by earlier activity. Coherence and dispersion can influence routing and
distinction, but a visual feature still requires stimulus, anatomy, state, learning, and downstream
effect rather than a frequency label alone.

## A field-sensing hypothesis with a measurable bridge

`a0360z.md` asks whether neural tissue can register patterns generated by its own electric or
magnetic activity and whether such internal patterns contribute to feeling or intuition. This is
preserved as a coupling problem:

```text
measured endogenous field pattern
-> identified cellular coupling mechanism
-> membrane, firing, or plasticity change
-> circuit and behavioral consequence
```

Electric-field and ephaptic effects, magnetic-field sensitivity, and ordinary synaptic common
drive must be measured separately. A successful test needs matched field perturbation, sham,
orientation or waveform controls, and a rescue or dose-response relation.

## The 2019 BCI semantic-co-registration program

`a0371z.md` is a dense public-program source. It connects Jonathan Toomim's fNIRS/HEG discussion,
speech reconstruction from auditory cortex, high-spatial EEG claims, the 2018 EEG-to-WebVR work,
Mary Lou Jepsen's Openwater proposal, EIT, PointNet, 3D Cross-Hair CNNs, Or Litany's point-cloud
work, and behavioral segmentation.

The joined engineering objective is:

```text
time-aligned 3D world and body model
+ neural, hemodynamic, and physiological measurements
+ segmented behavior and task events
-> registered multimodal dataset
-> held-out prediction of neural state, perception, or action
-> controlled write-back and measured consequence
```

This is a clear engineering ancestor of world-body-brain semantic co-registration and later NAPOT
measurement proposals. Each instrument still requires its own forward model, resolution, latency,
artifact, safety, and inference boundary.
