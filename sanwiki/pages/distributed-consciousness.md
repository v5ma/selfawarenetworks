**Distributed consciousness** is SAN's claim that observer-action is realized by the coordinated activity of a spatially distributed biological system rather than one anatomical point, module, neuron, or inner viewer.

## Distributed does not mean fragmented subjects

The useful claim is not that every neuron or cortical column contains a small consciousness. Cells and circuits have different sensory, memory, predictive, inhibitory, autonomic, and motor roles. A subset participates in a particular content or control cycle. The larger observer description applies only when those roles form a persistent causal organization that registers differences, integrates consequences, preserves relevant history, and changes possible action.

Terms such as **micro-observer**, **vote**, and **broadcast** are metaphors unless the page identifies:

- what each population measures;
- what state it transmits;
- which receivers can use that state;
- how conflicts are resolved;
- what body or task variable is controlled; and
- what perturbation should change the resulting behavior or report.

## Biological boundary

Distributed processing does not require every area to synchronize to one rhythm. Neural coordination can use spikes, inhibition, recurrent synaptic activity, traveling waves, oscillatory phase relations, neuromodulation, and changing effective connectivity at different spatial and temporal scales. Coordination can be transient and content-specific.

The participating boundary can also change with state and task. This is why one fixed brain-wide field, one cortical-column lattice, or one list of always-active nodes is medically implausible.

## SAN interpretation

SAN's strongest contribution is the positive no-homunculus account: the network's own receive-transform-re-express-use loops constitute the observer-action process. Tonic activity supplies receiver-relative context; phasic changes update that context; recurrent and embodied consequences determine which distinctions persist. Unity is a property to explain through coordinated causal use, not a separate object created after the distributed work is complete.

## Tests

A distributed-consciousness model should predict which contents survive selective disconnection, which routes are redundant, how local perturbations propagate, when reports and actions dissociate, and how function recovers. Phase-aware predictions must add value beyond anatomy, firing rate, recurrent population state, and movement.
