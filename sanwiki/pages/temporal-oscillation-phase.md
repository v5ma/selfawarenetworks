# Temporal Oscillation Phase

**Temporal Oscillation Phase** is, on the face of its name, the [[self-aware-networks|Self-Aware Networks]] term for the *phase* dimension of a [[gamma-oscillation|neural oscillation]] viewed *as a temporal coordinate* — i.e., not just amplitude vs. time, but the angular position within an oscillation cycle treated as a coding axis. In SAN this axis is the same one that carries the [[dominant-phase-wave-differential|DPWDR]] / [[phase-wave-differentials|phase-wave differential]] computation: a [[neural-array]] cell's response is conditional on the *temporal-oscillation-phase* at which its inputs arrive, not just on input rate.

## Position

In a [[self-aware-network]], oscillation is one of the three core variables that joint-encode the brain's instantaneous state — alongside [[synaptic-connections]] and [[dendritic-morphology|dendritic-threshold]] structure. The phase of an oscillation is, within the SAN reading, *the* dimension along which information is multiplexed. *Temporal oscillation phase* names the coordinate. Concretely: at any moment, a [[neural-array]] cell's [[apical-dendrite|apical-dendrite]] integration is gated by where, in the local [[gamma-oscillation|gamma]] / [[theta-oscillations-background-scripts|theta]] cycle, its inputs land; identical inputs delivered a quarter-cycle apart drive different outputs. This is the substrate of the [[oscillatory-binding-problem|binding-by-phase]] solution and of [[computational-phase-synchronization|computational phase synchronization]]. The same axis is what [[phase-precession|phase precession]] in the hippocampal literature codes along — phase relative to the local rhythm, treated as a temporal coordinate in its own right.

## Position — what the phase axis buys

The argument for treating phase as a *temporal* coordinate (rather than as a derived feature of a fixed-rate spike train) runs as follows. (a) A spike at phase 0 of the local gamma cycle and a spike at phase π of the same cycle are *both* "one spike per gamma cycle" by rate — yet they meet a different dendritic [[apical-dendrite|apical-integration]] window and join a different [[phase-wave-differentials|phase-wave differential]] coalition. (b) Two arrays running at the same frequency but offset by a phase Δφ form a different coalition than two arrays running at the same frequency *in phase*. (c) The [[cross-scale-oscillation-communication|cross-scale]] coupling that lets [[gamma-oscillation|gamma]] embed into [[theta-oscillations-background-scripts|theta]] is itself a phase-of-phase relation — high-frequency phase organized by low-frequency phase. None of these structures is visible if rate is the only coordinate; all are visible if temporal-oscillation-phase is treated as a first-class axis. SAN treats the axis as first-class and reads the [[dominant-phase-wave-differential|DPWDR]] as the global selector that picks which arrays are "in phase" at the moment.

## Position — substrate

The phase axis is implemented in the substrate by: (1) [[apical-dendrite|apical-dendrite]] integration windows that are shorter than a gamma cycle, so phase modulates summation; (2) [[chemical-synapse|synaptic]] release dynamics gated by [[synaptic-ion-channel-tone|ion-channel tone]] that itself oscillates; (3) [[traveling-waves-neural-oscillations|traveling waves]] that propagate phase across the [[cortex]]; (4) [[cortical-column-oscillatory-synchronization|column-scale oscillatory synchronization]] that locks within-column arrays into a shared phase; and (5) [[phase-attractor|phase attractors]] that pull the system back into a previously-visited basin. Together these implement the phase axis as a usable computational coordinate.

## Relation to mainstream framings

Phase coding is well-studied in mainstream [[neuroscience]] — [[phase-precession|phase precession]] in the [[hippocampus]], theta-gamma coupling, cross-frequency coupling, communication-through-coherence (CTC). SAN does not deny these findings; it makes the stronger structural move that the phase axis is the *primary* coordinate along which the brain's instantaneous content is encoded, with rate as a derived projection. *Temporal oscillation phase* names that primary axis. The SAN-distinguishing testable [[prediction]] is that experimentally controlled stimulation that varies *phase* relative to local rhythm while holding *rate* constant should reveal a phase-axis on dendritic responsiveness across many cortical regions, not just the [[hippocampus]].
