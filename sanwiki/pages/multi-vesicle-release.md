# Multi-Vesicle Release

**Multi-Vesicle Release** is the synaptic mechanism -- a single presynaptic [action potential](action-potential.md) triggering release of multiple neurotransmitter-laden vesicles into a single cleft -- that the [Self](gh-a0206z.md)-Aware Networks reading promotes from a neglected synaptic-physiology curiosity into a *channel-coding primitive*: an information-theoretically meaningful way for one neuron to transmit both amplitude *and* frequency content across a single connection, and the SAN-internal explanation for what mainstream neuroscience labels [synaptic unreliability](synaptic-unreliability.md). It threads into [multivesicular-release spatial-information](multivesicular-release-spatial-information.md), [multi-vesicle-release spatial-encoding](multi-vesicle-release-spatial-encoding.md), [multivesicular-release synaptic-unreliability](multivesicular-release-synaptic-unreliability.md), [dendritic MVR cognition](dendritic-mvr-cognition.md), and (at the cellular level) into [chemical synapse](chemical-synapse.md) and [3D protein-receptor](3d-protein-receptor.md) dynamics.

![Multi-Vesicle Release graded channel-code diagram](/v5ma.github.io/wiki/assets/generated/san/multi-vesicle-release/multi-vesicle-release-graded-channel-code-20260627.png)

This SAN image frames multi-vesicle release as a graded channel-code mechanism: spike width and calcium open time control whether 0, 1, 2, or 3 vesicles enter the cleft, changing neurotransmitter duration, receptor reach, and downstream phase weight. The comparison strip marks the page's boundary: classical rate coding emphasizes spike frequency, while the SAN MVR reading treats vesicle-count variation as signal rather than mere unreliability.

## Position

Within [Self](gh-a0206z.md)-Aware Networks proper, Multi-Vesicle Release asserts that the synaptic cleft is a *graded-output channel*, not an all-or-none one -- and that what the mainstream synaptic-unreliability literature reads as noise is, on the SAN reading, the *signal* of an MVR-driven multi-output structure (`b0267y--md`, line 274, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/b0267y.md)). The channel coding is keyed by spike width via potassium-channel kinetics -- longer action potentials open more calcium channels for longer, releasing more vesicles per spike (`b0114y--md`, line 63, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/b0114y.md)) -- which gives the postsynaptic side access to both the spike-time *and* the spike-width of the presynaptic event in a single transmission. ## Post-SAN

Compared with mainstream MVR / synaptic-unreliability literature -- which typically reads MVR as a quantitative refinement of quantal release theory (multiple vesicles per release-site rather than one) and treats the trial-to-trial variability as noise -- the SAN reading reframes MVR as a *channel-coding primitive*: variability in vesicle count is signal, not noise, and it carries spike-width information that mainstream rate-coding abstractions discard (`b0267y--md`, line 274, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/b0267y.md); `b0114y--md`, line 63, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/b0114y.md)). The structural prediction this generates is that synapses with high MVR variability should carry significantly more information per spike than rate-coding analyses estimate, and that experimental manipulations that artificially clamp the vesicle count (e.g., narrowing the AP width or saturating release probability) should produce information-rate deficits the noise-reading does not predict; see [multivesicular-release spatial-information](multivesicular-release-spatial-information.md), [multi-vesicle-release spatial-encoding](multi-vesicle-release-spatial-encoding.md), [multivesicular-release synaptic-unreliability](multivesicular-release-synaptic-unreliability.md), [synaptic unreliability](synaptic-unreliability.md), and [dendritic MVR cognition](dendritic-mvr-cognition.md). The SAN MVR-as-information-coding reading is also the sympathetic adjacent for the [criterial-causation](criterial-causation.md) / [dendritic coincidence-detection](dendritic-coincidence-detection.md) account of how the postsynaptic cell integrates the multi-output transmission.
