# Early a0088-a0104 Obscure Argument Map

## What this tranche recovered

Fifteen files in the fixed semantic-review queue were read as complete source bodies. The main
result is not a collection of isolated quotations. It is a set of older bridges into current SAN:

- emergence as a real higher-level regularity that is not yet a mechanism;
- model adequacy judged relative to a declared target rather than generic realism;
- sparse sequential rendering as a receiver-state process with no hidden viewer;
- belief confidence, compositional concepts, memory volatility, and carrier-content separation;
- fan-out as receiver-specific transformation rather than literal photocopying;
- attention and awareness as experimentally separable;
- cross-modal time alignment and explicit microtubule optionality; and
- reciprocal mechanical feedback from an enlarging spine to a presynaptic bouton.

## Two verified literature joins

`a0098z.md` points to the correct 2011 study. Watanabe and colleagues found robust attentional
modulation of V1 BOLD during binocular suppression while visibility did not produce a significant
V1 BOLD effect. That supports separating attention and awareness; it does not localize a unique
consciousness generator. [Watanabe et al., 2011](https://doi.org/10.1126/science.1203161)

`a0102z.md` points to the correct 2021 Nature paper. Ucar and colleagues found that enlargement of
a postsynaptic dendritic spine could push a presynaptic bouton, enhance SNARE assembly, and increase
glutamate release in a bounded preparation. This supports reciprocal mechanical participation in
synaptic plasticity, not a general mechanical code. [Ucar et al., 2021](https://doi.org/10.1038/s41586-021-04125-7)
