# Tonic Activity as a Candidate Predictive Reference Context

> **Scientific boundary:** Ongoing neural activity can shape responsiveness, expectation, attention, and sensorimotor state. It is not established that a standing theta rhythm is the brain's macro prior, that every phasic event is a prediction error, or that one power band is a universal reference frame.

## Established component science

Neural oscillations arise from several cellular and circuit mechanisms and vary across structures, behaviors, species, and recording scales. Predictive-processing models describe relations among expectations, sensory evidence, and updating, but the terms **prior**, **prediction error**, **oscillation**, and **reference frame** are not interchangeable.

A reference frame specifies what a variable is relative to. A tonic state is an ongoing receiver condition. A phasic event is a transient change. Any experiment joining these descriptions must show which variable is represented, which two signals or states are compared, and which receiver uses their relation.

## SAN hypothesis

SAN's tonic-canvas and phasic-ink proposal is stronger and more precise when stated as follows:

- **Tonic canvas:** a maintained population state that constrains how incoming changes affect that receiver.
- **Phasic ink:** a differentiated event or departure that changes the receiver and may propagate onward.
- **Predictive relation:** present only when a declared model, expectation, or state predicts a measurable input or consequence.
- **Reference-frame relation:** present only when a declared variable is encoded relative to an origin, orientation, object, body, landmark, or maintained state.

The same activity may participate in more than one role, but role identity cannot be inferred from frequency alone.

## Micro, meso, and macro scales

- **Micro:** membrane, dendritic, and synaptic state changes a neuron's response to input.
- **Meso:** a local circuit maintains task- and state-dependent population dynamics.
- **Macro:** recurrent cortical, thalamic, hippocampal, sensory, and motor systems coordinate selected relations over time.

These levels may interact without one identical oscillator or algorithm repeating at every scale.

## Discriminating test

A SAN-specific test should compare capacity-matched firing-rate, connectivity, recurrent-state, and predictive-processing models with a model containing the proposed receiver-relative tonic/phasic term. It must prespecify the carrier or measured signal, receiver, time window, represented variable, expected downstream effect, selective perturbation, failure mode, and rescue.

The null result matters: if ordinary recurrent state and movement variables explain the held-out behavior and intervention effects, the tonic-reference-frame phrase remains a useful hypothesis or metaphor, not an additional demonstrated mechanism.
