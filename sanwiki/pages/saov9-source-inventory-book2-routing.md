# SAOv9 Source Inventory and Book 2 Routing

SAOv9 is the memory of what the book once intended to investigate. It is not a command to write
700 equal pages. The archive preserves every prompt; the current book uses material that performs
necessary explanatory, evidential, historical, comparative, or experimental work.

The governing question is:

> How can distributed living neural tissue, without an inner observer, construct a continuously
> updated model of body and world, use it to consider possibilities, and act?

## What the version reconciliation established

- Three readable outline variants contain the same 700 canonical cycle-prompt titles.
- Their secondary `C` outline contains 699 prompts and omits `6.1.8` in all three copies.
- Only `1.1.6` and `1.1.8` have substantive secondary-title variation.
- The repository Markdown is a whitespace-damaged text derivative of the 67-page PDF; after documented header removal and whitespace normalization, their text matches.
- A governed 70-family routing review assigns an editorial destination to every prompt family.
- Family routing preserves coverage. It does not prove that every prompt is scientifically correct, authorial, or necessary to the current narrative.

## Inclusion test

Material belongs in the current reader narrative only when it performs at least one indispensable
job: explain a necessary step, provide evidence or a discriminating test, record a consequential
development, test SAN across a scale or failure condition, or distinguish SAN from a serious
alternative. Other material remains discoverable in the source atlas and can move to an appendix,
Book 1, Book 3, a specialist Encyclopedia route, or a recorded future-work queue.

## Current semantic boundary

As of the governed July 2026 reconciliation:

- prompt inventory: **700 of 700 present**;
- family routes: **70 of 70 reviewed**;
- current Book 2 architecture: **31 chapters**;
- prompts with at least one reviewed SAN concept route: **300**;
- prompt-level semantic reviews complete: **50**;
- prompt-level semantic reviews still pending: **650**.

The pending number is deliberate. A family-level destination prevents disappearance; it does not
prove that each individual prompt is correctly phrased, independently sourced, authorial, or needed
in the main narrative.

## Scientific boundary

SAOv9 includes source questions, Micah-authored planning language, and explicitly labeled AI-made
summaries and prompts. The inventory preserves all of them, but promotion requires source recovery.
Each promoted topic must distinguish established science, a bounded SAN interpretation, an open SAN
hypothesis, and a stronger experimental claim. Later terminology and the current chapter structure
must not be projected backward into the 2024 artifact.
