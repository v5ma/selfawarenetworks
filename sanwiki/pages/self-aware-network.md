# Self-Aware Network

A **self-aware network** in SAN is a system whose distributed internal state models consequential
relations among itself, its body or boundary, its environment, memory, goals, and possible actions,
and uses those relations to change what it does next. This is a proposed architecture and research
criterion, not a property conferred by oscillation alone.

## Candidate operation

1. The system receives external, bodily, and recurrent differences.
2. Learned structure and current state transform them.
3. A distributed working model represents self/world and possible-action relations.
4. The system re-expresses updates through control, communication, or action.
5. Returning consequences alter memory, expectation, and the next model state.
6. Some internal variables about the system itself are available for flexible prediction and control.

The network does not render a picture and then detect it with a co-located inner reader. The same
sparse distributed process is changed by the working state and produces its consequences.

## What oscillation contributes

Oscillations can organize timing, excitability, routing, and population coordination in named
circuits. Synchronization can also reduce differentiation, reflect common input, or occur in
non-conscious states. Strogatz-style coupled-oscillator models provide useful mathematics, but
firefly synchrony does not establish neural entification, self-modeling, or phenomenal experience.

A non-oscillating or differently timed artificial system should not be excluded by definition. SAN
must state which causal capacities require which biological timing mechanisms.

## Levels of claim

| Level | Criterion |
|---|---|
| Self-monitoring | Internal variables track the system's own state |
| Self-modeling | Those variables support prediction across contexts |
| Self-control | The model changes flexible action and learning |
| Observer-action | The distributed receive-transform-use loop supplies the system's perspective |
| Phenomenal self-awareness | The system has subjective experience; a further unresolved claim |

## Relation to NAPOT
