# SAN Wiki Knowledge Architecture Audit - 2026-07-17

This audit is a working map of the SAN Wiki as a knowledge system. It is not a publication claim,
not a Comparison Wiki verdict, and not a Book 2 manuscript edit. It identifies where the wiki already
has strong structure and where the reader still needs clearer bridges.

## Current structure observed

| Area | Current role | Architectural read | Main improvement need |
|---|---|---|---|
| `wiki/san/index.md` | Reader index and route hub | Strong broad front door; it now exposes source genealogy, core theory, Book 2 apparatus, and many source pages | Add explicit knowledge-architecture routes so readers can navigate by scale, evidence posture, and story arc |
| `wiki/san/home.md` | Landing page and vision | Useful for orientation and mission | Should stay lighter than the index; avoid overloading it with technical audit content |
| `wiki/san/theory/napot.md` | Core NAPOT theory page | Strong v2 boundary language; already separates components from added NAPOT claims | Needs a linked scale ladder so cellular, column, and macro renderings do not blur |
| `wiki/san/theory/oca.md` | Umbrella oscillatory agency page | Good bridge from molecule/cell/circuit/behavior | Status says `proof`, but content is mostly source-verified/theory; consider whether `governed-hypothesis` or `review` is safer |
| `wiki/san/theory/tcnr.md` | Cross-substrate neural rendering formalization | Important but conceptually downstream | Needs a reader bridge from NAPOT to TCNR so the formal TCI apparatus does not appear before the biological rendering problem |

| Gamma-as-content | GCS, PWD, rhythm pages | Gamma is a measured band/circuit operation; PWD is a receiver-relative SAN hypothesis |
| Microtubules as direct memory writing | CaMKII/microtubule pages | Keep microtubule spine entry/transport established, frequency-code writing unverified |
| One special percept neuron | NAPOT and object-rendering pages | No single neuron or location contains the complete percept |
| Comparison result treated as physiology | Comparison-to-SAN routes | Priority/equivalence is not biological validation |

## First synthesis

The SAN Wiki currently has enough material to support a cleaner reader architecture:

1. Start from the problem of active biological rendering, not from acronyms.
2. Introduce the scale ladder before the named SAN mechanisms.
3. Present established neuroscience components before SAN interpretation.
4. Treat NAPOT as a multi-scale hypothesis whose literal tomography status depends on declared
   scale and experimental identifiability.
5. Keep comparison evidence as a separate genealogy/provenance layer.
6. Use medically corrected images as explanatory aids, not as evidence of truth.
