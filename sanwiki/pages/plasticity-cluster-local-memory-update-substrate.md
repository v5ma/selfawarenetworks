# Plasticity Cluster: Local Memory and Update Substrate

This bridge page connects the SAN Wiki pages on CaMKII, LTP, LTD, BTSP, microtubule-linked
plasticity, and multivesicular release. The point is not to collapse them into one mechanism. The
point is to give readers a clean subsystem map for how local biological changes can constrain later
activity without becoming the whole mind, the whole memory, or proof of NAPOT.

## The subsystem in one sentence

Synaptic and dendritic plasticity provide local, pathway-specific ways for recent activity to change
future responsiveness; SAN interprets those changes as part of the slow substrate that recurrent
rendering and NAPOT-like update cycles can read from and write back into.

## Why this cluster matters for SAN

SAN needs a local update substrate. A theory of active rendering cannot only describe macro-scale
waves, cortical loops, or abstract information. It also needs mechanisms that can change future
responses at the level of spines, branches, synapses, boutons, and dendritic compartments.

This cluster supplies that bridge:

1. presynaptic output can be graded and modulated;
2. postsynaptic calcium and receptor state can detect activity context;
3. CaMKII and related pathways can convert transient signals into plasticity events;
4. LTP and LTD can alter future synaptic efficacy;
5. BTSP can update a representation over behavioral timescales in bounded CA1 preparations;
6. local translation, cytoskeleton, and synapto-nuclear routes can participate in longer consolidation;
7. those changed local constraints can bias the next active ensemble and working render.

That is enough to support a local substrate story. It is not enough to claim that SAN's full
oscillatory tomography mechanism is established.

## The correct scale label

This is a **micro-to-meso bridge**.

- Micro: receptors, spines, synapses, Ca2+, CaMKII, AMPAR/NMDAR, boutons, vesicles, local translation.
- Branch / compartment: clustered inputs, dendritic plateau signals, Ras/Ca2+ spread, branch-local resources.
- Meso: ensembles and local circuits whose population state changes because many local sites changed.
- Macro: whole-brain render or body-world model, which depends on many micro and meso changes but is not identical to any one of them.

Use [[san-scale-ladder-and-claim-boundaries]] when a page or diagram starts moving between these levels.

## Established biology vs SAN interpretation

| Claim level | Safe wording |
|---|---|
| Established background | Synaptic and dendritic mechanisms can produce pathway-specific, activity-dependent changes in future responsiveness. |
| Bounded empirical support | Specific preparations show CaMKII activation, LTP, LTD, BTSP, MVR, local translation, and cytoskeletal participation under declared protocols. |
| SAN synthesis | These mechanisms form a plausible local memory/update substrate for active rendering. |
| Stronger SAN hypothesis | Relative timing, phase, waveform, or receiver-specific effects may predict plasticity beyond rate, spike count, common input, and standard eligibility-trace variables. |
| Strongest SAN hypothesis | Local plasticity events participate in a reconstructive NAPOT/TCNR render loop with identifiable causal contribution to content or conscious access. |

## Non-claims

This cluster does not claim:

- one synapse stores one memory;
- CaMKII is a permanent memory molecule by itself;
- microtubules are established frequency-code storage tapes;
- LTP equals memory or consciousness;
- LTD equals forgetting in every pathway;
- BTSP is universal across cortex;
- MVR proves deterministic synaptic transmission;
- local plasticity proves NAPOT, TCNR, DPWDR, or consciousness.

## Book 2 use

Book 2 can use this cluster as the local biological foundation before moving into NAPOT, GCS, and
NDCA. A useful chapter sequence is:

1. Local update substrate: MVR, calcium, CaMKII, LTP/LTD, BTSP, local translation.
2. Circuit update substrate: dendritic branches, inhibition, ensembles, recurrent loops.
3. Active render: distributed working model constrained by changed local substrate.
4. NAPOT/TCNR: proposed reconstruction/update formalisms operating over the substrate.

That order prevents the reader from thinking SAN skips from molecule to mind without the middle
levels.
