A memory or concept does not reside at a fixed address in the brain — it **drifts**:
the neural correlates of the same idea appear in different regions depending on which
feature dimension (color, texture, sound, touch) is currently active. [[gh-resnote04|Micah]] frames
this as evidence that engrams are **virtual phase patterns**, not stored structures.

## Neural drift

When neuroscientists try to measure where an idea lives, they find it in different
places at different times. [[gh-resnote04|Micah]]'s explanation: multiple cortical areas each hold a
partial representation of the same concept biased by their dominant modality. The
somatosensory cortex represents a coffee mug via texture; the visual cortex represents
it via color. Both fire together when "mug" is activated, but neither is *the* memory —
the mug is the ensemble. Day to day, whichever modality is primed determines which
area's representation dominates → the neural correlate appears to move. See
[[napot]] for the tomographic view of why this ensemble is stable despite apparent drift.

## Engrams as bodies of oscillations

Everything identifiable is a **body of oscillations** whose size is proportional to
the brain area devoted to it (cortical magnification), not its physical size. A laptop
occupies more brain volume than a room because it demands more fine-grained
motor/perceptual processing. An [[engram]] — a phase pattern in the brain that
represents a specific object or experience — is therefore not a fixed cluster of
synapses but a *temporary intersection* of [[traveling-waves-phase-arrays|traveling
waves]] and phase arrays that sit waiting for incoming sensory streams.

## Information is virtual

Because sensory information is separate from the brain's general learning algorithm,
any region can in principle represent any information. The tongue-strip experiment
(teaching the tongue to see) illustrates this: representation is not anatomically
fixed. Information in the brain is virtual — its location is temporary, a function of
which phase arrays are currently resonating with the arriving traveling wave.

## Object segmentation link

[[gh-resnote04|Micah]]'s personal Salvia divinorum experience (loss of object segmentation — inability
to distinguish hand from table, floor from field) provides a phenomenal anchor: when
the mechanism that assigns distinct phase-pattern boundaries to objects fails, the
world collapses into an undifferentiated point field. Normal consciousness requires
active [[object-segmentation]] running continuously. See [[3d-semantic-segmentation]]
and [[consciousness-wave-magnification]].
