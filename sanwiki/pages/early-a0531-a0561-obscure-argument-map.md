This page maps sixteen early SAN sources without treating unusual wording as a reason to discard the
underlying research question. Each source is read first for its strongest legitimate operation. Its
internal date, first public Git fixation, copied material, speaker attribution, later terminology,
and current scientific status remain separate.

## The problem before the terminology

A brain is continuously changing. Cells integrate into old circuits, memories become hard to
retrieve, present input activates only part of a learned pattern, and the body must act before every
possibility can be explicitly reasoned through. A useful theory must explain how a distributed
network preserves enough continuity to recognize, predict, choose, and move without placing a small
viewer inside the head.

The early sources propose this constructive chain:

```text
partial sensory evidence and bodily state
-> learned relational readiness and predicted possibilities
-> distributed reconstruction rather than fixed-picture playback
-> the network itself acts as screen, projector, and viewer
-> inhibition and value change which route becomes effective
-> coordinated motor action and returned consequence
-> later structural and functional adaptation
```

Later SAN terminology makes parts of this chain more precise. It does not move those later names into
an earlier source that did not yet use them.

## The network is the observer

The most important line in `a0552z.md` is easy to mistranslate. The source does not place a little
viewer behind an internal picture. It says the cells are collectively the screen, the projector,
and the viewer. In current plain language:

1. receptors and lower pathways transform external and bodily events;
2. active and prepared neural populations carry partial, learned relationships;
3. recurrent interaction reconstructs a task-relevant self-world state;
4. the same distributed system uses that state to attend, predict, and act; and
5. action changes the next input.

Observation is therefore an operation of the network, not a hidden observer added to it.

## Meaning is relational

`a0552z.md` says that meaning is not wholly inside one node but in relationships among nodes. An
object acquires meaning through learned relations to position, texture, temperature, use, words,
memory, reward, and action. The source's vector and category language is an early attempt to state a
current computational problem:

```text
partial cue + learned relational structure + current task
-> recruited representation -> prediction or action
```

Later SAN terms can describe the temporal and receiver-relative signal details. The 2017 source
already establishes the relational and distributed architecture.

## Memory is reconstruction across changing tissue

`a0531z.md` asks whether inaccessible infant memories still have a recoverable physical trace and
whether their format differs from adult autobiographical memory. `a0532z.md` asks how memory survives
the integration of adult-born neurons. `a0553z.md` asks how compact physical constraints can recruit
a much larger active reconstruction.

The current joined answer is not a DNA copy or a photograph hidden in one molecule:

```text
multiscale physical trace
-> partial cue and present state
-> selective ensemble reinstatement
-> reconstructed content, confidence, report, or action
```

Mouse engram-reactivation studies show that some apparently inaccessible early memories can be
recovered under highly specific experimental conditions. Human infant imaging shows early encoding.
Neither result demonstrates a Neuralink-like extraction of a person's first years.

## Optical BCI was a real research question

`a0559z.md` proposes using near-infrared optical changes associated with neuronal firing rather than
assuming every useful fast signal requires a nearby implanted electrode. The wording is stronger
than the evidence, but the research direction is legitimate. Action potentials have measurable
mechanical and optical correlates, and fast optical signals have been investigated through the
scalp. The unresolved engineering question is whether those signals can be localized at useful
depth, speed, spatial resolution, and signal-to-noise ratio without confusing individual spikes,
population activity, motion, and hemodynamics.

## Prediction becomes action

The 2012 `a0560z.md` source treats intelligence as embodied prediction: sensory input changes
category-like populations, candidate expectations become more or less ready, inhibition limits
competing paths, and distributed motor systems convert the selected trajectory into action. Practice
then changes future performance through several plasticity mechanisms, including activity-dependent
myelination under bounded conditions. This is stronger and more accurate than either a purely
conscious reasoning story or a one-headshot-one-myelin story.
