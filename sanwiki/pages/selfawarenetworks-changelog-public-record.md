# SelfAwareNetworks Changelog as a Public Development Record

The SAN repository changelog is Micah Blumberg's dated, author-maintained account of changes to the
Self Aware Networks research program. It helps readers locate when a named note, whitepaper,
revision, source intake, or research direction entered the repository.

The changelog is useful provenance, but it is not sufficient by itself. A strict chronology joins
the changelog entry to the exact file, the relevant Git commit, and any earlier public recording,
article, archive capture, or platform metadata.

## What the changelog records

The file begins with later updates and proceeds backward through earlier repository development. It
records, among other things:

- additions and revisions to SAN and NAPOT notes;
- the development of QGTCD and related physics branches;
- the NAPOT revision sequence and 2022 whitepaper work;
- transcript, summary, and source-recovery work;
- book-organization plans and source-map files; and
- the later use of AI tools to summarize, route, and check an already large research archive.

The [current public changelog](https://github.com/v5ma/selfawarenetworks/blob/main/00changelog.md)
can be read alongside [[gh-00changelog|the SAN Wiki source mirror]].

## Verified repository chronology

The earliest currently verified Git commit that adds `00changelog.md` is
[`a5f25729d14bc8805cc6993fe99156bfb6351920`](https://github.com/v5ma/selfawarenetworks/commit/a5f25729d14bc8805cc6993fe99156bfb6351920),
dated August 26, 2022. Later commits show continuing modification through January 22, 2025.

That evidence supports the following narrow statement:

> A version of the changelog existed in the public repository by the dated Git commit.

It does not automatically establish that every event described inside the file occurred on the
date written in the prose. Event date, author-entered date, file commit, public publication, and
later synthesis remain separate fields.

## Preprint and peer-review boundary

In its January 22, 2025 entry, the changelog declares the repository a preprint and
journal-equivalent publication surface. That declaration records Micah's publication policy and
his intent to invite review, comments, and corrections.

For public scientific claims, the Wiki uses a narrower description:

- GitHub supplies public version history and useful timestamp evidence.
- A repository publication can function as an author-posted preprint.
- Repository publication is not independent peer review merely because the author invites review.
- A commit date supports repository chronology, not biological truth, experimental replication, or
  priority over every earlier source.

This distinction preserves the value of the public record without asking Git metadata to perform a
scientific role it cannot perform.

## AI and authorship chronology

The changelog records both pre-AI development and later AI-assisted organization. It says the
December 2022 work preceding the author's use of ChatGPT was difficult, substantial theory
development across neuroscience and physics. Later entries describe using ChatGPT and related
tools for summarization, book routing, and research comparison.

The January 5, 2024 entry also warns that AI-produced answers can be wrong and instructs readers to
return to the underlying SAN notes for verification. The correct provenance reading is therefore:

- the core research program has a recoverable pre-ChatGPT history;
- later AI output can help navigation, checking, mathematical formulation, and editorial work; and
- AI summaries are derivative aids, not independent scientific evidence or substitutes for Micah's
  source text.

## How to use the record

For a chronology claim:

1. locate the changelog entry;
2. open the named source file;
3. identify the exact wording or bounded claim atom;
4. recover the relevant commit or public platform date;
5. separate an early functional ancestor from a later mature term; and
6. evaluate scientific support independently from authorship and chronology.

This process prevents both underclaiming and overclaiming. Earlier SAN material is not erased
because later vocabulary became more precise, and later vocabulary is not silently backdated into
an earlier source that did not contain it.
