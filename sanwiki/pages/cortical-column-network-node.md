# Cortical Column Network Node

**Cortical Column Network Node** is the SAN reading of a [[Cortical-columns|cortical column]] as a node in a directed, learnable network — a unit of cortical computation that takes inputs from other nodes (other columns, thalamic afferents, modulatory loops), maintains internal state on its own [[cortical-column-manifolds|manifold]], and emits outputs that drive both nearby and remote columns. Where [[cortical-column-as-display]] reads the column as a rendering tile and [[cortical-column-manifolds]] reads it as a state-space, this concept reads it as a *graph element* — the per-column counterpart to whatever larger architecture (the [[Pattern-Propagation-Cascade]], the [[Convergent-Playback]] mesh, the thalamo-cortical loop touching [[thalamus-as-display-screen]]) is doing.

In SAN's framing the column-as-node has three signatures. Locally, it integrates afferents into a [[sparse-distributed-representation]] / [[sparse-distributed-representations]] / [[sparse-distributed-memory]] pattern via [[Hebbian-Learning]], [[Long-Term-Potentiation]], the [[NMDA-receptors]] / [[NMDA-receptor]] machinery, and [[Dendritic-compartmentalization]]. Laterally, it exchanges activity with sibling columns under [[Inhibitory-circuits]] / [[GABA]] competition, producing the cross-column dynamics that show up as [[cortical-traveling-waves]] and [[neocortical-dynamics]]. Globally, it participates in long-range edges — the kind that [[Jeff-Hawkins]] and [[thousand-brains-theory]] use to argue that many columns vote on a single percept — and these edges are what the SAN reading uses to explain how the same firing sequence in left and right [[Cortex|cortex]] can be a single experience even without dense direct wiring.

The "network node" framing knits the column lineage together. It generalises [[Cortical-columns]] / [[cortical-column]] / [[Neuronal-minicolumns]] / [[micro-column]] / [[micro-columns]] / [[microcolumns]] / [[columnar-organization]] from a list of repeat-units into a graph of typed nodes, lines up with [[fractal-cortical-column]] (where nodes are nested at multiple scales), feeds the [[grid-cells]] and [[neocortical-columns-grid-cells]] coordinate substrate that the network uses for spatial routing, and extends naturally to [[hippocampus-as-cortical-column]] where memory traces become walks on the column graph. Under top-down drive from [[Brainwaves|beta]] traffic ([[Phase-precession]]), the same nodes participate in [[Predictive-Coding]] inference; under bottom-up sensory drive they support the [[NAPOT]]-style observer formation the project locates in [[Consciousness]].
