# Autogenous Associative Memory and Reconstructive Retrieval

## The idea in plain language

A memory system does not need a new external command for every transition. A smell, image, word,
body state, or preceding thought can provide a partial cue. Recurrent neural activity reconstructs
a context-dependent state, and that state changes which memory, prediction, or action can follow.

```text
external or internal partial cue
-> state-dependent reconstruction
-> active memory or prediction
-> new internal cue and route bias
-> next reconstruction, simulation, or action
```

"Self-activating" does not mean that information acts without biology. It means the physical cue
for a later transition can be generated by the network's own preceding state.

## What neuroscience contributes

Recurrent associative networks can complete patterns from partial cues. Hippocampal sequences can
also be internally generated rather than simple copies of immediate experience. Dendrites are
active nonlinear compartments, and physiological spike-train timing can alter distal dendritic
backpropagation beyond what is predicted by the same mean firing rate.

These findings supply candidate operations. The stronger SAN claim is that one reconstructed state
becomes a typed control signal for the next transition through timing, phase, dendritic state,
recurrent routing, and receiver-specific transformation.

## How to test it

1. Decode whether each recalled transition is better predicted by the preceding internal state,
   an external event, or both.
2. Compare exact replay, static attractor, probabilistic reconstruction, and autogenous-sequence
   models on held-out episodes.
3. Perturb a candidate recurrent, dendritic, or corticothalamic route after one reconstruction and
   predict how the next-state distribution should change.
4. Reject the stronger SAN extension if internal-state variables add no information beyond sensory
   input, arousal, movement, and ordinary recurrent-network baselines.
