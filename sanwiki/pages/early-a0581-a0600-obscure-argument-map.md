# Early a0581-a0600 Obscure Argument Map

This page recovers sixteen SAN source notes as a connected research sequence. It keeps historical
wording, speaker attribution, chronology, and current scientific interpretation separate. The
purpose is not to make every old sentence literal. It is to preserve the problem Micah was trying
to solve and show how the strongest operation connects to later SAN work.

## The problem before the terminology

A living system does not receive a complete, labeled description of its world. It receives partial
changes through receptors, dendrites, membranes, sensory organs, and social signals. It must decide
which differences matter, relate them to memory and possible action, and change what it can do
next.

The sixteen notes repeatedly approach this sequence:

```text
partial physical difference
-> state-dependent detection
-> thresholded transformation
-> recurrent or oscillatory coordination
-> internal representation
-> selection and action
-> returned consequence
-> changed future state
```

The later SAN terms should be introduced only after this problem is understood. These sources are
ancestors, bridges, and in some cases mature 2022 formulations. They are not all the same date or
the same evidentiary kind.

## Dendrites detect enough, not everything

`a0587z.md` asks how a branch structure can recognize a learned pattern when only part of that
pattern arrives. In plain language, the neuron does not need to receive every possible detail. Its
branches and membrane state can make some combinations more effective than others. A sufficiently
matched partial cue can change whether the cell fires and therefore change the state of a larger
network.

```text
partial input across branches
-> branch-local nonlinear interaction
-> somatic and recent-state integration
-> threshold crossing
-> distributed downstream consequence
-> later completion, prediction, or action
```

The later SAN receive-transform-project vocabulary names the whole proposed route. It adds the
claim that the receiving configuration and the projected consequence should be measured as one
state-dependent transformation. It is not merely a new name for ordinary dendritic integration.

Read next: [[receptive-inceptive-dendritic-projection]], [[expert-data-structures]], and
[[autogenous-associative-memory-retrieval]].

## Artificial internal representation was already a 2012 problem

The November 2012 block in `a0600z.md` asks what it would mean for a machine to possess an internal
representation rather than only produce a statistical output.

The source distinguishes several steps:

```text
the system encounters an object or property
-> distributed activity changes
-> repeated relations make some reactivations more likely
-> a partial cue can restore a larger learned relation
-> the relation changes possible prediction and action
-> the system can use feedback to change later responses
```

The example treats an apple, a color, and a symbol as learned physical relations rather than
objects manipulated by an invisible inner agent. It also proposes an external brain that expands
the available workspace. Those are clear ancestors of later [[sensory-to-symbol-neural-grounding]],
[[artificial-neurology-states-stages-development]], and
[[extended-brain-thought-density-hypertime]].

## A distributed network observes by changing

`a0595z.md` uses screen and point-cloud language. Read literally, that language could appear to put
a viewer inside the brain. The source-faithful reading is the opposite.

The observer operation is distributed:

```text
cells receive differences
-> their states change
-> those changes alter other cells
-> the network re-expresses a structured relation
-> the relation changes prediction and action
```

There is no additional entity watching a screen. The network registers its own changes because
those changes alter the network's subsequent behavior. This is the route developed in
[[entification-observer-problem]], [[perceptual-screen-neural-rendering]], and
[[field-cell-self-bioelectric-information-entity]].

## Tonic context and informative change

`a0599z.md` states that a perceived difference can be represented relative to an ongoing tonic
state. A box edge, color boundary, motion change, or change in apparent size is not useful because
it has one universal frequency. It is useful because it changes a structured relation within the
current system.

In information-theoretic language:

- a stable context may be highly predictable and therefore carry low surprise per repeated event;
- a rare deviation may carry greater surprise relative to that context;
- the tonic state is still informative because it supplies the receiver's reference and
  conditional expectations;
- a high-frequency event is not automatically high information;
- phase, amplitude, duration, rate, spatial geometry, and receiver state must be tested
  separately.

This is an explicit source bridge to [[tonic-phasic-phase-wave-differential]] and
[[tonic-context-rare-deviation-tomographic-language]].

## Cells use clocks, gradients, thresholds, and feedback

`a0597z.md` joins several biological observations:

- gene-regulatory feedback can oscillate;
- concentration gradients provide positional information;
- receptors make cells selectively responsive;
- intracellular state changes movement, secretion, gene expression, and development;
- immune and neural cells follow different but physically implemented detection rules;
- body-wide sensing emerges from connected, interacting cells.

The strongest common operation is not "every cell is literally a neuron." It is:

```text
physical or chemical difference
-> receptor- and state-dependent detection
-> thresholded intracellular transformation
-> changed gene expression, secretion, movement, or structure
-> changed signals available to other cells
```

This supports the research path from [[cellular-oscillating-tomography]] to
[[protein-oscillation-tomography]] and [[scale-invariant-patterns]]. Whether a particular cell
learns in a Hebbian sense requires evidence that correlated activity changes a later association,
not only that the cell has receptors or thresholds.

## Similar problem, different substrate: neuron and T cell

`a0590z.md` compares neural pattern recognition with T-cell education. The useful comparison is
that both systems must respond to complex, partial evidence while avoiding harmful false
positives.

The mechanisms remain distinct:

```text
neuron:
distributed synaptic input -> dendritic/somatic integration -> spike and synaptic consequence

developing T cell:
rearranged T-cell receptor -> peptide-MHC encounters -> positive, negative, or regulatory fate
```

The comparison belongs in a scale-aware discussion of biological detection. It does not show that
the thymus trains T cells exactly as a neural network trains neurons.

## Experience can persist into imagery and self-models

`a0589z.md` connects repeated engagement with a game, book, film, or person to continuing imagery,
dream content, expectations, and temporary changes in self-description. The Tetris experiment
provides a bounded comparison: extended play can recur as stereotyped hypnagogic imagery.

SAN's broader question is how repeated activation changes which internal patterns are easiest to
restore and which behaviors feel available. That route connects to
[[memory-state-drift-virtual-mind]] and [[feedback-strange-loops-self-model]] without turning a
first-person report into a diagnosis.

## From a single EEG channel to multimodal reconstruction

`a0591z.md` preserves the Neo Mind Cycle salon and its emphasis on EEG, entrainment, education, and
instrument access. `a0594z.md` shows the later engineering expansion:

```text
EEG + eye tracking + ECG + EMG + GSR + audio + task context
-> synchronized acquisition
-> artifact handling and denoising
-> individual calibration
-> state estimate with uncertainty
-> feedback or perturbation
-> measured consequence
```

This is a substantive transition from single-modality feedback toward
[[multimodal-neuroaffective-xr-closed-loop]]. It also explains why the
[[bci-instrument-atlas]] must separate what each device measures from what the entire person is
experiencing.

Historical drug, supplement, stimulation, and treatment claims in `a0591z.md` are retained as
history rather than presented as current guidance.

## What separates a thinking system from a storm?

`a0583z.md` asks whether a long electrical storm on Jupiter is thinking. `a0592z.md` proposes that
biological computation can inform artificial consciousness. `a0595z.md` adds internal
representation and action.

Together they form an eligibility ladder:

```text
dynamics
-> recurrent organization
-> memory-bearing state
-> learned internal relations
-> counterfactual prediction
-> selective action
-> returned consequence
-> self-registration and report
```

A storm may satisfy the first one or two levels. That does not decide the later ones. This is why
[[mechanistic-emergence-model-adequacy]] and
[[intelligence-attention-awareness-self-capability-ladder]] require component-specific evidence
rather than one dramatic analogy.
