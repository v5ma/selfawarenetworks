The single-cell Hebbian assembly is the hypothesis that [[hebbian-learning]] applies not only across multi-neuron populations but within a single cell: a neuron's surface receptors grow in response to input patterns, forming a configuration that represents the learned pattern. Any subset of the trained receptors can then reactivate the full assembly — the same associative completion Hebb proposed for cell assemblies, but compressed into one cell.

## Core Claim

In classical Hebb, neurons that fire together wire together — a cell assembly stores a pattern across N cells. The single-cell extension holds that a single neuron can develop a receptor configuration that is isomorphic to a Hebb assembly: the [[gh-b0049y|summary]] pattern of receptors *is* the learned representation. This matters because it suggests the brain's storage density is far higher than cell-count alone implies.

*From note [[gh-a0606z|a0606z]]*: "The combined pattern representation could be represented by the [[gh-b0049y|summary]] configuration of the receptors that developed in response to some signalling that the cell received… any of the receptors could activate the rest of them, a learning pattern isomorphic to Hebb's multi-neuron assemblies but on a single cell."

## Relation to Dendritic Compartmentalization

This concept is consistent with [[dendritic-compartmentalization]]: if [[dendrite]] branches already function as semi-independent computational units, then receptor clustering on a single branch IS a within-cell pattern storage. The active dendritic segment detection mechanism (~8-9 coincident NMDA synapses) is a concrete biophysical implementation of this idea.

## Body-Wide Extension

The same note proposes extending the principle beyond neurons: the entire body functions as a distributed chemical neural network, with T-cells, microglia, and other cells acting as feature-learning nodes. Teacher T-cells programming other cells parallels how inhibitory interneurons shape cortical learning. See [[body-as-chemical-neural-network]] (stub).

## Brainwave Power Bands

Related claim from the same source: neural activity clusters into discrete frequency power bands (alpha, beta, theta, delta, gamma) rather than filling the continuous spectrum. This mirrors wave-particle discretization. Consciousness may operate only at active power bands, not between them — relevant to [[napot]]'s treatment of oscillatory phase as information carrier.
