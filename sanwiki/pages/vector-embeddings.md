# Vector Embeddings

**Vector Embeddings** in [[gh-a0206z|Self]]-Aware Networks is the load-bearing biology-AI bridge that identifies [[dendrite|dendrites]] as the *analog computational equivalents* of the high-dimensional vector embeddings used in modern machine learning, and reframes the brain's [[oscillatory-computational-agency|oscillatory activity]] as the engine that reads, writes, and continuously updates those embeddings across [[cortical-column|cortical columns]] in real time. The concept threads through [[micah-blumberg|Micah Blumberg]]'s draft chapters as both a chapter-level heading ("21. Dendrites as Vector Embeddings" and "30. Vector Embeddings and Semantic Space") and as a recurring synthesis point that links [[dendritic-computation]], [[long-term-potentiation|LTP/LTD]], [[mixed-selectivity]], [[3d-semantic-segmentation]], and the [[napot-overview|NAPOT]] readout model.

![Vector embeddings in SAN as dendritic phase readout](/v5ma.github.io/wiki/assets/generated/san/vector-embeddings/vector-embeddings-dendritic-phase-map-20260628-v3.png)

This page-specific SAN image frames vector embeddings as a biological mechanism rather than a loose AI metaphor: feature events arrive at dendritic synaptic addresses, synapse location and strength form the active embedding state, oscillatory phase reads and updates that state, and population readout turns the local dendritic vector into a larger phase-topological map.

## Position

The core SAN claim is operational: "Dendrites function as analog computational equivalents to vector embeddings by encoding information in high-dimensional synaptic configurations. Each [[dendrite]] mirrors an AI inference stage" (`draft2--md`, line 306, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/draft2.md)). Each [[dendrite]]'s activated synapses act as a coordinate vector in a high-dimensional concept space, so a single neuron is "a [[gh-a0206z|self]]-organizing intelligence model, forming a high-dimensional representation of sensory or cognitive inputs" — and "Much as vector embeddings in machine learning can be visualized as a 'Gaussian splat' in multidimensional space, a neuron's dendritic activity captures" the same kind of distributed, continuous structure (`draft3--md`, line 377, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/draft3.md); restated `draft6--md` line 440, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/draft6.md)). Because many synapses can be co-activated, "a neuron can flexibly encode multiple associations, paralleling modern machine learning vector embeddings" (`draft2--md`, line 308, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/draft2.md)) — i.e. [[mixed-selectivity]] is *the same phenomenon* as vector-embedding superposition.

The dendritic-embedding picture composes with SAN's [[napot-overview|NAPOT]] readout. ## Post-SAN

The SAN [[dendrite]]-as-embedding thesis sits adjacent to several published research lines without being identical to any of them. [[mixed-selectivity]] (Rigotti et al., Fusi and colleagues) describes single PFC neurons that respond to non-trivial conjunctions of task variables — exactly the multi-association capacity SAN points at when it says a single [[dendrite]] encodes "multiple associations, paralleling modern machine learning vector embeddings" (`draft2--md`, line 308, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/draft2.md)). Mainstream [[dendritic-computation]] research (Poirazi, Larkum, Major) treats individual dendritic compartments as nonlinear units; SAN extends this by claiming each compartment is *structurally* an embedding coordinate, not just a nonlinear gate. Mechanistic interpretability of large language models (Anthropic's circuits work) and brain-[[fmri]] semantic mapping (Huth, Gallant) converge on the same testable consequence the SAN drafts call for in section 32 — that the same semantic axes should be recoverable from both substrates. SAN's distinct, [[criterial-causation|criterial-causation]]-flavoured claim is that the *update rule* is continuous and adaptive at test time (`vecC--md`, line 941, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/vecC.md)) — a falsifiable [[prediction]] that dendritic [[ltp]]/LTD signatures will track ongoing inferential state in a way frozen-weight ANN embeddings do not. Where this is reformulation rather than novel claim — e.g. the metaphor of Gaussian-splat embedding visualization — the SAN drafts are honest about it, treating the analogy as a *visualization* aid (`draft3--md`, line 377, [on GitHub](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/draft3.md)).
