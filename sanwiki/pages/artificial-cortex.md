# Artificial Cortex

An **artificial cortex** is the SAN program's name for an external adaptive computational system intended to enter a person's recurrent cognitive or sensorimotor loop through a brain-computer interface. The word *cortex* names an engineering role: receive partial state, transform it, return a useful consequence, and adapt with the person. It does not mean that a computer is anatomically equivalent to neocortex or that biological and artificial components already form one conscious subject.

## The Recovered Operation

The source-faithful Artificial Cortex proposal is:

**biological, behavioral, and environmental state -> declared neural or body measurement -> task-bounded inference -> external adaptive transformation -> calibrated sensory, peripheral, or neural return -> user action and co-adaptation -> changed biological, behavioral, and environmental state**

This is stronger than ordinary one-way decoding because the returned result must enter the person's next perception or action cycle. It is narrower than mind uploading, merged identity, or a silicon replacement cortex. A decoder, display, memory aid, or language model can improve performance without becoming part of the user's biological cortex or personal identity.

## The Original 3D Capture-to-Return Route

The 2017-2020 sources were not proposing that fNIRS contains a video or that a holographic scanner reads a complete thought. They proposed an engineering chain:

**external volumetric capture -> task-defined 3D representation -> neural and bodily measurement -> cross-modal model with uncertainty -> personalized external computation -> WebXR, audio-visual, peripheral, or neural return -> action and later measurement**

The purpose of external 3D capture is to supply known world-side structure against which a measured neural response can be trained and tested. The medical-imaging side supplies another partial measurement. A model must learn a bounded relationship between them. Neither side is a ground-truth copy of subjective experience.

In this context, *holographic* can refer to volumetric reconstruction or display. It must not imply that fNIRS alone produces a literal optical hologram of the brain's semantic contents.

## Measurement Is Not Thought Capture

Different instruments expose different variables and delays:

- **EEG** measures scalp voltage differences produced by spatially and temporally mixed neural current sources, with reference, volume-conduction, muscle, eye, and movement effects.
- **fNIRS** estimates changes in oxygenated and deoxygenated hemoglobin from detected light. It is a hemodynamic measurement with depth, hair, optode-coupling, systemic-physiology, spatial, and temporal limits. It does not measure a single neuron's impulse or a complete thought.
- **Intracortical arrays** can record more local population activity but sample only a small implanted region and introduce surgical, tissue, stability, and calibration burdens.
- **Behavioral and environmental sensors** measure actions and context. They can improve an interface without becoming neural measurements.

Hybrid systems can use complementary measurements, but complementarity is an empirical result rather than a license to fuse every channel. Khan and Hong decoded separate fNIRS mental-task and EEG eye-movement commands for online quadcopter control ([2017 primary study](https://doi.org/10.3389/fnbot.2017.00006)). Li and colleagues tested early EEG and fNIRS features together during hand movement ([2017 primary study](https://doi.org/10.3389/fnhum.2017.00462)). Each result is participant-, task-, sensor-, feature-, and validation-specific.

## Return Is a Separate Causal Problem

The system can return information through:

- a visual, auditory, haptic, or mixed-reality display;
- sensory substitution;
- peripheral nerve or muscle stimulation;
- intracortical or other implanted stimulation; or
- carefully targeted noninvasive stimulation.

Focused ultrasound is one possible intervention class, not the inverse of fNIRS and not automatically part of an optical measurement system. Human studies have shown target-dependent modulation under specific transcranial focused-ultrasound protocols ([Legon et al., 2014](https://doi.org/10.1038/nn.3620)). That does not establish arbitrary neural writing. Target, skull model, acoustic field, frequency, pressure, pulse timing, duty cycle, thermal and mechanical indices, off-target exposure, state dependence, adverse effects, and follow-up must be specified.

Existing BCI work also demonstrates bounded pieces of the larger loop: neural control of a robotic arm ([Hochberg et al., 2012](https://doi.org/10.1038/nature11076)), intracortical somatosensory feedback during object manipulation ([Flesher et al., 2021](https://doi.org/10.1126/science.abd0380)), and adaptive deep-brain stimulation tied to a selected biomarker ([Little et al., 2013](https://doi.org/10.1002/ana.23951)). These results do not establish unrestricted thought reading, arbitrary memory writing, or shared consciousness.

## The Closed-Loop Requirement

A candidate artificial cortex needs at least six separately tested operations:

1. **Measure:** observe a declared biological, behavioral, or environmental variable through a known forward model.
2. **Infer:** estimate a bounded task state with uncertainty and held-out validation.
3. **Compute:** transform that estimate using an inspectable model with declared latency, resources, and failure behavior.
4. **Return:** affect the user through a calibrated sensory, peripheral, or neural route.
5. **Adapt:** update person and machine models while detecting drift, fatigue, adverse effects, and loss of calibration.
6. **Verify consequence:** show that the returned result changes a later biological, behavioral, or environmental state in the predicted direction.

The return path is decisive. Software does not enter the neural self-loop merely because it processed neural data. The person must receive and causally use a returned consequence.

## SAN and Artificial Neurology

Artificial Cortex is the bridge between SAN's BCI program and its Artificial Brains program. The biological system contributes living receptors, dendrites, cells, circuits, body state, and learned history. The artificial system contributes sensors, models, memory, simulation, and return routes. Their interaction is a coupled learning process whose boundaries must remain measurable.

SAN proposes that a useful artificial cortex would join a distributed observer-action process rather than report to an inner viewer. Biological tonic activity supplies ongoing receiver-relative context. Phasic biological and machine-mediated events may alter that context. Inhibition, structured coordination and separation, memory, action, and returned consequences shape the next state. The coordinated biological network remains the observer-action system unless stronger evidence establishes a different identity claim.

At the **micro scale**, the relevant variables are receptors, synapses, cells, stimulation targets, and local measurements. At the **meso scale**, they are assemblies, cortical and subcortical circuits, recorded populations, and adaptive decoders. At the **macro scale**, they are the person, device, body, task, environment, and continuing action loop. Success at one scale does not prove integration at the others.

## Subjective-Time Hypothesis

The historical SAN claim is not that processor speed automatically slows consciousness. It is that additional **usable, returned, and retained cognitive updates** might change experienced or remembered duration during a fixed physical interval.

That proposition remains open. Attention and working-memory load can affect duration judgments, but the direction depends on task and measurement. One controlled study found that attending to time lengthened estimates while greater working-memory load shortened them ([Polti et al., 2018](https://doi.org/10.1038/s41598-018-25119-y)); another found no cognitive-load effect on longer prospective or retrospective estimates ([Walker et al., 2022](https://doi.org/10.3758/s13421-021-01241-7)). Raw calculations per second are therefore not an accepted proxy for subjective duration.

A valid Artificial Cortex test must define:

- the physical interval;
- the added computation and its latency;
- which returned information the person actually used;
- prospective duration, retrospective duration, and felt passage of time as separate outcomes;
- retained task-relevant content, performance, and error;
- arousal, emotion, stress, sleep, fatigue, workload, novelty, and strategy; and
- whether the effect survives matched displays, matched feedback, training, and later retest.

Calling the result life extension is appropriate only as clearly labeled speculation about experienced duration. It is not biological longevity.

## Evidence Gates

| Gate | Minimum evidence |
|---|---|
| Functional assistance | Better task performance or access under held-out testing |
| Closed-loop participation | Returned output causally changes a later biological or behavioral state |
| Cross-modal 3D model | World-side and neural-side variables generalize across held-out scenes, sessions, and confounds |
| Adaptive integration | Stable benefit under drift, delay, changed tasks, and changed user state |
| SAN architecture support | Declared receiver-relative timing or state variables outperform matched conventional systems |
| Subjective-time support | A preregistered effect survives separate duration measures and workload, novelty, and memory controls |
| Identity or consciousness | Separate evidence beyond performance, language, coupling, or self-report alone |

## What the Current Image Does and Does Not Show

The current image is medically acceptable as a general architecture because it does not assign thought to one cortical layer, treat beta as a universal code, or equate functional coupling with merged identity. It is not a complete historical Artificial Cortex illustration. It omits the source program's external 3D capture, optical measurement, WebXR return, and separately calibrated ultrasound route.

When art resumes, a companion figure should show those channels as alternatives with explicit resolutions and delays. fNIRS should be labeled as hemodynamic measurement; external volumetric capture should be labeled as world-side training data; WebXR should be a sensory return; and focused ultrasound should be a distinct intervention model. The figure must not collapse them into one proven read-write machine.

The earlier plate remains quarantined because it labeled generic cortical layer 4 as rendered thought, treated beta as one cognitive code, assumed a phase-locked translation gate, and drew denser computation as a denser conscious moment.

## Safety and Governance

An artificial cortex could expose neural, behavioral, identity-linked, and health information. It requires revocable consent, local interruption, auditability, data minimization, calibration ownership, adverse-event monitoring, and a usable exit path. A person must not lose access to essential functions because a vendor, model, or network changes.
