**Inhibitory decay rate as oscillation frequency determinant** is the principle that the
cadence of [[neural-oscillations|neural oscillations]] — including gamma frequency — is set by how fast inhibitory
signals decay, not by the rate at which excitatory neurons fire.

## The Mechanism

Interneurons release inhibitory transmitters (GABA) that suppress excitatory activity.
As inhibition decays, excitatory neurons rebound and fire, which re-recruits the interneurons,
restarting the cycle. The time it takes for inhibition to decay = the inter-burst interval =
the oscillation period.

> "Oscillation frequency is seen... the gamma frequency is defined by the decay rate of...
> inhibition." — [[gh-b0124y|b0124y]]

This makes inhibitory interneurons the **pacemakers** of cortical rhythms, not passive brakes.

## Why This Matters for SAN

[[napot]] proposes that arrays of neurons project phase patterns to successive arrays.
If oscillation frequency is set by inhibitory decay, then the *tempo* of these projections
is controlled by the inhibitory sub-network. Neuromodulators that alter inhibitory decay
(e.g., via cAMP — see [[camp-neural-phase-modulation]]) can therefore tune projection
frequency across the whole array.

This connects to the [[tonic-phasic-signaling]] distinction: the tonic inhibitory baseline
determines the resting frequency; phasic perturbations shift the decay curve momentarily,
creating frequency modulation within a burst.

## Multi-Scale Implications

The same decay-defined mechanism operates at different timescales:
- **Gamma** (~40 Hz): fast-decaying perisomatic GABA-A inhibition
- **Alpha/beta** (~8–20 Hz): slower dendritic GABA-B / interneuron network inhibition
- **Theta/delta** (~1–8 Hz): hippocampal interneuron networks with long decay constants

Each band corresponds to a different [[fractal-pattern]] of the same inhibition-rebound loop,
scaled across cortical depths and network sizes.
