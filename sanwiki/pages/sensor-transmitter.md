# Sensor Transmitter

**Sensor Transmitter** is the [[self-aware-networks|Self Aware Networks]] (SAN) name for the elementary biological computational unit — a single cell that simultaneously receives signals (sensor) and emits signals (transmitter), and which, when assembled into oscillating networks, [[entification|entifies]] into the larger sensor-transmitter systems that SAN identifies as the substrate of [[consciousness|sentience]] and perception. It is the unit that anchors SAN's [[fractal-pattern-scaling-brain|fractal scaling]] argument: each cell is a sensor-transmitter, each [[cortical-columns|cortical column]] is a sensor-transmitter, each region is a sensor-transmitter, and the whole brain is a sensor-transmitter — same primitive at every scale.
