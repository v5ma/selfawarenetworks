# Early a0070-a0087 Obscure Argument Map

## Why this source band matters

This band contains an unusually dense bridge from the hands-on Neo Mind Cycle apparatus to later
SAN mechanisms. Its strongest recoveries are not the broad medical or physics claims. They are the
distinction between machine-decoded commands and brain-self-decoded feedback, the bright/dark
receiver-state analogy, iterative choice refinement, and the Extended Brain thought-density
hypothesis.

Git dates establish repository fixation. Dates written inside a note remain internal-source dates
unless an independent archive, recording, export, or public page confirms them.

## Four recovered argument gaps

### 1. Brain-self-decoding feedback

The Neo Mind Cycle source distinguishes a classifier that assigns a fixed command from a loop that
returns a transformed measurement through the senses and lets the participant learn the relation.
This is a concrete ancestor of SAN's receiver-relative transformation language.

### 2. Receiver-facing bright and dark differences

The pixel metaphor becomes scientifically usable when translated into larger and smaller changes
in receiver state, including excitation, inhibition, and omitted expected activity. The result is
a distributed difference pattern, not a hidden illuminated screen.

### 3. Choice refinement after consequence

Immediate route selection and later criteria update are distinct. A consequence can introduce new
variables or change learned criteria so the same deterministic system makes a different later
choice.

### 4. Extended Brain thought-density hypertime

The Extended Brain is defined as reciprocal adaptive coupling, not mere tool use. The testable
quantity is useful human-integrated event density per world-clock interval, not raw machine speed.

## Paper-candidate disposition

No new paper number is created by this audit.

- Extended Brain already routes to an active manuscript.
- Choice refinement strengthens the existing Choice paper.
- Brain-self-decoding feedback should first be tested for nonduplication against the Neo Mind Cycle,
  BCI instrument, and Extended Brain papers before becoming a separate methods/history paper.
- Bright/dark receiver-state transformation strengthens Neural Rendering and NAPOT rather than
  presently supporting a standalone manuscript.
