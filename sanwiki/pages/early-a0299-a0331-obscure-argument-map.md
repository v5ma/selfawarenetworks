## Broadband population context and spatial scale

Davis, Muller, and Reynolds found that broadband LFP phase predicted spontaneous spike timing in
marmoset visual cortex better than the tested narrow bands. This supports treating the ongoing
population state as a spectrally rich, time-varying reference rather than forcing it into one
fixed band.

The complementary spatial claim is a two-timescale distinction. Slow tonic activity can spread,
recur, and coordinate broad cortical territories over time. A sharp-wave ripple is different: a
brief, highly synchronized and temporally compressed hippocampal event can rapidly recruit distant
targets through specific anatomical pathways. In that functional sense, an SWR can reach far "in
a single bound" even though the locally measured ripple field is spatially constrained. The
distant event is propagated neural influence and coupled target activity, not one extracellular
voltage waveform remaining unchanged across the brain.

This gives SAN a stronger multiscale model:

```text
slow tonic context -> broad coordination accumulated over repeated cycles
sharp-wave ripple -> compressed sequence and rapid pathway-specific distant recruitment
local phasic burst -> receiver-specific update within either larger temporal structure
```

### Current SAN clarification: coincidence becomes action

On July 22, 2026, Micah clarified the intended connection between the two-timescale distinction and
action. The tonic oscillatory state supplies the slower recurring coordination context, while
high-phasic PWD events carry the update. When timing- and phase-compatible events converge on the
same receiver within its integration window, their effects can summate into increased effective
drive. Sufficient drive can recruit the premotor and motor pathway that produces a movement or
vocalization. This is a current clarification of the mechanism, not evidence backdated to any one
file in the fixed 2022 source queue.

```text
tonic timing context
-> high-phasic PWD convergence
-> receiver-specific coincidence and summation
-> increased SAN electrical valence / effective drive
-> motor-pool recruitment
-> motor-neuron and neuromuscular activation
-> muscular or vocal action
```

The corresponding experiment must measure arrival time, relative phase, pathway delay, excitation
and inhibition, receiver state, motor recruitment, and output. Same-frequency activity predicts
reinforcement only when those receiver-relative conditions align.

The relevant observables are not hypothetical measurement categories. Bat studies have already
tracked pre-vocal beta/high-gamma power changes, theta coupling, gamma spike-LFP phase locking,
future call class, and directed pre-vocal information flow. SAN's present synthesis groups those
variables as a candidate building PWD/electrical-valence process and asks whether their aligned
combination causally recruits the selected vocal motor program.

Amplitude and reach still depend on source geometry, population synchrony, reference, tissue,
task, and instrument. Oscillation frequency, event duration, anatomical transmission delay,
spatial coherence, and wavefront propagation velocity remain separate variables.

The useful SAN consequence is methodological:

```text
declare the ongoing reference state
-> compare broadband, narrowband, transient-event, and hybrid models
-> test receiver-relative departures on held-out trials
-> retain PWD only if it adds prediction or causal control
```

## Dendritic domains and distributed semantic maps

The Spruston review supports structurally and functionally distinct dendritic domains, nonlinear
integration, and multiple coincidence-detection opportunities in pyramidal neurons. SAN can use
that foundation to ask whether learned domain-specific transformations improve prediction of a
cell's output and later network consequence.

Huth and colleagues modeled responses to natural movies and recovered a continuous semantic space
distributed over smooth cortical gradients. That result gives SAN a strong comparison for learned,
distributed property maps: a concept can be reconstructed from multiple spatially distributed
features and actions rather than stored in one isolated category location. The SAN extension is
to test whether receiver-relative timing and recurrent transformation improve prediction beyond
the voxelwise semantic model.

Primary routes:

- [Spruston, 2008](https://www.nature.com/articles/nrn2286)
- [Huth et al., 2012](https://pubmed.ncbi.nlm.nih.gov/23259955/)
- [Nishimoto et al., 2011](https://pubmed.ncbi.nlm.nih.gov/21945275/)

## Phase-separated memory operations

`a0327z.md` correctly points to the SPEAR family. Hasselmo, Bodelon, and Wyble proposed that
different portions of hippocampal theta can favor encoding or retrieval and thereby reduce
interference. Later human intracranial work found phase opposition between encoding and retrieval
under bounded tasks. This supplies a strong comparison for MPRS:

```text
phase can separate encoding and retrieval under defined conditions
-> MPRS must specify its additional sequence, rendering, and action predictions
```

Primary routes:

- [Hasselmo, Bodelon, and Wyble, 2002](https://pubmed.ncbi.nlm.nih.gov/11936962/)
- [Kerren et al., 2022](https://pubmed.ncbi.nlm.nih.gov/34857748/)
- [Hasselmo, 2025](https://pubmed.ncbi.nlm.nih.gov/39721980/)

## The situated self and immediate copy divergence

The most important Micah-authored turns in `a0331z.md` separate learned capacity from the active
person. A physical duplicate can begin with similar memories and skills, yet immediately receives
different sensory evidence, occupies a different location, enters different relations, and
produces different consequences. The source therefore anticipates a situated identity model:

```text
inherited structure and memory
+ current body and location
+ incoming criteria and active network state
+ action and returned consequence
-> a person-specific trajectory that begins diverging immediately
```

The modern formulation treats an informational pattern as multiply realizable rather than
immaterial. A causal neural instance is physically realized and can be measured through changes in
state, transition probability, output, or behavior. This gives the original criterial insight a
testable physical form.

The source is a multi-speaker discussion. Only explicitly named Micah Blumberg turns support Micah
genealogy. The note's internal 2013 date is not public-custody proof; its first tracked Git fixation
is June 12, 2022.
