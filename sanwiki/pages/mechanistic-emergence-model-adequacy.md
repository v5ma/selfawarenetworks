# Mechanistic Emergence and Model Adequacy

## The problem in plain language

A crowd can form a wave even though no one person contains the wave. A neural network can likewise
show synchronization, pattern completion, or memory behavior that is meaningful only at the group
level. Calling that behavior **emergent** can be accurate.

It is not yet a full explanation. "Consciousness emerges from enough neurons" leaves unanswered
which architecture matters, what each stage transforms, how a receiver changes, and what
intervention should remove or restore the result.

The opposite mistake is to reject every simplified model because it omits biological detail. A
model should be judged against its declared target. A point-neuron model can answer one population
timing question while being inadequate for dendritic integration or synaptic mechanics.

## The SAN correction

```text
higher-level regularity != complete mechanism
simplification != biological error
adequacy = target-relative prediction + intervention + declared limits
```

The internally dated 2014 discussion in `a0088z.md` already contains the important concern:
architecture, layers, input placement, and network organization cannot be replaced by neuron count
or computer speed. The same discussion also contains the correction: computational neuroscience
includes multicompartment, conductance, oscillator, and transmitter-release models, not only one
all-or-none point neuron.

`a0097z.md`, internally dated 2013, records the earlier question of how variable activity can form
coherent collective structure. Both notes entered the current Git history in 2022, so their
internal dates and immutable Git dates must remain separate.

## A model-adequacy checklist

For every model, name:

1. the exact phenomenon it claims to explain;
2. the preparation, species, task, and operating range;
3. the measured and deliberately omitted variables;
4. the held-out predictions;
5. the causal intervention;
6. the competing baseline models; and
7. the result that would make the model fail.

SAN must pass this checklist too. PWD, NAPOT, Neural Rendering, and the Field-Cell Self become
stronger when their added variables explain a residual that rate, power, anatomy, recurrence, or a
simpler model cannot explain.

## What is corrected

- A presynaptic spike normally triggers chemical release; it is not irrelevant because it stops at
  the synapse.
- All-or-none threshold behavior does not mean every waveform, timing relation, or downstream
  effect is identical.
- Soliton and electromechanical proposals remain hypotheses, not replacement physiology.
- Neuron count, computer speed, architecture, and complexity are not by themselves evidence of
  consciousness.

## Dynamics are not yet eligibility

[[gh-a0572z|a0572z]] asks why a neural process should count as thought when another dissipative
process does not. [[gh-a0574z|a0574z]] asks whether a software simulation can settle a claim about
biological hardware. Together they motivate an eligibility ladder: dynamics, learned content,
recurrent integration, action, report, self-maintenance, and perturbation-sensitive behavior must
be separated rather than inferred from energy flow, resonance, complexity, or substrate alone.

Models test explicit assumptions. Hardware experiments test substrate-dependent effects. Neither
route earns a consciousness claim without a declared discriminator and a result that could have
failed.

## Useful models under metaphysical uncertainty

A model can support prediction, rehearsal, and action without settling what reality ultimately is.
Simulation language is therefore strongest when it declares inputs, state transitions, predicted
consequences, and failure conditions. Predictive difficulty also does not identify an external
programmer; some fully specified dynamical systems contain undecidable long-term questions.

SAN can preserve the useful action loop while keeping ontology separate:

```text
partial observation -> model -> candidate consequence -> action -> returned evidence -> revision
```
