**Fractal Retinotopic Mirroring** is the conjecture that the brain repeats the functional organization of the retina throughout its entire structure at a fractal scale — each neural region encoding information in a spatially organized, retinotopic manner analogous to how the retina maps the visual field.

## Core claim

The retina converts light into spatially organized signals (a retinotopic map). SAN theory proposes that this organizational principle is not unique to the visual system but is replicated across all neural arrays. Perceptual areas, memory areas, and higher cognitive regions all operate with a form of retinotopic coding — the pattern repeats at every level.

This directly extends [[napot]] ([[neural-array-projection|Neural Array Projection]] Oscillatory Tomography): each neural array functions as a local "retina," projecting and receiving oscillatory tomographic representations rather than raw photons.

## Empirical support

Steel et al. (2024, *Nature Neuroscience*) found **inverted (negative) retinotopic coding** in category-selective memory areas at the cortical apex, functionally linked to positive retinotopic coding in perceptual areas. Memory areas respond to visual stimuli like a "photographic negative" — activity decreases when perceptual areas are active, then flips during recall.

This push-pull opponent dynamic parallels SAN's [[spike-inhibition-waves]] model: each [[action-potential|action potential]] spike creates a trailing inhibition wave, and sequences of spikes create sequences of inhibitory troughs — a traveling anti-pattern that memory areas may be encoding.

## Relation to distributed memory lineage

The fractal-retina idea extends a long tradition:

- **Pribram / Lashley**: memories are distributed; the brain encodes interference patterns like a hologram ([[holographic-brain]]).
- **Kanerva — Sparse Distributed Memory**: memory stored across a high-dimensional distributed space, no single locus.
- **Hawkins — Sparse Distributed Representations (SDRs)**: efficient coding via sparse neural patterns in *On Intelligence*.
- **SAN / NAPOT**: fractal iteration of the retinotopic principle generalizes these to all modalities, with [[traveling-waves]] as the carrier.

## Key insight

The inversion (memory = perceptual negative) is not noise — it is the mechanism. Just as film negatives store positive images via their complement, memory areas may store representations as inhibitory complements of perception, enabling recall by flipping the relationship.
