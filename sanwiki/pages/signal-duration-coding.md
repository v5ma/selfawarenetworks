# Signal Duration Coding

**Signal Duration Coding** is the [[self-aware-networks]] claim that information traversing a neural circuit is carried, in part, in the *duration* of each spike — the [[action-potential-duration|APD]] / [[apd]] envelope set by potassium-channel kinetics — and not by spike timing or rate alone. The [[napot-theory]] / [[napot-overview]] account uses APD changes to set the [[tonic-oscillation|tonic]] phase of the next neuron, gate vesicle release, and propagate the encoded pattern through [[phase-wave-differentials]] over [[neural-arrays]]; this gives a third coding axis alongside rate and phase, with mechanoreceptor pressure mapped directly onto APD.

## Post-SAN

Compared to mainstream neural-coding literatures, signal duration coding adds a third axis. Standard rate-coding accounts treat firing rate as primary; standard temporal-coding accounts treat spike *timing* (phase, latency) as primary. SAN keeps both and adds APD as a load-bearing third channel — the duration of each spike, gated by potassium and calcium kinetics, carries information about the input pattern (`a0011z--md`, line 127, [on github](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/a0011z.md)) and resets the [[tonic-oscillation]] phase of the inhibited group (`a0270z--md`, line 232, [on github](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/a0270z.md)). Compared to neuromorphic hardware programmes, SAN flags the gap explicitly: Stanford's Neurogrid "does not appear [to] model Plateau potentials, APD [[action-potential-duration|Action Potential Duration]], or the variation in Calcium Ca2+ channel duration" (`a0008z--md`, line 147, [on github](https://github.com/v5ma/selfawarenetworks/blob/d1c26a6fbf273695185a4036411215f53209eb71/a0008z.md)) — a concrete [[prediction]] that an APD-aware substrate should outperform spike-only substrates on tasks that require fine-grained sensory discrimination. The testable predictions are sharp: shortening APD via VGKC manipulation should attenuate the tonic-[[phase-reset|phase reset]] and degrade the [[phase-wave-differentials]] coding of the next array; lengthening APD via potassium-channel block should produce intrusion artifacts in the inhibited group's timing. Compared to [[criterial-causation]] (Tse), duration coding adds a second per-neuron control variable on top of threshold crossing — the cell decides not only whether to fire but how long to fire for, and both decisions feed the next stage.
