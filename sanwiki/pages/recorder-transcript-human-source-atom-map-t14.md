## The Observer Is The Distributed Responding System

Ranks 211 and 222 make the central operation clearer than the isolated screen metaphor does.

```text
a cell or population receives a structured input
-> its membrane and dendritic state change
-> it transforms that input according to its learned and current state
-> it projects a changed output
-> other populations receive and transform that output
-> the resulting network state changes discrimination, prediction, and action
```

The same living network produces, receives, and responds to its changing state. A neuron-as-eye
or neuron-as-LED comparison refers to reception and projection roles. It does not introduce a
little observer that looks at a screen.

Rank 211 adds the tonic-canvas ancestor. Coordinated population activity supplies a maintained
context. Excitation, inhibition, and even omission of an expected event alter that context.
Those changes can be meaningful because a receiving population is selectively sensitive to them.

The source also lists chemical, ionic-electrical, mechanical, and magnetic consequences of
neural activity. These are not treated as four equally proven neural communication protocols:

- synaptic chemical and membrane ionic-electrical signaling are established mechanisms;
- extracellular fields can contribute local ephaptic effects under constrained conditions;
- mechanical consequences require a named source, scale, coupling route, and receiver;
- aggregate magnetic fields are measurable, but ordinary neuron-to-neuron magnetic messaging is
  not established merely because those fields exist.

## From A Maintained Context To A PWD

The useful sequence is easier to understand before the SAN term is introduced:

1. a neural population maintains a changing but sufficiently stable context;
2. a new sensory, memory, interoceptive, or inhibitory event alters part of that state;
3. the alteration has phase, timing, duration, magnitude, location, and receiver-relative effects;
4. receiving populations transform the alteration according to their own state;
5. the distributed difference changes what the organism can perceive, predict, remember, or do.

After that operation is understood, **Phase Wave Differential** names the structured,
receiver-relative update. It is not merely another name for an oscillation, a traveling wave,
phase coding, or coherence. Those established terms describe important components. PWD names the
joined difference that is propagated, transformed, and used in the current SAN proposal.

Tonic and phasic remain relative functional roles. Tonic does not mean every low-frequency or
broadband signal, and phasic does not mean every high-frequency event. A stable fast pattern can
serve as context at one scale; a slower event can update that context at another.

## Molecular State Changes The Projected Signal

Rank 215 supplies a concrete molecular chain:

```text
presynaptic potassium conductance
-> action-potential width and repolarization
-> voltage-gated calcium-channel activation
-> presynaptic calcium influx
-> synaptotagmin and SNARE-mediated vesicle fusion
-> release probability and quantal content
-> postsynaptic response
-> changed circuit timing and population state
```

This explains why the projected consequence of a spike is not captured by an abstract scalar
`1`. Peak voltage, waveform duration, channel state, release probability, receptor state, and
recent history all matter.

Rank 219 records an early demand for equations. The scientifically useful quantities must remain
separate:

```text
current: I = dQ/dt
charge: Q = integral I dt
capacitive voltage change: C_m dV/dt
conductance current: I_i = g_i(V - E_i)
```

These relations do not supply one universal firing number. Threshold is cell-, compartment-,
history-, and state-dependent.

## A Sensory Organ Already Receives, Transforms, And Projects

Rank 212 is scientifically useful only after reconstructing its retinal physiology. Light does
reach rods and cones. Photoreceptor opsins absorb photons, molecular transduction changes graded
photoreceptor voltage, retinal interneurons transform the signal, retinal ganglion cells generate
action potentials, and their axons project through the optic nerve.

```text
photon
-> photopigment conformational change
-> photoreceptor biochemical cascade
-> graded membrane-potential change
-> horizontal, bipolar, and amacrine processing
-> ganglion-cell spike pattern
-> optic nerve projection
```

This corrected chain strengthens rather than erases the intended SAN argument: a sensory organ
does not passively copy the world. It transforms energy into a structured, action-relevant neural
signal before that signal reaches cortex.

Claims about brain biophotons are kept separate. Detecting light generated in tissue would not
show that an intact visual image travels as photons from retina to cortex.

## Temporal Multiplexing And Nested Rendering

Rank 216 provides a 2021 ancestor of NAPOT. A route through space and time can be compressed using
turning points, extrema, and other salient relations. Different populations can project
transformed versions of that route. Visual, auditory, and bodily streams can be coordinated
through timing without becoming the same modality.

The recording proposes two compatible ways to obtain an apparently unified state:

- overlapping recruitment across micro, meso, and macro scales;
- rapid temporal interleaving among representations that the organism cannot behaviorally
  separate at that timescale.

This resembles a level-of-detail system only functionally. The brain need not render every
possible viewpoint and feature at maximum precision. It must maintain enough structured detail
for the current body, task, prediction, and action.

The source does not authorize a fixed table that assigns low frequencies to coarse detail and
high frequencies to fine detail. Frequency, scale, anatomy, duration, phase, and receiver must be
measured together.

## Mental Imagery Reveals Transformable Relations

Rank 222 separates a symbol's identity from its changeable properties. In deliberate imagery, a
number can retain its outline while color, texture, position, and depth order are changed. Two
symbols can exchange locations or surface properties. A learned arithmetic relation can be
violated, producing a mismatch and an accompanying bodily or emotional response.

The important operation is not that imagery proves a particular field theory. It is that a
working neural state can:

```text
reinstate a learned pattern
-> separate some of its properties
-> transform or recombine those properties
-> compare the result with learned relations
-> register mismatch
-> use the result in planning or action
```

The same abstract relation can be re-expressed differently in visual, auditory, motor, or symbolic
systems because each receiving network transforms it according to its tuning. The physical
pattern need not be identical everywhere.

The recording's `scalar wave` phrase is not required for this mechanism and is not admitted as a
scientific result.

## Prospective Choice Connects Scene To Action

Ranks 213 and 220 supply complementary examples.

In the street example, the system tracks people, predicts trajectories, compares alternate
routes and arrival times, estimates proximity and risk, and selects a movement. In the
hunger-and-storm example, it joins interoceptive need, external danger, pain, delay, and expected
future opportunity.

```text
current body-and-world state
-> several predicted action sequences
-> expected consequences
-> value, risk, and body-state weighting
-> inhibition or recruitment of competing routes
-> selected movement
-> sensory and bodily feedback
```

This is a stronger Choice operation than either reflex or unexplained will. It also remains
compatible with substantial unconscious computation. The empirical question is whether a
conscious working state increases the number, integration, counterfactual depth, or temporal
horizon of the alternatives that can guide action.

## From Entity Module To A Learned Causal Self

Ranks 223 and 224 provide a joined identity genealogy.

Rank 223 describes the self as a changing computational organization realized by oscillatory
activity in three-dimensional neural tissue. The entity is the maintained process itself, not a
viewer outside it.

Rank 224 explains how that process can learn a body-centered causal boundary:

```text
motor command
-> predictable change in mouth, hand, foot, gaze, or posture
-> predictable change in proprioceptive and external sensory input
-> repeated command-consequence covariance
-> learned model of this body as a controllable causal source
```

The self/world boundary is therefore partly an acquired sensorimotor model. It joins vision,
touch, proprioception, interoception, memory, and motor consequence. No single neuron or localized
symbol has to contain the whole self.

This does not settle free will. Learned bodily causation is one requirement for agency; Choice
also requires alternatives, evaluation, selection, and feedback.

## A Shared Place Requires A Common Spatial Answer

Rank 221 begins with an ordinary engineering problem. If several people use
different devices to enter the same digital place, their systems must agree
about where objects are, how they are oriented, and what they are next to.

```text
physical place or event
-> corresponding navigable digital scene
-> persistent objects registered to shared spatial relations
-> each participant receives a local viewpoint
-> synchronized state keeps those partial views mutually intelligible
-> permissions and community rules govern durable changes
```

WebXR spaces and anchors provide established ways to express tracked
three-dimensional poses. Shared mixed-reality systems add multi-user
synchronization and spatial rendering. Rank 221's distinct historical value is
the product synthesis: a WebAR learning and construction environment,
persistent adjacency, governed spaces, temporary convention booths, and a
hybrid-event counterpart.

The cryptocurrency, NFT, leasing, and property language is therefore not
silently discarded. It is preserved as optional transaction, allocation, and
governance machinery. Price and adoption forecasts are not evidence, and
private family or travel speech remains unpublished.

This engineering genealogy later supplied a useful SAN question: can a
distributed nervous system maintain selectively updated, viewpoint-relative
body-and-world relations through local transformations? The analogy earns the
question but does not establish that brains use WebXR anchors, shared-scene data
structures, or the same rendering pipeline.

See [the WebXR Device API spatial model](https://www.w3.org/TR/2019/WD-webxr-20190521/),
[the WebXR Anchors editor's draft](https://immersive-web.github.io/anchors/),
and [Microsoft's 2021 Mesh account](https://news.microsoft.com/innovation-stories/microsoft-mesH/).
