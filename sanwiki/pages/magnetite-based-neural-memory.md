Magnetite-based neural memory is the hypothesis that biogenic magnetite particles (iron-oxide crystals) found in neurons, [[astrocytes]], and minicolumns serve as substrates for long-term and instinct memory storage via magnetic field interactions.

## Core Hypothesis

Magnetite crystals are present in human brain tissue. The Lanzalaco research program (cited in [[gh-resnote04|Micah]]'s notes as "more refined models" than Hameroff's) proposes that these biomagnetites:

1. Store information electromagnetically, possibly encoding long-term and instinctual memory.
2. Participate in neuromagnetic dialogue between neuronal minicolumns and astroglial networks.
3. Mediate columnar EEG magnetic influences on short-term memory development at multiple scales.

## Relation to Hameroff / Quantum Consciousness

[[gh-resnote04|Micah]] explicitly frames this work as post-Hameroff — "more recent papers on magnetic fields / memory / consciousness based on more refined models." Hameroff's Orchestrated Objective Reduction (Orch-OR) locates quantum consciousness in microtubules; Lanzalaco's framework shifts the physical substrate to magnetite and fields, potentially more compatible with the [[napot|neural array phase oscillation]] picture.

## Astrocyte Role

[[astrocytes]] are not passive support cells in this model — they participate in magnetite-based information integration and are proposed as active partners in the neuromagnetic dialogue that underlies cognition. See also [[astrocyte-cognition]].

## Multi-Scale Evidence

Columnar electromagnetic influences on memory are observed at multiple scales (molecular → columnar → neocortical), consistent with the [[fractal-isomorphic-sensory-arrays]] principle and the broader SAN claim that the same organizational logic recurs across scales.
