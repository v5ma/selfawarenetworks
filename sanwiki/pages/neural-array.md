A **neural array** is SAN's functional name for a declared population analyzed as a
receive-transform-re-express unit. The term can be useful only when the page states which cells are
included, where they are, what they receive, what transformation is measured, and which downstream
targets they influence.

## Not one universal biological object

A neural array might refer to a projection-defined ensemble, a local sensory population, a
thalamocortical loop, a hippocampal assembly, or another bounded circuit. It should not be used as a
synonym for every cortical column, minicolumn, layer, brain region, or arbitrary group of correlated
neurons.

The cortical column is itself a variable anatomical and functional motif, not a universal repeated
processor with one fixed algorithm across all cortex and species.

## Receive-transform-re-express

1. Named inputs alter cells in the array.
2. Dendritic, synaptic, inhibitory, intrinsic, and recurrent dynamics transform population state.
3. Projection neurons and other output routes influence declared downstream receivers.
4. Feedback changes the next state of the source and receiver populations.

The output is not a complete picture deposited into a target. Every receiver combines it with many
other inputs and its own history.

## Scale declaration

| Use | Biological denominator | Boundary |
|---|---|---|
| Micro analogy | One cell or compartment contributes to an array computation | A cell is not itself a population array or tomography unit by definition |
| Meso array | Named local population or circuit | Must specify membership, inputs, outputs, and task |
| Macro network | Multiple arrays or systems exchange partial state | No one array contains the complete percept or observer |

## Relation to NAPOT

[[napot-overview|NAPOT]] proposes that multiple populations gather partial state, transform it, and
redistribute a working update. The tomography analogy becomes literal only with identifiable
projections, a target relation, reconstruction, held-out tests, and causal perturbation. Calling a
population an array does not establish those elements.

## Camera and display metaphor

Historical SAN sources describe arrays as cameras and displays. The bounded translation is that a
population can be selectively changed by input and can re-express a transformed state to other
receivers. The array does not contain a lens, picture, voxel, or viewer. Its state contributes to the
distributed working model only through the larger recurrent and embodied loop.

## Phase and wave claims

Oscillatory timing and traveling waves can organize population activity, but a neural array is not
defined by perfect coherence or one phase code. Any PWD claim must identify the reference, route,
receiver, incremental information, artifact controls, and causal consequence.

## Source genealogy

The neural-array vocabulary is established within SAN and NAPOT source history, including the 2017
NAPOT revision lineage and later SAN manuscript explanations. That genealogy establishes the theory's
development, not a standard neuroscientific unit or empirical validation.
