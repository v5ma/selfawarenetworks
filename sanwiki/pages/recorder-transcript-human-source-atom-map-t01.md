# Recorder Transcript Human Source-Atom Map - T01

This page maps the first sixteen human-reviewed Google Recorder transcripts into the SAN Wiki.
The recordings range from April 2021 through November 2023 and contain **496 bounded source
atoms**. They include Micah monologues, private discussions, public panels, later clarifications,
and external-source material. Those source types remain distinct.

The plain-language question connecting the tranche is:

> How can a living or artificial network receive differences, transform them through learned
> structure, build a temporally persistent view of a world and body, select an action, and use
> returned consequences to improve the next cycle?

Computational ranking selected the review order. It did not determine what the sources mean.
Every source body was read, speakers and dates were bounded, and apparent errors were treated first
as possible transcription errors or compressed intent.

## The joined mechanism

Across the sixteen sources, a consistent causal sequence emerges:

```text
external, bodily, or remembered difference
-> receptor, dendritic, and circuit transformation
-> a changed relation to the ongoing population state
-> receive-transform-project cycles across connected arrays
-> sparse, viewpoint-limited, temporally persistent rendering
-> body-centered prediction and valuation
-> route competition and selected action
-> motor execution and returned sensory consequence
-> plastic revision of the next cycle
```

This sequence connects [[receptor-to-phase-sensory-quantification]],
[[receptive-inceptive-dendritic-projection]], [[tonic-phasic-phase-wave-differential]],
[[perceptual-screen-neural-rendering]], [[napot-revision-genealogy]],
[[agency-valuation-action-feedback]], and [[flow-of-information-in-the-brain]].

It does not require a little viewer inside the brain. The receiving and transforming network is the
observer operation.

## Tonic context and differentiated updates

Several sources describe experience as a change against an already active background. The
constructive version is:

```text
ongoing coordinated activity supplies context
+ a transient or newly weighted difference changes that context
+ downstream receivers respond to the changed relation
= an updated population state with a different predicted or experienced consequence
```

Tonic and phasic are functional roles, not permanent frequency labels. A slow rhythm can be a
transient update, and a relatively fast pattern can be a stable local context. The relevant
questions are:

- What is the reference population?
- Which state is expected in that context?
- Which difference is rare or behaviorally important?
- Which receiver can distinguish it?
- How long does the relation persist?

Under a defined probability model, a common contextual state can carry less self-information than
a less expected update. That gives a bounded Shannon interpretation of PWD without claiming that
all high-frequency activity is high-information or that all low-frequency activity is
low-information.

See [[tonic-context-rare-deviation-tomographic-language]],
[[continuous-dynamics-discrete-neural-information]], and
[[state-relative-differential-neural-write-in]].

## Receive, transform, and project

The recordings repeatedly reject a passive relay model:

```text
a cell or array receives a connectivity-defined partial view
-> dendritic, synaptic, ionic, and network state transform the input
-> output changes the state available to another receiver
-> recurrent traffic revises the currently active rendering
```

The same component can receive in one relation and project in another. The terms "camera,"
"microphone," "screen," "speaker," and "pixel" describe functional roles, not anatomical identity.
The network does not send a completed inner picture to a separate spectator.

This is the operational core of [[receptive-inceptive-dendritic-projection]],
[[detection-rendering-interlace]], and [[cascaded-array-perspective-transformation]].

## Viewpoint-limited rendering

The 2021 and 2022 sources show why computer graphics, XR, NeRF, tomography, and 3D semantic
segmentation became useful design comparisons.

A bounded biological or artificial system need not represent every possible view at once. It can:

1. sample partial projections;
2. reconstruct the current task-relevant scene;
3. segment objects, boundaries, and action possibilities;
4. maintain only the currently useful viewpoint and nearby predictions;
5. update that representation as the body, eyes, or sensors move.

This is a resource-bounded analogy, not evidence that a brain literally runs a graphics engine or
NeRF. NeRF, medical tomography, semantic segmentation, and biological perception solve different
inverse and grouping problems. Their value is to expose shared engineering questions about partial
views, reconstruction, uncertainty, and action.

See [[world-body-brain-semantic-coregistration]],
[[broccoli-shared-recognition-artificial-perception]],
[[sensory-to-symbol-neural-grounding]], and [[perceptual-screen-neural-rendering]].

## The distributed observer

The tranche makes the anti-homunculus claim explicit:

```text
many cells and arrays maintain a coordinated context
-> local changes alter what connected receivers can detect
-> the aggregate state constrains prediction, report, feeling, and action
-> the system as a whole performs the observing
```

The observer is therefore an operation of the coupled system, not a hidden object inside it.
Synchrony alone is not enough. A candidate observer also needs differentiation, recurrent causal
influence, persistence, memory and body linkage, and consequences for action.

## From perception to action

Coincident and phase-compatible neural inputs can increase effective drive to a receiving neuron
or motor pool. That drive can help cross threshold, but it is not the metabolic energy of muscle
contraction.

The complete chain is:

```text
coordinated neural input
-> action potentials in descending and local motor pathways
-> motor-neuron recruitment
-> neuromuscular transmission
-> muscle-fiber calcium release
-> ATP-powered contraction
-> movement, vocalization, or other action
-> proprioceptive, visual, auditory, and interoceptive return
```

This preserves SAN's timing-and-route proposition while respecting the physiological boundary
between neural coordination and muscular energy.

See [[agency-valuation-action-feedback]],
[[neural-path-selection-interneurons-choice]], and
[[inhibitory-routing-signal-processing-grid-graph]].

## Emotion as a measurable multiscale state

The sources repeatedly connect emotion with detectable electrophysiological and bodily changes.
The bounded claim is multivariate:

```text
receptor and neuromodulator state
+ local membrane and circuit dynamics
+ autonomic and endocrine response
+ interoceptive representation
+ attention, memory, and action tendency
= a changing affective state with measurable correlates
```

No emotion is assigned to one universal band, electrode, neurotransmitter, or brain region.
The research opportunity is to measure coordinated changes across levels and test how
perturbations alter experience, behavior, and returned bodily evidence.

This connects [[multimodal-neuroaffective-xr-closed-loop]],
[[multimodal-neural-state-reconstruction-perturbation]], and
[[conscious-state-perturbation-tomography]].

## Coordinated availability under perturbation

The 2021 Neuroscience and AI source asks a more precise question than whether anesthesia turns the
brain `off`:

> When local and specialized processing continues, which relations among world, body, affect,
> memory, prediction, and action remain jointly available to the system?

A controlled perturbation makes that question measurable:

```text
declared stimulation or event
-> early local response
-> spread and differentiation across connected systems
-> persistence and recurrence
-> influence on memory, report, valuation, and action
-> returned consequence
```

TMS-EEG work under midazolam found preserved initial cortical reactivity with a shorter, more local
response during loss of consciousness than during wakefulness
(https://doi.org/10.1073/pnas.0913008107). Perturbational Complexity Index research compares the
differentiated spatiotemporal response across states
(https://doi.org/10.1126/scitranslmed.3006294). Human hippocampal recordings under general
anesthesia have also found residual oddball discrimination, semantic processing, prediction, and
plasticity (https://doi.org/10.1038/s41586-026-10448-0).

The constructive distinction is therefore between component processing and coordinated
availability. The comparison stops before one anesthetic, stimulation site, complexity measure,
or absent report becomes a universal consciousness test. SAN preserves the hypothesis that a
joined episode has measurable consequences across recurrent rendering, body and affect state,
memory, prediction, route selection, action, and feedback.

The same source treats affective and social function as a multilevel measurement problem.
Negative and positive valence, cognition, social process, arousal, sensorimotor state, and
interoception can be described across molecules, cells, circuits, physiology, behavior, and
self-report. A diagnosis, facial expression, or frequency band is not a complete person or
mechanism. This dimensional treatment is consistent with the NIMH RDoC research matrix:
https://www.nimh.nih.gov/research/research-funded-by-nimh/rdoc/constructs/rdoc-matrix

See [[conscious-state-perturbation-tomography]],
[[multimodal-neural-state-reconstruction-perturbation]],
[[multimodal-neuroaffective-xr-closed-loop]], and
[[consciousness-claim-and-evidence-ladder]].

## BCI and NerveGear capability ladder

The recordings separate several tasks that are often collapsed:

```text
detect that neural state changed
-> classify a constrained intention or percept
-> reconstruct a task-specific state
-> perturb a simple percept or action
-> write a learned multimodal pattern
-> verify the resulting experience and behavior
-> adapt the decoder and intervention in closed loop
```

Motor decoding does not equal unrestricted thought reading. A simple stimulation-evoked percept
does not establish full qualia reconstruction. A useful BCI must declare its measurement scale,
decoder, write channel, uncertainty, tissue interaction, security model, and verification loop.

The tranche also preserves the engineering genealogy from participatory EEG and EEG-to-XR through
multimodal optical, electrical, magnetic, ultrasound, vascular, and implanted routes. Those
modalities are complementary rather than interchangeable.

See [[neo-mind-cycle-neurofeedback-bci]], [[bci-instrument-atlas]],
[[multimodal-neuron-signal-correlate-channel]], and
[[extended-brain-thought-density-hypertime]].

## Artificial Neurology and machine-consciousness measurement

The recordings treat machine consciousness as a physical and architectural measurement problem,
not as a conclusion inferred from fluent language or image generation.

A candidate test program asks whether a system has:

- temporally persistent internal state;
- recurrent access to its own changing internal outputs;
- differentiated but integrated world and body models;
- memory, prediction, valuation, and action;
- perturbation-sensitive changes that propagate through those roles;
- counterfactual and returned-consequence learning;
- a stable distinction between its own action and external events;
- report or behavior that survives controls for imitation and stored scripts.

These are candidate criteria, not proof that satisfying them is sufficient for consciousness.
They route to [[artificial-neurology-states-stages-development]],
[[intelligence-attention-awareness-self-capability-ladder]],
[[mechanistic-emergence-model-adequacy]], and
[[consciousness-claim-and-evidence-ladder]].

## Structured propagation and molecular transduction

The `We are Waves` source raises two connected engineering problems before it reaches its more
speculative language:

1. How can a changing physical pattern remain identifiable long enough for another receiver to
   distinguish it?
2. How can a difference at molecular scale become consequential to a cell, a neural population,
   and later behavior?

The first operation is structured propagation. Cortical traveling waves provide an established
case in which phase relations move across measured tissue. A soliton is a narrower mathematical
possibility: a localized waveform maintained by a particular balance of nonlinearity and
dispersion. PWD therefore does not mean `soliton`. SAN can test whether a subset of PWDs preserves
shape or relational structure across receivers, but a soliton claim additionally requires a
declared medium, state variable, governing equation, parameter regime, and test for attenuation
and dispersion.

The second operation is receiver-specific molecular transduction:

```text
three-dimensional molecular configuration
-> receptor binding or activation difference
-> second-messenger and ion-channel state
-> membrane and cellular output
-> population update
-> behavior and recurrent readback
```

Enantiomer-selective olfactory-receptor studies show that mirror-image molecular configurations
can produce different receptor, electrophysiological, and behavioral consequences. This gives the
source a real micro-to-macro bridge. The comparison stops before making chirality a universal
neural phase code. Quantum chemistry contributes to molecular structure and binding, but that does
not by itself demonstrate neural qubits, long-lived entanglement, or quantum consciousness.

SAN preserves two separate hypotheses. First, a differentiated update can retain a measurable
receiver-relative structure while it propagates through successive arrays. Second, microscopic
physical distinctions can enter a typed molecular-to-cellular-to-population conversion chain.
Each proposed conversion must name its variable, receiver, timescale, intervention, and readback.

See [[traveling-waves-phase-arrays]], [[phase-wave-propagation]],
[[soliton-wave-mechano-neural-signaling]], [[3d-protein-receptor]],
[[receptor-to-phase-sensory-quantification]], and
[[microtubule-to-circuit-scale-translation]].

## A PWD experiment matrix

The January 2023 PWD discussion turns the mechanism into a comparison program:

| Contrast | Candidate measurement |
|---|---|
| current sensory drive vs remembered or imagined reinstatement | spatial precision, decoder stability, onset and persistence |
| sustained input vs transient retrieval | duration, recurrence, and decay |
| ordinary state vs altered gain | vividness, signal diversity, coupling, and action |
| high vs low competing input | robustness, selection, and error |
| participant strategy A vs strategy B | reproducible subgroup or within-person differences |
| matched report with different source | overlap and divergence in sensory, associative, and motor routes |

Sharp-wave ripples are important organized hippocampal events, but not every conscious memory is a
sharp-wave ripple. fMRI is a hemodynamic proxy. EEG personality typing is not an established
stratification standard. These boundaries make the proposed comparisons more testable.
