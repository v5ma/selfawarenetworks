# Perspective-Conditioned Rendering and the External-Cortex Loop

## The problem

Neither a computer nor a person can devote equal resources to every possible object, detail, and
future viewpoint. A useful system has to preserve a wider model while selecting what matters now.

An external aid creates a second problem. A notebook or static display can help a person, but it
does not automatically become an external cortex. The stronger claim requires a reciprocal loop
in which person and system repeatedly change one another.

## The operation in plain language

```text
person-specific goals, memory, body, gaze, and action
+ current world and task
-> selected high-detail view and accessible external information
-> interface response
-> changed attention or action
-> measured behavioral or physiological return
-> updated interface state
-> next person-interface cycle
```

For several users:

```text
distinct continuing persons
-> voluntary registered connection
-> shared objects, messages, and task state
-> coordinated but attributable actions
-> returned consequences
-> individual learning and reversible disconnection
```

Once those operations are clear, three SAN terms can be earned:

- **Perspective-conditioned rendering** selects and updates an action-usable current view.
- **External cortex** names a person-specific reciprocal cognitive-support loop.
- **Transient shared cognition** names a temporary group task model maintained by several
  continuing participants and a shared adaptive system.

## Established neighboring operations

- Gaze-tracked foveated rendering allocates display detail according to fixation
  ([Patney et al. 2016](https://doi.org/10.1145/2980179.2980246)).
- Visual-attention effects depend on stimulus and suppressive context as well as the attention
  field ([Reynolds and Heeger 2009](https://doi.org/10.1016/j.neuron.2009.01.002)).
- External information stores can change memory strategy
  ([Sparrow, Liu, and Wegner 2011](https://doi.org/10.1126/science.1207745)), and cognitive
  offloading can improve immediate performance while changing later unaided memory
  ([Grinschgl et al. 2021](https://doi.org/10.1177/17470218211008060)).
- Brain-machine interfaces can improve through reciprocal user and decoder adaptation
  ([Shenoy and Carmena 2014](https://doi.org/10.1016/j.neuron.2014.08.038)).
- Communication and joint action can produce measurable cross-person temporal relations
  ([Stephens et al. 2010](https://doi.org/10.1073/pnas.1008662107);
  [Dumas et al. 2010](https://doi.org/10.1371/journal.pone.0012166)).
- Group performance can contain a measurable collective-intelligence factor
  ([Woolley et al. 2010](https://doi.org/10.1126/science.1193147)).

## Where the comparison stops

- A graphics engine and a nervous system can solve related selection problems without sharing the
  same implementation.
- Attention is not identical to foveated rendering.
- An external memory store is not literally cortical tissue.
- A responsive EEG-XR display does not read arbitrary thoughts.
- A co-adaptive decoder does not thereby understand experience.
- Interbrain synchrony does not transfer memory or qualia.
- Collective performance does not prove one conscious group subject.
- A shared task model does not erase person-specific memory, agency, or identity.

## Preserved SAN hypotheses

### Perspective-conditioned neural rendering

SAN proposes that perception builds and updates an action-usable current view from partial sensory
evidence, memory, body state, attention, prediction, and feedback. XR supplies an engineering
comparison and experimental scaffold, not proof of a literal graphics pipeline in cortex.

### External cortex

An external-cortex candidate should:

1. learn person-specific task relations;
2. change what information or action is available;
3. receive the person's behavioral or physiological return;
4. adapt through repeated use;
5. improve declared outcomes beyond static-aid and behavior-only baselines; and
6. preserve consent, inspectability, revocation, and independent continuation.

### Temporary shared "we"

Several continuing persons may maintain a common task model containing shared objects, goals,
roles, uncertainty, and returned consequences. This can be tested as a higher-level controller
before asking whether the coupled system is one conscious subject.

## Discriminating tests

For an external cortex, compare no aid, static aid, personalized open-loop aid, adaptive
behavior-only aid, and adaptive physiological aid. Measure performance, transfer, unaided memory,
calibration, error correction, withdrawal effects, and privacy cost.

For transient shared cognition, compare isolated participants, common-input controls, ordinary
communication, a shared static workspace, and an adaptive shared workspace. Perturb the shared
state and test whether it adds held-out predictive and causal value while action authorship,
memory continuity, and successful disconnection remain measurable.
