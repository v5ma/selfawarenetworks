# Cognitive Maps

> **Evidence boundary:** Cognitive maps are established most strongly in spatial navigation and relational-memory research. A cognitive map is not necessarily a literal geometric map, a grid-cell lattice, a semantic embedding, a complete three-dimensional percept, or a conscious inner display.

A **cognitive map** is an internal organization of relationships that supports navigation, memory, inference, choice, and action. In spatial tasks, the relationships can include position, direction, distance, boundaries, landmarks, and routes. In non-spatial tasks, researchers test whether learned concepts, values, hidden task states, or social relations are organized in a state space or graph that supports inference.

The word *map* therefore covers several experimentally different claims:

1. a spatial code for location and movement;
2. a relational graph learned from transitions among events or objects;
3. a task-state model that supports prediction and choice; or
4. the stronger SAN proposal that recurrent, multimodal state updates contribute to a distributed working model.

Evidence for one meaning does not automatically prove the others.

## Established biological base

Hippocampal-entorhinal and connected circuits contain place, grid, head-direction, boundary, object-vector, speed, and mixed-selectivity responses. These populations interact with sensory, motor, retrosplenial, parietal, prefrontal, thalamic, septal, and other systems. Their activity can remap with context and can support memory-guided behavior.

This distributed system is the secure biological starting point. It does not imply that one cell class is the map, that the hippocampus alone contains the map, or that the hippocampus contains a complete three-dimensional percept.

## Beyond physical space

Human fMRI and animal electrophysiology have found structured neural responses to non-spatial task variables. Constantinescu and colleagues reported sixfold fMRI modulation while participants moved through a learned two-dimensional conceptual space. Aronov and colleagues recorded hippocampal-entorhinal neurons tuned to a continuously varying sound frequency during a task. Garvert and colleagues recovered an implicitly learned graph of object relationships from hippocampal-entorhinal fMRI adaptation. Knudsen and Wallis recorded primate hippocampal neurons with fields over an abstract value space. Schuck and colleagues decoded hidden task states from human orbitofrontal activity.

These results support relational coding beyond physical navigation in the studied tasks. They do not establish one domain-general cellular mechanism, show that every concept is literally spatial, show that the same grid-cell microcircuit is reused everywhere, or make a sixfold population statistic equivalent to identified grid cells. Different experiments also disagree about how spatially specialized the hippocampus is, so "cognitive map" should name a measured relation and task rather than function as a universal label.

## Relation to reference frames

A reference frame declares what variables are measured relative to. A cognitive map is the larger relational organization that can use several frames. For example, an object's location can be represented relative to the body, another object, a room, or a remembered route. Transforming among those relations requires multiple interacting populations and pathways.

## Maps are revised through action

A useful map is not just stored content. It tracks state transitions and helps organize possible actions. In rats at a decision point, Johnson and Redish found hippocampal ensemble representations that swept ahead along alternative paths. Shin and colleagues later found task-specific hippocampal-prefrontal replay of past and future paths during spatial learning. Human experiments have also related hippocampal-entorhinal graph structure, orbitofrontal hidden-state representations, and offline replay to later inference or replanning.

Those results do not establish that every replay event evaluates the next choice. Gillespie and colleagues found a task in which awake replay reflected particular past experiences but was decoupled from the animal's subsequent choice. The defensible conclusion is that spatial, relational, and task-state representations can contribute to memory and decisions, while the content and function of replay depend on task, state, and circuit.

At the operational level, a dynamic map can be described as:

**ongoing relational context + current sample + candidate transition + selected action + feedback -> revised relational context**

That formulation does not assign the whole operation to one neuron, one rhythm, one layer, or one brain region.

## Source-faithful SAN recovery

Micah's June 2022 sources proposed more than a generic "relational organization." They joined three operations:

1. **Persistent context and faster differences.** A relatively stable population state provides context while faster sensory, positional, or feature changes update it. The original note attached this operation too literally to fixed cortical layers and to grid-cell-versus-place-cell anatomy. The recoverable claim is a population-timescale hypothesis, not a universal laminar circuit.
2. **Distributed, modality-constrained models.** Visual, auditory, somatosensory, hippocampal, thalamic, and other pathways contribute different transformations. Their partial representations can coordinate without every local population directly receiving every raw modality.
3. **Candidate futures close through action.** Recurrent activity can reinstate or construct possible next states; selecting and acting on one possibility changes the sensory and bodily input that updates the next state.

The June 2022 volumetric-rendering source adds a separate hypothesis: spatially distributed electrical, mechanical, metabolic, vascular, and thermal state changes may contribute detectable context to neural rendering. That is not merely a water-flow metaphor, but neither cognitive-map evidence nor current field evidence proves a complete volumetric consciousness mechanism.

The nested-timescale source adds another separate hypothesis: neural, behavioral, and cultural relations can persist over different durations and constrain one another. Frequency alone does not establish what time horizon a population represents.

## Current SAN interpretation

SAN uses cognitive maps as a bridge to active neural rendering:

1. sensory and motor systems produce partial, viewpoint-dependent samples;
2. local and distributed populations encode selected relations and hidden state;
3. recurrent networks compare current input with persistent context and can express candidate transitions;
4. receiver populations transform and redistribute the resulting differences;
5. memory, perception, valuation, language, bodily state, and motor systems change together;
6. action changes the sampled world and supplies feedback for the next update;
7. the distributed network performs the observer-action without a hidden inner viewer.

NAPOT names the proposed many-to-one-to-many update motif. NDCA names the proposed maintenance of useful continuity across changing samples. The tonic canvas is the receiving network's ongoing state; phasic ink is a relative update. None of these SAN terms is established by cognitive-map evidence alone.

## Scale ladder

- **Micro:** one neuron contributes a selective, state-dependent response; it does not contain the full map.
- **Meso:** a local population represents relations, values, events, or transitions in a defined task space.
- **Macro:** interacting cortical, hippocampal, thalamic, subcortical, and bodily systems maintain a revisable model that guides perception and action.

The same diagram should not collapse these three levels into one generic neuron.

## Discriminating tests

1. **Map geometry:** Define the task space before examining neural data, test alternative graph and geometric models, replicate across tasks and participants, and require a behavioral prediction.
2. **Cellular mechanism:** Use direct recording before calling an fMRI symmetry a grid-cell code or assigning a relational field to a cell class.
3. **Persistent context versus faster differences:** Test whether separable population states carry slower context and faster updates without presupposing a fixed cortical layer or frequency band.
4. **Candidate futures:** Decode several possible transitions before choice, distinguish prospective content from past-memory replay, and test whether perturbing that content changes the selected action.
5. **Cross-modal update:** Name the sender, receiver, anatomical route, sign, latency, and behavioral consequence rather than drawing a generic all-to-all map.
6. **SAN timing claim:** Test whether receiver-relative phase, duration, amplitude, or coupling predicts the next state and behavior beyond firing rate, connectivity, task-state, and replay-content models.
7. **Distributed observer-action:** Test whether perceptual reports and actions depend on the proposed distributed interaction; do not infer an observer from a decoded representation alone.
