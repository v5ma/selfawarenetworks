## Position

In a [[self-aware-network]], a [[neural-array]] cell is tuned not to a feature vector but to a *trajectory* — an evolving spatial pattern of [[chemical-synapse|synaptic]] inputs whose temporal order matters. The cell's response is conditional on the inputs arriving in the right *temporal pattern*, in the right [[Temporal-Oscillation-Phase|phase relative to the local oscillation]], at the right positions on the [[dendritic-morphology|dendritic tree]]. *Temporal pattern coding* is the umbrella name for this read of cellular tuning, and it is the read that licenses the [[ltp-tempo-spatial-rhythmic-memory|tempo-spatial-rhythmic-memory]] story of [[ltp]] — that connections strengthened under one rhythm preferentially re-fire under that rhythm because the cell has tuned to the *temporal pattern* under which the connections grew, not just to the *static set* of connections.

## Position — three layers of temporal pattern

Within SAN the temporal-pattern axis runs at three layered scales. (1) *Sub-cycle*: within a single [[gamma-oscillation|gamma cycle]], the order of phase-locked spikes from different inputs arriving on the [[apical-dendrite|apical-dendrite]] tree is itself a code — what the [[oscillatory-binding-problem|binding-by-coherence]] literature reads as phase-of-firing. (2) *Cross-cycle*: across many cycles, the *evolution* of the firing pattern (which arrays peak in which sequence under the [[dominant-phase-wave-differential|DPWDR]]) carries the trajectory information. (3) *Cross-rhythm*: at a [[multi-timescale-reference-frames|multi-timescale]] level, the way [[gamma-oscillation|gamma]] rides on [[theta-oscillations-background-scripts|theta]] under [[cross-scale-oscillation-communication|cross-scale]] coupling is itself a coding axis. *Temporal pattern coding* is the conjunction of these three, not a single rate-coded variable.

## Position — substrate

The substrate that implements temporal pattern coding is: (1) [[dendritic-coincidence-detection|dendritic coincidence detection]] that is sensitive to the *order* of arrivals; (2) [[apical-dendrite|apical-dendrite]] integration windows that quantize the coincidence detector to gamma-cycle resolution; (3) [[multi-vesicle-release|multi-vesicular release]] whose count and timing encode the input statistics; (4) [[ltp-bouton-synaptic-memory-traces|bouton memory traces]] whose plasticity rule favors connections that fire in the right temporal pattern; and (5) the [[phase-wave-differentials|phase-wave differential]] envelope at the column scale that selects which cells are listening at which moment. Together these implement temporal pattern coding as a usable computational primitive.

## Relation to mainstream framings

In mainstream [[neuroscience]], the rate-vs-temporal-coding debate runs back decades. SAN sides firmly with temporal coding, and adds two structural moves: (a) the temporal pattern is *phase-organized*, so two rate-equivalent patterns at different phases code different content (cf. [[Temporal-Oscillation-Phase]]); and (b) the temporal pattern is *physically grown* in the [[synaptic-connections]] / [[dendritic-morphology]] joint state, so temporal coding is not a software trick over rate but a hardware property of the substrate. This puts SAN's *temporal pattern coding* in dialogue with [[predictive-coding]], [[free-energy-principle|free-energy]], [[hierarchical-temporal-memory]] (HTM), and the broader spatiotemporal-pattern literature, while making a substrate-specific testable [[prediction]]: that experiments which preserve rate but disrupt phase order should disrupt content recognition by the receiving cells, which the rate-only abstraction does not predict.
