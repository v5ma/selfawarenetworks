This mechanism plate separates the page's core claim into three steps: competing coincidence
patterns enter a dopamine salience selector, only the selected pattern enters reinforcement,
and durable memory storage happens downstream through protein synthesis and synaptic-weight
change rather than dopamine itself.

In SAN theory, dopamine is **not** a universal memory chemical. Memory storage depends on
[[neuron-rank-protein-synthesis|protein synthesis and synaptic weight changes]] triggered by
any neurotransmitter-receptor binding event. Dopamine's specific role is as a **selection
signal** — it modulates which of the competing coincidence patterns in a neural circuit get
reinforced, not whether reinforcement can occur at all.

## The distinction

Any neurotransmitter can carry a [[coincidence-pattern-neural-bit|coincidence pattern]]:
GABA provides inhibitory gating, [[acetylcholine]] modulates arousal and [[attention]], glutamate
drives excitatory cascade. Memory encoding — new protein synthesis, increased electromagnetic
synaptic density — follows any successful receptor-binding event that changes ionic gradients
and triggers soma depolarisation.

Dopamine applies differently: it acts on dopaminergic receptors to **elevate or suppress the
probability** that a given pattern gets reinforced. It is the brain's *salience vote*, not
its storage medium. A pattern that receives dopaminergic reinforcement wins the competition
for rank; one that does not may still activate but fails to propagate up the oscillatory
hierarchy.

## Implication for rank-based memory

In the [[neuron-rank-protein-synthesis]] model, neurons gain rank when they fire. Dopamine
modulates which neurons are *permitted* to fire in a given context — by opening or closing
dopaminergic receptor channels on the receiving [[dendrite]], it acts as a gating mechanism that
selects which patterns enter the protein-synthesis loop at all. The memory substrate (protein
+ electromagnetic density) is universal; the selection gate (dopamine) is specific.

## Relation to gravity of attention

This maps directly to [[gravity-of-attention]]: the brain's [[attention]] system is partly a
dopaminergic selection system that routes high-salience patterns toward cortical columns that
will reinforce them. Low-dopamine environments (depletion, as in [[adderall-dopamine-dynamics]])
reduce the selectivity of this gate — all patterns seem equally (un)worthy, producing the
motivational flatness of dopamine depletion.
