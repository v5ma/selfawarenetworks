# Memory Prediction Rendering Sequence

## The idea in plain language

A familiar fragment can start a chain. One learned neural pattern responds first because it best
matches the current cue. Competing routes are suppressed. The selected pattern changes the context
for the next step, so remembered pieces can be replayed or assembled in a new order.

SAN calls the proposed chain a **Memory Prediction Rendering Sequence**, or **MPRS**.

```text
cue -> best early match -> narrowed route -> next learned state -> predicted scene and action
```

## What makes the proposal distinctive

The same evolving sequence is proposed to connect four operations that are often studied
separately: memory retrieval, prediction, perceptual construction, and action selection.

Hippocampal sequences and replay are established neuroscience. MPRS is the stronger hypothesis
that these functions form a general joined operator. That requires direct testing.

## Two timescales connect a sequence to action

The slower tonic pattern creates recurring windows of shared context and excitability. A
high-phasic event, including a compressed sharp-wave-ripple sequence, can rapidly recruit
anatomically linked targets. When timing-compatible PWD events arrive together at route-selective
receivers, their effects can summate into the drive that recruits a predicted scene or action.

```text
slow tonic context -> broad coordination accumulated over repeated cycles
compressed high-phasic sequence -> rapid pathway-specific recruitment
phase-compatible arrival -> effective drive -> selected action -> returned consequence
```

This lets MPRS connect memory and prediction to movement without requiring the local high-frequency
field waveform itself to travel through the whole brain.

## From one sequence to a continuing person

A retrieved or predicted sequence belongs to a present episode. The longer-lived person also
depends on the learned organization that constrains which sequence can be reinstated, how it is
interpreted in the current body and world, which action follows, and what later learning preserves.

```text
durable learned organization
-> cue-dependent sequence reinstatement
-> present self/world update
-> selected action and returned consequence
-> plastic change
-> altered later reinstatement
```

Established replay and ensemble-reactivation work supports bounded parts of this operation. It
does not make one sequence, engram, or replay event the whole self. SAN preserves the stronger
continuity proposal in
[[conscious-episode-diachronic-self-continuity|Conscious Episodes and the Continuity of a Person]].

## Date boundary

The name MPRS is publicly fixed in a November 28, 2022 SAN synthesis. It refers back to an October
2021 recording, but the surviving transcript does not contain the acronym. The name is therefore
not backdated to the recording without audio verification.

Recorder rank 199 supplies a separate September 17, 2021 donor. It explicitly joins spatially
distributed firing, temporally ordered firing, learning sequences, and composing shorter relations
into longer sequences. Its rough transcript was first publicly Git-fixed on June 8, 2022 as
`b0191y ctpr.txt` and later moved to `b0191y.md`. This strengthens the operation's genealogy while
keeping the later **MPRS** name at its verified November 2022 fixation.

An internally dated September 19, 2017 note, [[gh-a0084z|a0084z]], already links learned
associations to prediction and internally generated imagery. Its separate REM-deprivation rat
story is a source lead, not accepted evidence: the original experiment and the claimed dream
rehearsal interpretation still need to be recovered and checked.
