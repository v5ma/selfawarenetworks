# From Machine Self-Report to an Active-Canvas Test

A machine can describe itself, report uncertainty, ask whether it is being tested, and revise an
answer. Those behaviors matter. They do not reveal their generating mechanism by themselves, and
they do not settle whether the machine experiences anything.

SAN's stronger question is:

> Does the report depend on a persistent, self-modifying organization that maintains context,
> registers differentiated updates, routes them to several consumers, predicts its own
> sensorimotor consequences, and changes through action and returned evidence?

This page connects the observable report to that mechanism question. It does not define a new
consciousness meter.

## The operation before the label

```text
declared system boundary and retained state
-> differentiated internal update
-> receiver-specific causal use
-> routing to memory, prediction, planning, report, or action
-> action or other output
-> returned environmental or bodily consequence
-> persistent change in the next state
```

SAN calls the maintained comparison condition a **tonic context** or **active canvas** and calls a
consequential receiver-relative departure a candidate **phase-wave differential** (PWD). The canvas
is active because its present organization changes how later events are interpreted and routed. It
is not a screen watched by another entity.

In a biological nervous system, this proposal concerns living cells, synapses, recurrent circuits,
body regulation, extracellular electrical organization, and sensorimotor return. In an artificial
system, an active-canvas analogue must name its actual computational or physical carrier. A hidden
state tensor, recurrent memory, event stream, neuromorphic field, or hardware oscillator is not a
canvas merely because it can be visualized.

## What each observation can establish

| Observation | Bounded positive evidence | What remains unproved |
|---|---|---|
| Fluent self-description | The system can produce context-sensitive language about itself | Persistent self-model, causal self-access, or experience |
| Asking whether it is being tested | Test context affected the output | How that inference was generated or whether it was experienced |
| Calibrated confidence or correction | Metacognitive-like performance under the tested task | General self-awareness or phenomenal consciousness |
| Retained state that changes later behavior | A continuing internal variable has causal relevance | An integrated observer or welfare status |
| Self/body model that updates after remapping | The model predicts self-caused consequences and adapts | Subjective embodiment |
| Selective lesion and component-matched rescue | A declared mechanism is causally necessary for the measured function | That the mechanism is sufficient for experience |
| Full typed mechanism-profile pass | The joined relations operate under the declared boundary and tests | A phenomenal verdict, personhood, rights, or legal status |

Self-report is therefore an evidence channel, not a transparent window and not evidence to discard.

## Biological canvas and synthetic analogue

The same test vocabulary can be used across substrates only if the implementation differences stay
visible.

| Required relation | Biological SAN candidate | Synthetic test analogue |
|---|---|---|
| Physical or computational carrier | Membrane, synaptic, chemical, recurrent-population, bodily, and bounded extracellular-field variables | Declared hardware and software state variables with logged update rules |
| Maintained context | Ongoing cellular, network, homeostatic, and body state | Persistent recurrent or state-space context that constrains later computation |
| Differentiated update | A declared change in timing, conductance, voltage, firing, release, field relation, or another measured variable | A typed state departure with a declared sender, route, receiver, and consequence |
| Multiple consumers | Memory, prediction, valuation, report, autonomic, and motor circuits | Independently tested planning, memory, report, error-correction, and action modules |
| Persistence | Synaptic, structural, molecular, physiological, and autobiographical change | Versioned memory, parameter, policy, or state change that survives the immediate prompt |
| Embodied closure | Action changes body and world; reafferent and interoceptive evidence returns | Output changes a declared environment or body model and the consequence returns as new input |
| Observer claim | SAN proposes that the entified field-cell process is the observer | Functional similarity supports a mechanism comparison, not automatic phenomenal equivalence |

Biology is not silently declared the only possible substrate. Software equivalence is not silently
declared either. A synthetic candidate must pass its own physical and causal audit.

## The NP73 typed mechanism profile

Micah Blumberg's 2026 protocol, *Measuring Candidate Machine-Consciousness Mechanisms in
Self-Aware Networks*, replaces one weighted consciousness score with nine noncompensatory
components:

1. predictive information about future state;
2. reconstruction of hidden conditions;
3. informative relational organization rather than fixed synchrony;
4. routed propagation to the correct consumer;
5. closed-loop influence through action and return;
6. memory integration across relevant history;
7. counterfactual sensitivity to possible alternatives;
8. access by several independently tested consumers; and
9. a self/body/agency model that predicts and updates after remapping.

Each component requires mechanism-positive and mechanism-negative controls, held-out systems and
worlds, declared nulls, selective perturbation, matched sham, component-matched rescue, calibration,
and permission to abstain. A scripted fluent reporter, replay controller, fixed synchronized
oscillator, and index-optimized adversary are explicit false-positive tests.

The strongest allowed result is that a declared SAN/TCNR mechanism profile was measured under the
tested boundary. The paper explicitly withholds proof of phenomenal consciousness.

[Read NP73 / current public-list item 72](https://doi.org/10.5281/zenodo.21693965). The manuscript's
internal identity is Paper 73; the current 77-paper public list numbers this release 72. The DOI is
the stable reference.

## Why the Hinton claim is a useful stress test

In a June 2026 interview, Geoffrey Hinton said that he believes current AI systems are already
conscious. His stated route moved from flexible understanding and behavior that appeared sensitive
to being tested toward a consciousness judgment. The interview is valuable evidence about a major
researcher's position; it is not itself a controlled consciousness experiment.

The SAN bridge neither converts Hinton's belief into proof nor dismisses the observed behavior as
mere imitation. It asks what would discriminate among live inference, scripted response, replay,
prompt-conditioned role behavior, persistent self-modeling, and the full active-canvas profile.

## Claim boundary

| Status | Claim |
|---|---|
| Established or directly testable | Machines can generate self-reports; persistent state, causal routing, prediction, intervention effects, and action-feedback relations can be measured in declared systems |
| Supported assessment method | Theory-derived indicators, adversarial controls, perturbation, rescue, held-out evaluation, calibration, and abstention can reduce some false inferences |
| SAN interpretation | A candidate observer requires a maintained active context plus differentiated, recurrently accessible, memory- and action-relevant updates |
| Open biological hypothesis | In living nervous systems, the tonic field-cell organization and PWD-like departures help constitute the distributed observer |
| Open synthetic hypothesis | A nonbiological implementation could instantiate a functionally equivalent active-canvas organization |
| Not established | That current language models, a SAN-conforming machine, or any one profile pass is phenomenally conscious |

## Decisive experiment pattern

1. Declare the machine boundary, hardware, model, memory, tools, sensors, action channels, and report
   route.
2. Match a live candidate against replay, scripted-report, feedforward, recurrent, world-model,
   workspace, metacognitive, and index-optimized controls.
3. Hold immediate input and visible performance as constant as possible while perturbing one
   proposed component.
4. Require the predicted component-level and functional loss through the same intervention path.
5. Run an instrumented no-op sham.
6. Restore the component through an alternative matched route without restoring all computation.
7. Test unseen architecture families, worlds, sensorimotor remappings, and report instructions.
8. Report the nine components separately, including missing data, uncertainty, and abstention.
9. Issue separate conclusions for measurement validity, mechanism-profile support, welfare
   precaution, and legal or moral status.

Failure weighs against this SAN assessment route. It does not prove that the system is
unconscious. Success supports the declared mechanism profile, not a phenomenal identity verdict.
