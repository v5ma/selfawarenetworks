# Temporal Dynamics of Awareness

> **Image status:** The July 2, 2026 plate failed medical review. It imposed one gamma frame sequence, one theta holding window, a universal thalamic pacer, a canonical laminar circuit, and one attention-selection pathway on a process that is distributed across overlapping circuits and timescales. The image is preserved outside the public build in the medically rejected archive. A source-faithful replacement prompt has been drafted, but no replacement image is installed.

**Temporal Dynamics of Awareness** is SAN's source-recovered account of how a distributed neural state can remain available, change, and guide action over time. It is not a claim that the brain has one conscious frame rate, one memory buffer, one anatomical clock, or one location where awareness is held.

The central SAN question is:

> How can relatively persistent network context and new receiver-relative differences be integrated across many timescales without requiring a separate inner viewer?

SAN's proposed answer is a recurring observer-action process:

```text
ongoing distributed state
-> incoming sensory, mnemonic, bodily, and predictive activity
-> receiver-relative differences
-> recurrent transformation and route selection
-> updated distributed rendering
-> memory, attention, and action consequences
-> changed ongoing state
```

The network populations that preserve, detect, transform, and act on these differences constitute the proposed observer-action process.

## What the dated SAN sources establish

### 2013 source, publicly fixed in 2022

The owner-dated July 28, 2013 note `a0122z`, publicly fixed in Git on June 8, 2022, describes sensory experience as "cycling synchronicity." It proposes that persistent oscillatory patterns formed through Hebbian learning become larger coordinated maps of seeing, hearing, feeling, knowing, breathing, and acting. It calls the joined activity a canvas of conscious experience.

A paragraph added on June 11, 2022 distinguishes long-term memory in synaptic connectivity from active conscious memory represented by ongoing tonic brainwave activity. That later paragraph must not be backdated into the owner-dated 2013 text.

### June 2022: consciousness as an active loop

The June 2022 note `a0628z` defines consciousness as a **temporally active loop** involving computed stories, graphical renderings, auditory and bodily pattern synthesis, predicted outcomes, and physical reorganization of choice mechanisms.

This is an embodied loop. Awareness is not merely a passive visual stream; its current state changes what the organism can select and do next.

### August 2022: frame as a multiscale state interval

The August 9, 2022 revision of `a0001z` uses a movie frame or soundtrack moment as an analogy for one changing state interval. It explicitly separates:

- **micro scale:** receptors, synapses, spikes, inhibition, and cellular state;
- **meso scale:** circuits, assemblies, and cortical or subcortical populations;
- **macro scale:** interactions among distributed cortical, thalamic, hippocampal, cerebellar, and other systems.

The source does not require a literal film strip. A frame is better interpreted as a bounded state estimate assembled from processes whose windows overlap and whose updates are not globally simultaneous.

### August-September 2022: sustained distributed rendering

The 2022 SAN and NAPOT sources propose that a content difference can persist through recurrent pattern rendering and detection. The tonic state supplies ongoing context; phasic differences modify that context; and multiple neural arrays participate in making, detecting, and redistributing the result.

The same sources describe temporal sequence processing across successive arrays. This is a candidate account of how earlier and later information can remain jointly available without placing a complete memory or percept inside one neuron, one oscillation, or one brain region.

## Established neuroscience

Several established findings make parts of this architecture scientifically plausible without proving the complete SAN theory:

1. **Neural systems integrate information over different windows.** Human temporal receptive windows increase from early sensory areas toward higher-order regions, and primate cortical areas show a hierarchy of intrinsic neural timescales.
2. **Oscillatory state can alter perceptual probability.** In threshold-vision tasks, prestimulus theta/alpha phase and power have predicted whether an identical stimulus is detected.
3. **Attention can be rhythmically reweighted.** Intracranial and macaque recordings show task-specific theta-rhythmic changes in perceptual sensitivity and frontoparietal-pulvinar coordination.
4. **Recurrent processing can influence conscious visual perception.** Masking, EEG, and timed perturbation studies show that later recurrent activity can improve perceptual clarity or be selectively necessary for reported awareness in particular tasks.
5. **Short-term availability is not always sustained firing.** Working-memory content can sometimes be recovered from activity-silent network states, so active memory cannot be identified universally with one continuously active oscillation.

These findings support overlapping temporal organization, recurrent processing, and state-dependent perception. They do not establish one universal conscious frequency, a literal gamma frame, a theta memory container, or a thalamic master clock.

## The source-faithful SAN interpretation

### Tonic context

In this page, **tonic** means the relatively persistent, distributed state against which a receiver interprets change. It can include membrane potential, synaptic readiness, ongoing population activity, neuromodulatory state, body state, and slower network history. It is not one sinusoid shared identically by every neuron.

### Phasic differences

A **phase-wave differential** is SAN's proposed receiver-relative update event. Its measurable description may include timing, phase, frequency, amplitude, duration, transmitted quantity, location, and recent history. A PWD is therefore not interchangeable with phase coding, firing rate, or prediction error alone.

### Overlapping windows

Each participating receiver can have its own effective temporal window. A compact representation is:

```text
x_r(t + dt) = F_r(x_r(t), u_r(t), C_r(t; tau_r), b(t), a(t))  [1]
```

where:

- `x_r(t)` is receiver `r`'s current state;
- `u_r(t)` is incoming activity;
- `C_r(t; tau_r)` is the receiver's recent context over an effective window `tau_r`;
- `b(t)` is bodily and interoceptive state;
- `a(t)` is action and efference-related state; and
- `F_r` is the receiver-specific transformation.

There is no requirement that all receivers share the same `tau_r`, phase, or update boundary.

### Distributed rendering

The running render is the causally available pattern produced by many such updates:

```text
R(t) = A({x_r(t), Delta_r(t), tau_r | r in P(t)})  [2]
```

Here `P(t)` is the set of participating populations and `A` is distributed recurrent assembly, not an inner screen. The render exists insofar as its distinctions can be detected, transformed, remembered, and used for action by the network itself.

## Frames and continuous flow are not opposites

SAN uses both frame-like and continuous language. These can be reconciled without inventing a universal refresh rate:

- a **frame** is a bounded measurement or state-estimation window;
- **continuity** arises when overlapping windows, recurrent state, body feedback, and prediction preserve usable relations across updates;
- **segmentation** occurs when a sufficiently large change reorganizes the active state, route, or behavioral interpretation.

The same experience can therefore be locally discontinuous and globally continuous, depending on the receiver, measurement, and timescale.

## Claim ladder

### Established

- Neural activity and perception unfold across multiple temporal scales.
- Ongoing phase and power can influence detection in specific tasks.
- Recurrent processing can contribute to conscious visual perception.
- Working memory can use both active and activity-silent mechanisms.

### Supported SAN interpretation

- Relatively persistent network state can serve as context for interpreting faster changes.
- Distributed recurrent processing can preserve and revise a usable percept without an inner viewer.
- Perceptual continuity can emerge from overlapping windows rather than a single global frame.

### Open SAN hypothesis

- A typed PWD vector predicts state change, reported content, and downstream action better than phase, power, rate, or prediction error alone.
- Repeated tonic/phasic interactions implement a general receive-transform-project-update operator across micro, meso, and macro scales.
- The distributed causal availability of the resulting render is part of the mechanism of awareness itself.

### Not established

- Gamma cycles are complete conscious frames.
- Theta oscillations universally hold percepts for a fixed duration.
- The thalamus is one master pacemaker for awareness.
- One canonical cortical column circuit implements all conscious contents.
- Deja vu, seizures, or altered states can be explained by a generic "temporal tag mismatch" without disorder-specific evidence.

## Discriminating tests

A useful SAN test should compare the full proposed mechanism with simpler alternatives.

1. Record spikes, local field potentials, EEG/MEG or fNIRS, behavior, and body state during a task with controlled temporal integration demands.
2. Estimate receiver-specific context windows rather than assigning frequency bands in advance.
3. Test whether the full PWD vector predicts detection, maintenance, transition, and action better than rate, phase, power, recurrent connectivity, or prediction error alone.
4. Perturb a declared circuit and time window using a method appropriate to the preparation.
5. Test whether the perturbation changes a specific content relation while controlling for arousal, eye movement, attention, working memory, and motor timing.

The strong SAN account is weakened if its receiver-relative variables add no predictive or causal value beyond established models.
