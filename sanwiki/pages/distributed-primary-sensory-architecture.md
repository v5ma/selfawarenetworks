# Distributed Primary Sensory Architecture

**Distributed Primary Sensory Architecture** is the [[self-aware-networks|SAN]] reading of the brain's sensory frontier — the claim that "primary" sensation is not localized to a single cortical patch per modality but spread across geometrically specialized [[multi-modal-sensory-array-geometry|sensor arrays]], a [[thalamo-cortical-information-flow|thalamo-cortical relay]], and a fan-out of [[cortical-column-signal-projection|cortical-column projections]] that together constitute a *distributed* primary stage. It is the architectural counterpart to [[distributed-observer-vs-consciousness-module|the distributed observer]] thesis: just as no single circuit *contains* the observer, no single area *is* the primary sensory site.

## Position

The architecture is *primary* because it is the first cortical resolution of incoming signals, and *distributed* because that first resolution is shared across many parallel routes rather than concentrated. Each modality enters through its own geometrically specialized [[multi-modal-sensory-array-geometry|sensor array]] — the retina, cochlea, vestibular labyrinth, somatosensory periphery, and so on — whose shape pre-filters what dimensions of the world it can sample. Most modalities then converge on the [[thalamocortical-network|thalamocortical relay]], which the framework reads as a [[thalamic-bridge-consciousness-portal|consciousness portal]] rather than a passive switchboard, and which stands in for the integrative role described in [[thalamus-modular-agi-architecture]]. Olfaction is the deliberate exception — see [[olfactory-pathway-uniqueness]] and [[olfactory-tripartite-circuit]] — and that exception is itself an argument for distribution: a system whose "primary" stage is uniform would not tolerate one channel that bypasses the thalamus while another, like the [[auditory-cortex]] route, depends on it.

Inside the cortex, the primary stage continues to distribute itself across [[cortical-columns-reference-frames|cortical columns acting as reference frames]]. [[cortical-column-oscillatory-transmission|Oscillatory transmission]] and [[cortical-column-oscillatory-collaboration|column-to-column collaboration]] turn each column into a small primary detector, while [[cortical-column-voting]] aggregates partial evidence across columns so that no single one carries the whole percept. The [[apical-dendrite|apical dendrites]] of layer-5 pyramidals act as the inceptive fields that read predictions back against incoming signal — see [[apical-dendrites]] — and the same fractal arrangement repeats across [[fractal-neural-scale-hierarchy|nested neural scales]] and across the [[fractal-retinotopic-mirroring|retinotopic mirrors]] that propagate the receptor map through the hierarchy. The result is the [[sensor-array-consciousness|telescopic sensor array]] reading of consciousness — primary sensation as an array, not a point.
