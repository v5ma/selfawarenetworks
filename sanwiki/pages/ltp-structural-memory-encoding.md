LTP as structural memory encoding is the position that long-term potentiation (LTP) consolidates memories by triggering protein synthesis in neurons, permanently altering the neuron's physical structure — making memory a physical trace, not merely a synaptic weight change.

## Core claim

When a neuron forms a new memory through LTP, it must synthesize new proteins. These proteins permanently alter the neuron's physical architecture (dendritic spine geometry, receptor density, cytoskeletal structure). Memory is therefore not stored as a reversible strength adjustment but as a durable physical modification of the cell itself.

This view contrasts with simplified artificial neural network models where "memory" is a floating-point weight. In the SAN framework, the physical substrate matters: the [[self-aware-network]] is a network of physically differentiated cells whose structure encodes history, not a stateless weight matrix.

## Relation to SAN theory

SAN treats neurons as units that integrate oscillatory input and re-emit transformed signals. LTP-driven structural change is the mechanism by which prior oscillatory patterns leave a permanent residue in the network's physical substrate. This creates a hierarchy: [[phase-wave-differential]] carries real-time signal; LTP encodes the prior-experience context that biases how each neuron responds to future oscillations.

The structural view also implies that [[multi-vesicular-release]] (MVR) statistics at any given synapse are shaped by LTP history — a synapse that has been potentiated releases vesicles with different probability distributions, linking structural memory to real-time signal processing.

## Epigenetic extension (contested)

The source document explores whether LTP-driven protein synthesis could theoretically generate heritable epigenetic marks — transmitting memory traces to offspring. [[gh-resnote04|Micah]]'s position: the mechanism is not implausible (protein synthesis can alter methylation patterns) but depends on unknown transmission odds across multiple biological barriers (demethylation, gamete encoding). This extension is marked **contested** within SAN literature pending experimental replication of multi-generational memory transfer.
