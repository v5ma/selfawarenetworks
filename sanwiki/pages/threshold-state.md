# Threshold State

**Threshold State** is, in [[self-aware-networks]], the configuration in which a neuron — or, by extension, an oscillating subassembly of neurons — sits *just below* the firing point, so that any incremental synaptic event that arrives within the right [[oscillatory-synchrony-multimodal-integration|phase window]] can tip it across into an [[action-potential]]. It is the state in which [[coincidence-detection|coincidence detection]] is maximally sharp: small inputs produce no spike when far from threshold, but the same small input produces a spike when the cell is already poised, which is what makes the threshold state the place where a single arriving coincidence is converted into one [[coincidence-as-a-bit|bit]] of system-wide signal.

## Position

In SAN, the threshold state is the working register of the [[coincidence-detection|coincidence-detection]] account. A cell at rest is far from threshold and unresponsive; a cell already firing is in its refractory regime and again unresponsive in a precise sense; the *interesting* state — the one that does the system's bit-shifting work — is the narrow band just below threshold, where the [[membrane-potential]] is high enough that a coincident pair of EPSPs will cross threshold but a single one will not. The [[dendritic-leaky-membrane-coincidence-filter]] page makes this filtering geometric: the leakiness of the dendritic membrane sets the time constant over which incoming events can sum before decaying away, and that constant is what defines the *width* of the threshold state in time. The [[inhibitory-decay-oscillation-frequency]] page in turn argues that local [[oscillators]] tune the depth of inhibition so that whole populations are driven toward the threshold state in [[gamma-oscillation|gamma-band]] phase, which is what links the single-cell threshold story to the population-level [[brainwave|brainwave]] story. Read together, the threshold state is where SAN's [[coincidence-as-a-bit|coincidence-as-a-bit]] arithmetic actually gets executed: at the cell, at the column, and — through the [[thalamocortical-network]] / [[thalamic-convergence-zone|thalamic convergence zone]] — at the network as a whole. The framing also connects to the [[tonic-phasic-canvas-of-consciousness|tonic-phasic canvas]] picture: tonic activity sets the baseline near or far from threshold, and phasic events ride that baseline.
