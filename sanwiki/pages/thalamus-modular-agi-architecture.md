The [[thalamocortical-network|thalamus]] serves as a model for a key missing piece in
AGI architecture: a central integration hub that routes signals between specialized
sub-networks, modulates different sensory/memory streams, and synchronizes the whole
into a unified output — analogous to what the thalamus does in mammalian brains.

## Core proposal

Current deep-learning systems link layers but lack a dedicated routing and modulation
structure. A **thalamic module** in an AGI system would:
1. Receive outputs from multiple specialized networks (vision, language, motor planning)
2. Route them to appropriate downstream modules based on context
3. Modulate gain — amplifying salient signals, suppressing irrelevant ones
4. Maintain a shared temporal context so modules can coordinate

This mirrors how the biological thalamus integrates signals from sensory organs, limbic
circuits, and cortical feedback loops before relaying them back to cortex.

## 3D neural network corollary

The same discussion proposes a **3D neural network** — inputs from all spatial directions,
not just feed-forward depth — as a more accurate brain analog than flat layered networks.
A thalamic hub is necessary to prevent a fully-connected 3D network from becoming
computationally intractable: it selectively routes rather than broadcasting everything.
See [[napot]] for the projection-tomography interpretation of why 3D connectivity matters.

## Relation to SAN

SAN's [[self-aware-network]] architecture requires precisely this kind of selective
broadcast: arrays project pattern representations across a shared field, but not all
arrays activate simultaneously. The thalamic routing function is the mechanism that
determines *which* arrays are brought into phase. See
[[thalamo-cortical-information-flow]] for the anatomical grounding.
