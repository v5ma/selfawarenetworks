# Autogenous Associative Memory and Reconstructive Retrieval

## Governing question

Can an active memory state become part of the physical cue that reconstructs the next memory,
allowing thought to continue without each transition being selected by a new external stimulus?

## The idea in ordinary language

A conventional lookup begins when something outside the memory supplies an address. Biological
memory is different. A smell, image, word, body state, or internally generated thought can provide
a partial cue. Recurrent dynamics then reconstruct a context-dependent state from distributed
dispositions in synapses, dendrites, cells, and circuits. The reconstructed state changes the
network and thereby changes what can be recalled next.

The SAN contribution is the control-loop claim:

```text
partial external or internal cue
-> context-dependent reconstruction
-> active memory/prediction state
-> new internal cue and selection pressure
-> next reconstruction, simulation, or action
```

"Self-activating" does not mean information acts without matter or causation. It means that the
cue for a later transition can be generated by the network's own preceding physical state.

## Minimal state model

Let `W_t` denote the distributed structural and physiological dispositions available at time `t`,
`x_t` the active neural and body state, `s_t` the current sensory input, and `c_t` the task and
context. A recalled state is sampled or selected from a conditional distribution:

```text
m_t ~ p(m | q(x_t, s_t, c_t), W_t)
```

The retrieved state changes the next active state:

```text
x_(t+1) = F(x_t, s_t, m_t, c_t)
```

Plasticity changes later reconstruction probabilities:

```text
W_(t+1) = U(W_t, x_t, m_t, outcome_t)
```

This model separates four things that the file metaphor merges: the durable disposition `W`, the
cue `q`, the reconstructed content `m`, and the ongoing control state `x`.

## Claim ladder

### Established background

- Recurrent associative networks can complete a pattern from a partial cue.
- Hippocampal sharp-wave-ripple sequences can be internally generated and need not be literal
  copies of the immediately preceding trajectory; experiments have reported nonlocal and even
  never-experienced sequences.
- Spontaneous memory and future-oriented thought in humans follow semantic and temporal
  associations and engage interactions among hippocampal, default-network, and control-network
  regions.
- Dendrites are active nonlinear compartments. Local dendritic spikes can be sensory evoked,
  spontaneous, or associated with internally generated network events, depending on cell type and
  preparation.
- Corticothalamic feedback can modulate thalamic processing. This is not a cortex-to-retina
  pathway and does not establish a universal feedback ratio.

### SAN synthesis

- A memory is a context-sensitive reconstruction from physical dispositions, not a stored media
  file replayed without change.
- An active reconstruction can alter the cue, gain, context, and route that select the next
  reconstruction.
- Memory, prediction, imagination, and action selection can therefore form an autonomous but
  environmentally coupled sequence.
- Dendritic and circuit nonlinearities are candidate implementation layers; no single dendritic
  event is declared the memory or the self.

### Stronger hypothesis, not established

- Oscillatory phase relationships may help determine when one reconstructed state becomes an
  effective cue for another.
- A measurable transition operator may distinguish externally driven recall, internally cued
  recall, spontaneous replay, planning, and pathological perseveration.
- Reconstructive memory may supply a mechanistic bridge from SAN's memory-prediction cycle to
  continuous conscious thought, but it is not by itself a consciousness criterion.

## Decisive tests

1. **Cue-origin test:** decode whether each transition is better predicted by the preceding
   internal state, an external event, or both.
2. **Intervention test:** perturb a candidate recurrent or corticothalamic route after state `m_t`
   and preregister how the distribution of `m_(t+1)` should change.
3. **Reconstruction test:** compare exact-replay, static-attractor, probabilistic-reconstruction,
   and autogenous-sequence models on held-out episodes.
4. **Dendritic-boundary test:** manipulate a dendritic nonlinearity while preserving average
   somatic firing and ask whether recall selectivity or transition structure changes.
5. **Failure-condition test:** reject the SAN extension if internally generated states add no
   predictive information beyond sensory input, arousal, movement, and ordinary recurrent-network
   baselines.
