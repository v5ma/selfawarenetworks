LTD Inhibitory Pattern Sharpening describes how the inhibitory aftermath of a phasic [[action-potential|action potential]] clarifies the Sparse Distributed Representation (SDR) carried forward to the next neural layer — making the *dark* (inhibited) areas as informationally important as the *lit* (active) areas.

## Mechanism

When a neuron fires phasically, its exit terminal inhibits a surrounding set of downstream neurons via potassium-heavy synapses (lateral inhibition). Those inhibited neurons form a **negative mask**: they are temporarily desynchronized from the global oscillator and carry reduced charge. The few neurons that escaped inhibition now represent the sparse active pattern.

The result in the next layer (e.g., V1 → V2 → V4 in the visual pathway) is a TV-screen-like representation: **bright spots** = phasic burst neurons; **dark spots** = inhibited neurons; **dim spots** = tonically firing neurons. Pattern recognition in the receiving layer uses both the active and inhibited structure — the boundary between dark and bright *is* the pattern.

## Why Inhibition Equals Clarity

Without inhibition, too many downstream neurons would be candidates for activation, creating pattern ambiguity — multiple unrelated inputs could push a receiving neuron over threshold. Inhibition removes candidates, leaving only the neurons whose dendritic patterns specifically match the sparse input. This is the neural substrate of **selective [[attention]]**: the brain narrows what it sees by darkening what it is not looking at.

The same principle applies to the global oscillator: when a group of neurons is inhibited and slowed relative to the baseline rhythm, the global oscillation must re-absorb that phase deficit. This adjustment encodes the inhibitory event into the [[phase-wave-differentials|phase wave differential]], propagating the sharpened pattern as a phase shift to downstream networks including the default mode network.

## Relationship to LTP/LTD

- **LTP** (high-frequency burst stimulation) → strengthens synaptic bonds between co-firing neurons → builds the *positive* pattern.
- **LTD** (one-hertz / low-frequency inhibition) → desynchronizes co-firing neurons → erases spurious patterns → sharpens the encoding by removing noise.

LTD at the whole-oscillator scale (b0103y: 1 Hz stimulation trains) causes broad desynchronization — the opposite of LTP — which paradoxically *increases* pattern clarity by resetting ill-formed assemblies.
