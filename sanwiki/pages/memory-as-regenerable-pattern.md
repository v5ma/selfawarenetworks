# Memory as Regenerable Pattern

Memory as Regenerable Pattern is SAN's source-faithful distinction between a persistent learned biological substrate and the temporary, context-sensitive distributed activity reconstructed during retrieval.

> **Figure note:** The earlier one-neuron procedural-memory plate has been withdrawn from use. A replacement must depict distributed reconstruction supported by persistent learned changes, not a complete memory stored or replayed by one neuron.

## The 2013 proposal and its built-in correction

In a November 9, 2013 exchange preserved in [[gh-a0345z|the source record]], Micah Blumberg proposed that the same input could trigger procedures that regenerate a temporary memory or "brain canvas." Jordan Tribby immediately supplied a necessary constraint: the same cue can retrieve different details depending on preceding activity, priming, state, noise, and which learned components are available.

The paired argument is stronger than either sentence alone. Retrieval need not be literal playback of a stored picture, but reconstruction cannot occur without information retained through learning. A source-faithful SAN formulation is therefore:

**persistent learned constraints + current brain, body, and context state + partial cue -> selected ensemble recruitment -> recurrent completion and competition -> transient distributed re-expression -> memory-guided perception, report, or action**

## What persists and what is regenerated

| Stage | Biologically bounded description |
|---|---|
| Persistent substrate | Learning changes synaptic efficacy, cellular excitability, dendritic structure, gene expression, and relationships among neurons and circuits. These changes constrain what can later be reconstructed. |
| Cue and current state | A partial sensory, internal, or task cue arrives in a brain already shaped by attention, affect, bodily state, recent activity, and context. |
| Recruitment | The cue preferentially recruits some learned ensembles while inhibition, competition, and unavailable routes suppress alternatives. |
| Completion and reinstatement | Recurrent interactions can complete missing relations and reinstate activity across distributed regions. This is a new neural event constrained by the past, not a stored image being opened. |
| Consequence | The reconstructed state can guide recognition, recollection, language, choice, and action without requiring an inner viewer. The network itself performs the reconstruction and uses its consequences. |

This distinction connects the general [[engram]] concept to SAN's [[engrams|Holographic Engrams]] proposal. The engram names the enduring physical and functional changes produced by learning. The regenerable pattern names the transient activity those changes help produce during retrieval.

## What established evidence supports

Experiments support several parts of this architecture without proving the complete SAN interpretation:

- Optogenetic activation of a tagged hippocampal ensemble can evoke a learned fear response in mice, showing that bounded ensemble activity can participate causally in recall ([Liu et al., 2012](https://www.nature.com/articles/nature11028)).
- Human work supports hippocampal [[pattern-completion]] from partial event cues together with reinstatement of associated information in distributed neocortical regions ([Horner et al., 2015](https://www.nature.com/articles/ncomms8462)).
- Brain-wide mapping in mice supports a distributed engram complex: simultaneous reactivation of multiple engram ensembles produced stronger recall than reactivation of one ensemble alone ([Roy et al., 2022](https://www.nature.com/articles/s41467-022-29384-4)).

These findings support persistent biological change, ensemble recruitment, pattern completion, and distributed reinstatement. They do not show that one generic neuron contains a complete memory, that dendritic coincidence alone is sufficient for recall, or that retrieval recreates one exact phase pattern.

## The SAN interpretation

SAN treats retrieval as a receive-transform-project process operating across several scales:

1. Learned cellular and circuit constraints shape how a cue is received.
2. [[neural-coincidence-patterns|Coincidence]], inhibition, and recurrent interaction select a distributed response.
3. [[oscillating-group-completion|Oscillating-group completion]] may help re-express a learned population relation.
4. The resulting activity modifies the network's ongoing state and becomes available to perception and action.

This interpretation is compatible with [[distributed-memory]] and with the observation that representations can change while function persists, discussed in [[memory-state-drift-virtual-mind|Memory, Engrams, Representational Drift, and the Virtual Mind]]. It does not require a static neural photograph or a central observer.

## The open PWD extension

The stronger SAN hypothesis is that receiver-relative timing, phase, waveform, and other [[phase-wave-differentials|Phase-Wave Differential]] variables help determine which learned routes are recruited and how a reconstructed pattern changes downstream processing. That claim remains open and must be tested against simpler models.

A useful nested comparison is:

- **Model 0:** cue and current state predict retrieval.
- **Model 1:** learned ensemble membership and effective connectivity add predictive power.
- **Model 2:** receiver-relative timing and PWD variables add reproducible predictive power beyond firing rate, ensemble identity, and current state.

Model 2 should be rejected for this mechanism if those variables add no robust out-of-sample prediction or causal control.

## Predictions and falsifiers

- The same external cue should produce systematically different reconstructions when internal state or context changes.
- Graded partial cues should recruit correspondingly graded completion before report or action.
- Perturbing the relevant learned ensemble or connectivity should impair the reconstructed content or its behavioral consequence.
- Distributed perturbation should sometimes impair recall more than a matched single-site perturbation.
- A SAN-specific PWD account earns its place only if its typed variables improve prediction and intervention beyond standard ensemble, rate, and state models.
- Successful reconstruction does not by itself establish conscious access; that stronger claim requires an independent test.
