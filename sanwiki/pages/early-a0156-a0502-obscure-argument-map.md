# Early a0156-a0502 Obscure Argument Map

This page maps a fixed semantic-review queue from the downloaded SAN repository. It preserves the
strongest legitimate operation in each source before evaluating its scientific wording. Internal
dates, later Git fixation, duplicate source families, multi-speaker attribution, and current
scientific evidence remain separate.

## The problem before the terminology

A biological signal does not pass through the brain as one unchanged binary symbol. The state of
the sender affects the event it emits; the state of the receiver affects the consequence; recurrent
populations combine partial views with memory and prediction; the resulting state can guide action;
and the returning consequence changes the next state.

The recovered chain is:

```text
dendritic, membrane, and recent network state
-> non-binary timing, burst, waveform, and release event
-> receiver-specific transformation
-> distributed reconstruction and prediction
-> learned relation becomes usable through action
-> embodied self/world model selects a route
-> feedback changes the next state
```

Later SAN terms such as PWD, NAPOT, Entification, and Choice can be connected to this chain only at
their later verified dates.

## Constructive branches

### State-dependent output before PWD

`a0156z.md` asks a legitimate modeling question even though some period words are inaccurate: what
properties of the dendritic, somatic, and recent cellular state remain consequential after a neuron
fires? The current operation is:

```text
cellular state -> spike timing, burst, or waveform
-> terminal calcium and release state
-> receiver-specific postsynaptic effect
-> local or wider network consequence
```

This is an early source branch for [[synaptic-unreliability-mvr-2021|the ionotropic information
channel]] and [[flow-of-information-in-the-brain|the flow-of-information problem]]. It is not
backdated as PWD.

### Reconstruction without an inner viewer

`a0158z.md`, `a0482z.md`, `a0499z.md`, and `a0500z.md` converge on a distributed operation: many
partial, learned, and currently active relations contribute to a usable reconstruction; the same
embodied network then predicts, acts, and receives the result. A singular observer can summarize
that organization without introducing a second witness behind the neural activity.

### Meaning through relation and use

`a0493z.md`, `a0495z.md`, `a0496z.md`, and `a0497z.md` ask how a pattern becomes meaningful. Their
durable answer is relational and sensorimotor: a learned pattern matters when it predicts, selects,
or changes another pattern, bodily state, or action. Retinal waves, tractography, graph theory, and
category theory are neighboring tools or analogies; none alone supplies semantics.

### Choice across physical levels

`a0489z.md` separates a physical state transition from an action and from a person's later claim of
ownership. `a0497z.md` adds prediction, inhibition, and the possibility of stopping or permitting an
action. The resulting route belongs in [[neural-path-selection-interneurons-choice|Neural Path
Selection and Choice]]:

```text
learned criteria and current state
-> competing effective routes
-> inhibition, excitation, and recurrent comparison
-> physical commitment and action
-> report, ownership, evaluation, and later criteria update
```

### Neo Mind Cycle as an early closed loop

`a0491z.md`, `a0492z.md`, and `a0502z.md` preserve a 2013-2014 source family around one testable
engineering loop:

```text
EEG measurement -> software feature mapping -> light or sound feedback
-> participant response -> changed EEG -> repeated learning loop
```

The loop is legitimate apparatus and research genealogy. Historical claims about treating disease,
raising IQ, resolving trauma, or guaranteeing psychological improvement require controlled evidence
and are not current medical guidance.

## Matching scientific evidence

- [Li, Poo, and Dan 2009](https://doi.org/10.1126/science.1169957) showed that burst spiking of one
  rat cortical neuron could switch measured cortical state under their preparation. This supports
  the possibility of a large consequence from one cell, not a universal all-to-all broadcast.
- [Kwan and Dan 2012](https://doi.org/10.1016/j.cub.2012.06.007) measured cell-type-specific local
  responses to single-neuron stimulation in mouse visual cortex. The effect depended on cell class,
  burst size, radius, and network state.
- [Zador 1998](https://doi.org/10.1152/jn.1998.79.3.1219),
  [Holler et al. 2021](https://doi.org/10.1038/s41586-020-03134-2),
  [Cho et al. 2020](https://doi.org/10.1073/pnas.2000790117), and
  [Hoppa et al. 2014](https://doi.org/10.1016/j.neuron.2014.09.038) support a stochastic,
  waveform- and state-sensitive synaptic route.
- [Ackman, Burbridge, and Crair 2012](https://doi.org/10.1038/nature11529) supports patterned
  retinal-wave propagation during visual-system development. It does not show that those waves
  already contain learned semantic tokens.
- [Churchland et al. 2012](https://doi.org/10.1038/nature11129) supports structured population
  dynamics during movement, while [Chang and Snyder 2010](https://doi.org/10.1073/pnas.0913209107)
  supports mixed reference frames. These are components of a transformation-and-action account,
  not proof of the complete SAN synthesis.
