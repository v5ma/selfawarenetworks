Individual synapses contain **over 1,000 interacting proteins** that configure diverse post-synaptic receptors — making each synapse a significant computational unit, not merely a binary switch. This molecular richness is the physical substrate for [[ltp|long-term potentiation (LTP)]] and memory consolidation.

## Structural changes in LTP

Long-term memory is not just a persistent weight change; it requires physical restructuring: synaptogenesis, formation of new [[dendritic-spines]], and dendritic arborization. These structural changes are triggered by repeated firing patterns and require **new protein synthesis**.

Key molecular actor: **CaMKII** (calcium/calmodulin-dependent protein kinase II) interactions with [[microtubules]] stabilize these structural changes, linking cytoskeletal dynamics to durable memory encoding. This is [[gh-resnote04|Micah]]'s counter to the "synapses alone explain memory" position: the molecular machinery extends *into* the cytoskeleton.

## Small-world topology context

The brain's [[small-world-network]] architecture — dense local clusters + sparse long-range links — gives any two neurons roughly six degrees of separation. This compact topology enables both efficient local computation (per synapse) and rapid global broadcast, a macro-level analogue to [[napot-neural-array-phase-tomography|NAPOT's]] distributed phase rendering.

## Multiple memory systems

SAN argues (against the strict "synapses are the primary memory store" view) that multiple overlapping memory substrates exist: synaptic weight changes, structural remodeling, cytoskeletal protein states, and oscillatory phase-pattern encoding (see [[napot-neural-array-phase-tomography]]). Synaptic LTP is necessary but not sufficient.

## SDR note

[[sparse-distributed-representations|Sparse Distributed Representations (SDRs)]] (Hawkins/HTM) offer a mathematical model for how sparse neural patterns efficiently encode information. While not a strict neuroscientific model, SDRs are complementary to SAN's phase-slice framework.
