## Main recovery: memory can cue memory

`a0131z.md` asks whether an associative memory can generate the event that activates another
memory. `a0191z.md` supplies the qualification needed to make that proposal coherent: the brain
need not store an exact internal recording. A partial cue and the current network state can
reconstruct one context-dependent realization from distributed physical dispositions. That
realization can then help select the next one.

The repaired route is [[self-activating-content-addressable-memory|Autogenous Associative Memory
and Reconstructive Retrieval]]. It preserves the SAN insight while removing the old Wiki's
incorrect cortex-to-retina anatomy and preventing "information-driven" from being read as
nonphysical causation.
