# Source-Faithful Correction Retro-Audit Register

This ledger applies the typo-first intent-recovery rule to SAN Wiki corrections that were made
before the rule was adopted on July 22, 2026. It does not pretend those older edits happened today,
and it does not assign later SAN terminology to earlier sources.

## What is compared

Every repaired page must preserve and compare four layers:

```text
Micah's underlying source and its real date
-> preserved Wiki version before the rewrite
-> first scientific correction and its real date
-> current source-faithful repair and audit date
```

The comparison asks whether the first correction gained accuracy but lost an argument, example,
prediction, analogy, mechanism, or genealogy because a wording problem was mistaken for a failed
idea.

Every row begins under the working presumption `PROBABLE_TYPO_OR_COMPRESSED_INTENT`. A fix is not
accepted merely because the newest prose agrees more closely with conventional terminology. It
must separately pass both scientific accuracy and SAN narrative preservation.
