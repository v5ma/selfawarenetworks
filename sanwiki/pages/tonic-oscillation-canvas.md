# Tonic Oscillation as Canvas

**Tonic oscillation as canvas** is a historical SAN name for the idea that an ongoing neural state
supplies the conditions against which a transient difference is registered. The canonical current
formulation is [[tonic-phasic-canvas|Tonic and Phasic Roles: Canvas and Ink]].

The canvas should not be pictured as one global rhythm, a literal display surface, or a state of
pure awareness. Depending on the experiment, the relevant context may include membrane potential,
synaptic conductance, adaptation, population activity, neuromodulation, oscillatory phase, body
state, or several of these together.

Likewise, phasic "paint" is not a fixed 0/1/2/3-vesicle pixel value. A release event is transformed
by terminal dynamics and by the receptors, voltage, inhibition, and history of each postsynaptic
receiver. Deep anesthesia also changes many interacting variables; it does not selectively erase a
single universal canvas while leaving an independent paint channel intact.

The durable SAN insight is relational: an ongoing field-cell state is changed by an event, and the
same coupled system carries that change into later processing, body control, and action.
