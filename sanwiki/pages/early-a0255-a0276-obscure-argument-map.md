## Coherence, splay, and the anti-bit

`a0256z.md` says that coincident phase patterns provide the basis of a neural bit while a splay state
provides the basis of an anti-bit. The durable insight is not a two-symbol digital alphabet. It is
that organized alignment and organized phase separation may both carry computational structure:

```text
local alignment -> recruitment, coupling, or persistence
structured dispersion -> distinction, competition, or route boundary
interaction with receiver state -> a measurable differential consequence
```

This strengthens the existing coherence-dispersion paper candidate and PWD. It does not establish
that every desynchronized state is a splay state or that neural activity implements Boolean
negation.

## The 2018 implementation gate

`a0264z.md` is unusually valuable because it records both accomplishment and incompleteness in the
same source. The portable EEG, WebVR, and Oculus Go loop was described as demonstrable. FFT, AI,
and Raspberry Pi features were still pending. EIT, volumetric video, 3D Cross-Hair CNNs, and
brain-scene segmentation were the next proposed project.

The governed history is therefore:

```text
implemented: portable EEG -> software/WebVR -> headset-visible feedback
planned: FFT + TensorFlow + Raspberry Pi integration
proposed next: EIT + volumetric scene + 3D segmentation + neural correlation
```

This is stronger than a vague BCI aspiration because it supplies a bounded implementation claim.
It is also safer than collapsing the entire roadmap into one completed system.

## Adversarial correction without erasing the innovation

`a0263z.md` objects to the phrase "axon potential," explains membrane potential as a voltage
difference across the membrane, and distinguishes dendritic backpropagation from a supposed
surplus above an axonal maximum. Those corrections should govern the Wiki.

They do not reduce action potentials to interchangeable binary tokens. The defensible residual
question is whether recent input history changes a compartment-specific waveform and whether that
change survives terminal calcium, release, receptor, and receiver transformations well enough to
add predictive or causal information beyond spike occurrence, count, and timing.

## Observer, attention, and multimodal rendering

`a0261z.md`, `a0267z.md`, `a0268z.md`, and `a0276z.md` converge on a useful plain-language story.
Attention changes which visual, tactile, auditory, memory, and motor relations are recruited. The
observer is the distributed system that is changed by and uses those relations, not a hidden
viewer. The tonic canvas is therefore a receiver context; phasic events are candidate updates to
that context.

The sources do not license a universal rule that attention always means larger activity, one
frequency, one region, or literal magnification at every scale. Gain, precision, selection,
effective connectivity, inhibition, and task-dependent decoding must be measured separately.
